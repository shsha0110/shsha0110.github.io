  • 요약 (Summary)

들어가며

많은 실제 최적화 문제에서 목적 함수는 매끄럽지 않습니다(nonsmooth). 대표적으로 \(\ell_1\) 정규화, \(\ell_2\) 노름, 힌지 손실 등이 그러한 예입니다. 이러한 함수에 대해 부분기울기(subgradient) 방법을 사용하면 수렴 속도가 \(O(1/\sqrt{T})\) 수준에 그칩니다.

이번 강의에서는 이 한계를 극복하기 위한 두 가지 핵심 도구를 공부합니다.

  • 매끄러운 근사(Smooth Approximation): 비매끄러운 함수를 매끄러운 함수로 근사하여 Nesterov 가속 경사하강법(\(O(1/T)\) 수렴)을 적용하는 기법.
  • Fenchel 켤레(Fenchel Conjugate): 볼록 함수의 쌍대 표현으로, 최적화 이론의 근간을 이루는 개념. Moreau 분해(Moreau decomposition)로 이어집니다.

2. Smooth Approximation (매끄러운 근사)

2.1 (p, q)-Smoothability의 정의

볼록 함수 \(f\)가 (p, q)-smoothable이라고 함은, 임의의 \(\mu > 0\)에 대해 볼록 함수 \(f_\mu\)가 존재하여 다음 두 조건을 동시에 만족할 때를 말합니다.

  1. \(f_\mu\)는 \((p/\mu)\)-매끄러운(smooth) 함수이다. 즉, \(\nabla f_\mu\)가 \((p/\mu)\)-Lipschitz 연속이다.
  2. 모든 \(x\)에 대해 근사 오차가 균일하게 제어된다: \[ f_\mu(x) \leq f(x) \leq f_\mu(x) + q\mu. \]
  • 조건 2는 \(f_\mu\)가 \(f\)를 아래에서 근사하되, 최대 \(q\mu\)만큼의 오차만 허용함을 뜻합니다.
  • \(\mu\)를 작게 할수록 근사가 정확해지지만, 매끄러움 상수 \(p/\mu\)는 커집니다. 정확도와 매끄러움 사이에 트레이드오프가 존재합니다.

2.2 예시: \(\ell_1\) 노름의 Huber 함수 근사

Huber 함수의 정의

Example 14.1 (\(\ell_1\) norm). 1차원 절댓값 \(|\cdot|\)의 매끄러운 근사로 Huber 함수를 사용합니다:

\[ L_\mu(z) = \begin{cases} \dfrac{z^2}{2\mu}, & \text{if } |z| \leq \mu, \\[6pt] |z| - \dfrac{\mu}{2}, & \text{otherwise.} \end{cases} \tag{14.1} \]

근사 오차 검증

다음이 성립합니다:

\[ L_\mu(z) \leq |z| \leq L_\mu(z) + \frac{\mu}{2}. \]

유도: - \(|z| \leq \mu\)인 경우: \(L_\mu(z) = z^2/(2\mu)\). AM-GM에 의해 \(z^2/(2\mu) \leq |z|\). 또한 \(|z| \leq L_\mu(z) + \mu/2 = z^2/(2\mu) + \mu/2\)는 \((|z| - \mu/2)^2 \geq 0\)에서 따라옵니다. - \(|z| > \mu\)인 경우: \(L_\mu(z) = |z| - \mu/2 \leq |z|\)이고, \(|z| \leq L_\mu(z) + \mu/2 = |z|\)로 등호가 성립합니다.

따라서 Huber 함수는 절댓값을 \(\mu/2\) 오차 내에서 아래에서 근사합니다.

매끄러움 검증

\(L_\mu\)의 도함수는 다음과 같습니다:

\[ L_\mu'(z) = \begin{cases} z/\mu, & |z| \leq \mu, \\ \text{sign}(z), & |z| > \mu. \end{cases} \]

\(|L_\mu'(z_1) - L_\mu'(z_2)| \leq (1/\mu)|z_1 - z_2|\)임을 확인할 수 있으므로, \(L_\mu\)는 \((1/\mu)\)-매끄럽습니다.

따라서 \(|\cdot|\)은 \((1, 1/2)\)-smoothable입니다.

\(\ell_1\) 노름으로 확장

\(x \in \mathbb{R}^d\)에 대해 \(f_\mu(x) = \sum_{i=1}^d L_\mu(x_i)\)로 정의하면:

  • \(f_\mu\)는 \((1/\mu)\)-매끄럽습니다 (각 좌표마다 독립적으로 적용).
  • 다음을 만족합니다:

\[ f_\mu(x) \leq \|x\|_1 \leq f_\mu(x) + \frac{d\mu}{2}. \]

따라서 \(\|\cdot\|_1\)은 \((1, d/2)\)-smoothable입니다.

2.3 예시: \(\ell_2\) 노름의 매끄러운 근사

Example 14.2 (\(\ell_2\) norm). \(x \in \mathbb{R}^d\)에 대해 다음을 정의합니다:

\[ f_\mu(x) = \sqrt{\|x\|_2^2 + \mu^2} - \mu. \]

근사 오차 검증

임의의 \(\mu \geq 0\)에 대해:

\[ f_\mu(x) \leq \|x\|_2 \leq f_\mu(x) + \mu. \]

  • 좌측 부등식: \(\sqrt{\|x\|_2^2 + \mu^2} - \mu \leq \|x\|_2\)는 \(\sqrt{a^2+b^2} \leq a + b\) (\(a, b \geq 0\))의 형태입니다.
  • 우측 부등식: \(\|x\|_2 \leq \sqrt{\|x\|_2^2 + \mu^2}\)에서 \(-\mu\)를 더하면 됩니다.

매끄러움 검증

그래디언트와 헤시안을 계산합니다:

\[ \nabla f_\mu(x) = \frac{x}{\sqrt{\|x\|_2^2 + \mu^2}}, \qquad \nabla^2 f_\mu(x) = \frac{1}{\sqrt{\|x\|_2^2 + \mu^2}} I - \frac{1}{(\|x\|_2^2 + \mu^2)^{3/2}} xx^\top. \]

헤시안의 최대 고유값을 추정하면:

\[ \nabla^2 f_\mu(x) \preceq \frac{1}{\sqrt{\|x\|_2^2 + \mu^2}} I \preceq \frac{1}{\mu} I. \]

따라서 \(f_\mu\)는 \((1/\mu)\)-매끄럽고, \(\|\cdot\|_2\)는 \((1, 1)\)-smoothable입니다.

2.1 Smoothing Lipschitz Functions (Lipschitz 함수의 매끄러운 근사)

Moreau-Yosida 스무딩

\(f\)가 \(L\)-Lipschitz 볼록 함수이면 \(f\)는 \((1, L^2/2)\)-smoothable임을 보입니다. 이를 위해 Moreau-Yosida 스무딩(Moreau-Yosida smoothing)을 소개합니다.

함수 \(f: \mathbb{R}^d \to \mathbb{R}\)와 \(\eta > 0\)에 대해 Moreau-Yosida 스무딩을 다음으로 정의합니다:

\[ f_\eta(x) := \inf_u \left\{ f(u) + \frac{1}{2\eta} \|u - x\|_2^2 \right\}. \]

  • 이 표현은 근위 연산자(proximal operator)의 최솟값을 구하는 것과 밀접한 관련이 있습니다.
  • \(f(u)\)의 최솟값을 찾되, \(x\)에서 너무 멀리 이동하지 않도록 이차 페널티를 부과하는 형태입니다.

근사 오차 검증

\(u = x\)를 대입하면:

\[ f_\eta(x) \leq f(x) + \frac{1}{2\eta}\|x - x\|_2^2 = f(x). \]

아래쪽 한계를 구하기 위해, \(x\)에서의 부분기울기를 \(g_x \in \partial f(x)\)라 하면:

\[ f_\eta(x) - f(x) = \inf_u \left\{ f(u) - f(x) + \frac{1}{2\eta}\|u-x\|_2^2 \right\} \geq \inf_u \left\{ g_x^\top(u-x) + \frac{1}{2\eta}\|u-x\|_2^2 \right\} = -\frac{\eta}{2}\|g_x\|_2^2. \]

\(f\)가 \(L\)-Lipschitz이면 \(\|g_x\|_2 \leq L\)이므로:

\[ f_\eta(x) \geq f(x) - \frac{\eta L^2}{2}. \]

즉, \(\eta = \mu\)로 놓으면:

\[ f_\mu(x) \leq f(x) \leq f_\mu(x) + \frac{\mu L^2}{2}. \]

따라서 \(q = L^2/2\)이고, \(f\)는 \((1, L^2/2)\)-smoothable입니다.

2.2 Smooth Optimization of Nonsmooth Functions (비매끄러운 함수의 매끄러운 최적화)

문제 설정

다음과 같은 최적화 문제를 고려합니다:

\[ \minimize_{x} \; g(x) + h(x) \]

여기서: - \(g\)는 볼록이고 \((p, q)\)-smoothable, - \(h\)는 볼록 함수(반드시 매끄럽지 않아도 됨).

알고리즘

  1. 근사 문제 구성: \(g\)의 매끄러운 근사 \(g_\mu\)를 사용하여 다음 문제를 푼다: \[\minimize_x \; g_\mu(x) + h(x)\] 여기서 \(g_\mu\)는 \((p/\mu)\)-매끄럽고, \(g_\mu \leq g \leq g_\mu + q\mu\).

  2. Nesterov 가속 경사하강법 적용: \(g_\mu + h\)의 최소화에 Nesterov 알고리즘을 적용한다. (\(h\)에 대해서는 근위 연산자를 사용)

수렴 분석

Theorem 14.3. \(T-1\)번 반복 후 출력 \(x_T\)에 대해:

\[ g(x_T) + h(x_T) - \min_x \{g(x) + h(x)\} \leq q\mu + \frac{p}{\mu T^2}\|x_1 - x^*\|_2^2. \]

증명의 핵심 흐름:

  • Nesterov 알고리즘 적용 결과: \[ g_\mu(x_T) + h(x_T) - g_\mu(x^*) - h(x^*) \leq \frac{p}{\mu T^2}\|x_1 - x^*\|_2^2. \]
  • \(g_\mu\)의 정의에 의해: \(g_\mu(x_T) \geq g(x_T) - q\mu\), \(g_\mu(x^*) \leq g(x^*)\).
  • 이를 결합하면: \[ g(x_T) + h(x_T) - g(x^*) - h(x^*) \leq q\mu + \frac{p}{\mu T^2}\|x_1 - x^*\|_2^2. \quad \square \]

최적 \(\mu\) 선택

오차의 두 항 \(q\mu\)와 \(\frac{p}{\mu T^2}\|x_1-x^*\|_2^2\)을 균형 있게 맞추기 위해 \(\mu = 1/T\)로 설정하면:

\[ g(x_T) + h(x_T) - \min_x \{g(x)+h(x)\} = O\!\left(\frac{1}{T}\right). \]

이는 부분기울기 방법의 수렴 속도 \(O(1/\sqrt{T})\)를 크게 개선합니다.

방법 수렴 속도
부분기울기(Subgradient) 방법 \(O(1/\sqrt{T})\)
매끄러운 근사 + Nesterov 가속 \(O(1/T)\)

3. Fenchel Conjugate (Fenchel 켤레)

3.0 정의

함수 \(f: \mathbb{R}^d \to \mathbb{R}\)의 Fenchel 켤레(Fenchel conjugate)는 다음으로 정의됩니다:

\[ f^*(y) = \sup_{x \in \text{dom}(f)} \left\{ y^\top x - f(x) \right\}. \]

  • \(y^\top x - f(x)\)는 \(y\)에 대한 선형 함수입니다. 따라서 \(f^*\)는 \(f\)의 볼록성과 무관하게 항상 볼록 함수입니다 (선형 함수들의 상한이므로).
  • 기하학적으로, \(f^*(y)\)는 기울기 \(y\)를 갖는 선이 그래프 \((x, f(x))\)의 에피그래프(epigraph)를 얼마나 ’아래서 받치는가’의 크기를 나타냅니다.

Fenchel-Young 부등식

Lemma 14.4 (Fenchel-Young Inequality). \(x \in \text{dom}(f)\), \(y \in \text{dom}(f^*)\)에 대해:

\[ f(x) + f^*(y) \geq y^\top x. \]

증명: \(f^*(y) = \sup_{x'}(y^\top x' - f(x')) \geq y^\top x - f(x)\)이므로 즉시 따라옵니다. \(\square\)

3.1 Fenchel Conjugate Examples (켤레 함수 예시)

Example 14.5: 선형 함수

\(f(x) = c^\top x + d\) (\(x \in \mathbb{R}^d\))일 때:

\[ f^*(y) = \sup_{x \in \mathbb{R}^d}(y^\top x - c^\top x - d) = \sup_{x}(y - c)^\top x - d. \]

\((y-c)^\top x\)는 \(y = c\)가 아니면 \(x \to \infty\)로 발산하므로:

\[ f^*(y) = \begin{cases} -d, & \text{if } y = c, \\ +\infty, & \text{otherwise.} \end{cases} \]

Example 14.6: 소프트플러스 함수

\(f(x) = \log(1 + e^x)\) (\(x \in \mathbb{R}\))일 때:

\[ f^*(y) = \sup_{x \in \mathbb{R}} (yx - \log(1+e^x)). \]

1차 조건 \(y = e^x/(1+e^x)\)을 만족하는 \(x^* = \log(y/(1-y))\)를 대입하면:

\[ f^*(y) = \begin{cases} y\log y + (1-y)\log(1-y), & 0 < y < 1, \\ 0, & y \in \{0, 1\}, \\ +\infty, & \text{otherwise.} \end{cases} \]

이는 베르누이 확률의 음의 이진 엔트로피(negative binary entropy)에 해당합니다.

Example 14.7: 이차 함수

\(f(x) = \frac{1}{2}x^\top Q x + p^\top x\) (\(Q \succ 0\))일 때:

\[ f^*(y) = \sup_x \left\{ y^\top x - \frac{1}{2}x^\top Q x - p^\top x \right\}. \]

1차 조건: \(y - Qx - p = 0 \Rightarrow x^* = Q^{-1}(y-p)\). 대입하면:

\[ f^*(y) = \frac{1}{2}(y-p)^\top Q^{-1}(y-p). \]

또한:

\[ \nabla f^*(y) = Q^{-1}(y-p). \]

이로부터 \(\nabla f(\nabla f^*(y)) = y\), 즉 \(\nabla f^* = (\nabla f)^{-1}\)임을 알 수 있습니다. 켤레의 그래디언트는 원래 함수 그래디언트의 역사상입니다.

Example 14.8: 음의 엔트로피

\(f(x) = \sum_{i=1}^d x_i \log x_i\) (\(x \in \mathbb{R}_{++}^d\))일 때:

\[ f^*(y) = \sup_{x \in \mathbb{R}_{++}^d} \sum_{i=1}^d x_i(y_i - \log x_i). \]

각 좌표별로 독립적으로 최대화: \(\partial/\partial x_i: y_i - \log x_i - 1 = 0 \Rightarrow x_i^* = e^{y_i - 1}\). 따라서:

\[ f^*(y) = \sum_{i=1}^d e^{y_i - 1}. \]

Example 14.9: 로그 행렬식 함수

\(f(X) = -\log \det X\) (\(X \in \mathbb{S}_{++}^d\))일 때:

\[ f^*(Y) = \sup_{X \in \mathbb{S}_{++}^d} \{\text{tr}(Y^\top X) + \log \det X\}. \]

\(\nabla_X \log \det X = X^{-1}\)을 이용하면 1차 조건: \(Y + X^{-1} = 0 \Rightarrow X^* = -Y^{-1}\) (따라서 \(Y \prec 0\) 필요). 대입하면:

\[ f^*(Y) = -d - \log \det(-Y). \]

3.2 Some Properties (성질들)

다음 연산 규칙들이 성립합니다. 이들은 복합 함수의 켤레를 체계적으로 계산하는 데 유용합니다.

  • 분리 가능성: \(f(x_1, x_2) = f_1(x_1) + f_2(x_2)\)이면 \[f^*(y_1, y_2) = f_1^*(y_1) + f_2^*(y_2).\]

  • 선형 이동: \(g(x) = f(x) + c^\top x + d\)이면 \[g^*(y) = f^*(y - c) - d.\]

  • 인수 이동: \(g(x) = f(x - b)\)이면 \[g^*(y) = b^\top y + f^*(y).\]

  • 하한 합성: \(f(x) = \inf_{u+v=x}\{g(u) + h(v)\}\)이면 \[f^*(y) = g^*(y) + h^*(y).\]

켤레 함수의 폐쇄성

Lemma 14.10. 임의의 폐쇄 함수 \(f: \mathbb{R}^d \to \mathbb{R}\)에 대해, \(f^*\)는 폐쇄(closed)이고 볼록(convex)이다.

증명 스케치: \(f^*(y) = \sup_{x \in \text{dom}(f)} h_x(y)\)이고, 각 \(h_x(y) = y^\top x - f(x)\)의 에피그래프는 폐쇄 반공간이므로: \[ \text{epi}(f^*) = \bigcap_{x \in \text{dom}(f)} \text{epi}(h_x). \] 임의의 수의 폐쇄 집합의 교집합은 폐쇄이므로 \(\text{epi}(f^*)\)가 폐쇄, 즉 \(f^*\)가 폐쇄입니다. \(\square\)

이중 켤레 부등식

Lemma 14.11. 임의의 함수 \(f: \mathbb{R}^d \to \mathbb{R}\)에 대해 \(f^{**} \leq f\).

증명 스케치: minimax 부등식 \(\inf_z \sup_y \{\cdot\} \geq \sup_y \inf_z \{\cdot\}\)를 적용하면:

\[ f(x) = \inf_{z \in \text{dom}(f)} \sup_{y \in \mathbb{R}^d} \{y^\top(x-z) + f(z)\} \geq \sup_{y \in \mathbb{R}^d} \{y^\top x - f^*(y)\} = f^{**}(x). \quad \square \]

이중 켤레 등식 (볼록·폐쇄 함수)

\(f\)가 폐쇄이고 볼록이면 \(f^{**} = f\)가 성립합니다. 증명은 엄격 분리 정리를 사용합니다.

Theorem 14.12 (Strict Point-to-Convex Set Separation). \(C \subseteq \mathbb{R}^d\)가 폐쇄 볼록 집합이고 \(y \notin C\)이면, \(\inf_{x \in C}\|x-y\| > 0\)이고, \(\alpha \in \mathbb{R}^d\), \(\beta \in \mathbb{R}\)이 존재하여: \[ \alpha^\top x > \beta \; \forall x \in C, \qquad \alpha^\top y < \beta. \]

Lemma 14.13. 폐쇄 볼록 함수 \(f: \mathbb{R}^d \to \mathbb{R}\)에 대해 \(f^{**} = f\).

증명 개요:

  • \(f \geq f^{**}\)은 Lemma 14.11에서.
  • \(f \leq f^{**}\)를 보이기 위해, 반례로 \((\bar{x}, f^{**}(\bar{x})) \notin \text{epi}(f)\)인 \(\bar{x}\)가 있다고 가정합니다.
  • Theorem 14.12의 분리 초평면을 적용하면 \(\alpha \in \mathbb{R}^d\), \(\gamma > 0\), \(\delta > 0\)이 존재하여: \[ \inf_{(x,t) \in \text{epi}(f)} \{(\alpha/\gamma)^\top(x - \bar{x}) + t - f^{**}(\bar{x})\} \geq \delta/\gamma > 0. \]
  • 그런데 Fenchel-Young 부등식으로 이 하한이 \(\leq 0\)임을 보여 모순을 유도합니다. \(\square\)

3.3 Moreau Decomposition (Moreau 분해)

부분미분과 켤레의 관계

이차 함수 \(f(x) = \frac{1}{2}x^\top Q x + p^\top x\)에서 \(\nabla f^*(y) = (\nabla f)^{-1}(y)\)가 성립함을 확인했습니다. 이 관계는 일반적으로 부분미분(subdifferential)의 역사상 관계로 확장됩니다.

Theorem 14.14. 폐쇄 볼록 함수 \(f: \mathbb{R}^d \to \mathbb{R}\)에 대해 다음 세 명제는 서로 동치(equivalent)입니다.

  • (i) \(y \in \partial f(x)\)
  • (ii) \(x \in \partial f^*(y)\)
  • (iii) \(y^\top x = f(x) + f^*(y)\) (Fenchel-Young 부등식에서 등호 성립)

증명 핵심 ((i) \(\Rightarrow\) (iii) \(\Rightarrow\) (ii)):

\(\bar{y} \in \partial f(\bar{x})\)이면 \(\bar{x}\)가 \(\inf_x\{-\bar{y}^\top x + f(x)\}\)의 최솟값이므로: \[ f^*(\bar{y}) = \bar{y}^\top \bar{x} - f(\bar{x}). \] 따라서 (iii) 성립. (iii)에서 \(f^*(y) \geq y^\top \bar{x} - f(\bar{x}) = (y - \bar{y})^\top \bar{x} + f^*(\bar{y})\)이므로 \(\bar{x} \in \partial f^*(\bar{y})\), 즉 (ii) 성립.

\(f\)가 폐쇄 볼록이면 \(f^{**} = f\)이므로 대칭 논리로 (ii) \(\Rightarrow\) (iii) \(\Rightarrow\) (i)도 성립. \(\square\)

Moreau 분해 정리

Theorem 14.15 (Moreau Decomposition). 폐쇄 볼록 함수 \(f: \mathbb{R}^d \to \mathbb{R}\)에 대해:

\[ \boxed{x = \text{prox}_f(x) + \text{prox}_{f^*}(x).} \]

증명:

\(u = \text{prox}_f(x)\)로 정의하면 (\(\text{prox}_f(x) = \arg\min_u\{f(u) + \frac{1}{2}\|u-x\|_2^2\}\)):

\[ x - u \in \partial f(u). \]

Theorem 14.14에 의해 \(u \in \partial f^*(x - u)\). \(v = x - u\)로 놓으면 \(x - v \in \partial f^*(v)\)이므로 \(v = \text{prox}_{f^*}(x)\). 따라서:

\[ \text{prox}_f(x) + \text{prox}_{f^*}(x) = u + v = u + (x - u) = x. \quad \square \]

직관적 해석:

  • 벡터 \(x\)는 \(f\)에 대한 근위 사영과 \(f^*\)에 대한 근위 사영으로 유일하게 분해됩니다.
  • 이는 직교 여공간에 대한 사영 분해의 일반화입니다.

Example 14.16: 선형 부분공간의 경우

\(V \subseteq \mathbb{R}^d\)가 선형 부분공간이고, \(f = I_V\) (지시 함수, indicator function)라 하면:

\[ f^*(y) = \sup_{x \in V} y^\top x = I_{V^\perp}(y). \]

  • \(y \in V^\perp\)이면 \(y^\top x = 0\) for all \(x \in V\)이므로 \(f^*(y) = 0\).
  • \(y \notin V^\perp\)이면 \(\sup = +\infty\).

근위 연산자를 계산하면:

\[ \text{prox}_f(x) = \arg\min_{u \in \mathbb{R}^d}\left\{I_V(u) + \frac{1}{2}\|u-x\|_2^2\right\} = \text{proj}_V(x), \]

\[ \text{prox}_{f^*}(x) = \arg\min_{u \in \mathbb{R}^d}\left\{I_{V^\perp}(u) + \frac{1}{2}\|u-x\|_2^2\right\} = \text{proj}_{V^\perp}(x). \]

따라서 Moreau 분해 정리는 다음과 같이 됩니다:

\[ x = \text{proj}_V(x) + \text{proj}_{V^\perp}(x). \]

이는 선형대수에서 잘 알려진 직교 분해 정리와 완전히 일치합니다. Moreau 분해는 이를 일반적인 볼록 함수로 확장한 것입니다.
