이번 강의에서는 제약 최적화 문제를 다루는 데 있어 가장 핵심적인 이론적 도구들을 학습합니다. 구체적으로 다루는 주제는 다음과 같습니다.

  • 안장점 문제(Saddle Point Problem): 최소-최대 구조를 가진 최적화 문제와 Primal-Dual 알고리즘

2. KKT 조건 (Karush-Kuhn-Tucker Conditions)

2.1 왜 KKT 조건이 필요한가?

우리는 이미 볼록 집합 \(C\)와 미분 가능한 함수 \(f\)에 대해 다음을 알고 있습니다.

\[x^* \text{가 } \min_{x \in C} f(x) \text{의 최적해} \iff \nabla f(x^*)^\top (x - x^*) \geq 0 \quad \forall x \in C.\]

그러나 이 조건은 집합 \(C\)의 구조가 복잡할 경우 검증이 매우 어렵습니다. KKT 조건은 제약 조건을 명시적으로 활용하여 최적성을 보다 실용적으로 판별할 수 있게 해주는 대안적 접근법입니다.

2.1 선형 제약 조건 (Linear Constraints)

먼저 가장 단순한 형태인 선형 제약 문제를 살펴봅니다.

\[ \begin{aligned} \text{minimize} \quad & f(x) \\ \text{subject to} \quad & Ax \leq b \\ & Cx = d \end{aligned} \tag{16.1} \]

여기서 \(A \in \mathbb{R}^{m \times d}\), \(b \in \mathbb{R}^m\), \(C \in \mathbb{R}^{\ell \times d}\), \(d \in \mathbb{R}^\ell\) 입니다.

정리 16.1 — 선형 제약 문제의 KKT 조건

[필요조건] \(x^*\)가 문제 (16.1)의 실현 가능해(feasible solution)이고 \(f(x^*)\)가 국소 최솟값(local minimum)이라면, 다음을 만족하는 \(\lambda^* \in \mathbb{R}^m_+\) 와 \(\mu^* \in \mathbb{R}^\ell\) 이 존재합니다.

\[ \nabla f(x^*)^\top + \lambda^{*\top} A + \mu^{*\top} C = 0 \quad \text{and} \quad \lambda^{*\top}(Ax^* - b) = 0. \tag{$\star$} \]

[충분조건] \(f\)가 볼록 함수이고, \(x^*\)가 실현 가능해이며, 위 조건 (\(\star\))를 만족하는 \(\lambda^* \in \mathbb{R}^m_+\)와 \(\mu^* \in \mathbb{R}^\ell\) 이 존재한다면, \(x^*\)는 문제 (16.1)의 전역 최적해(global optimal solution)입니다.

KKT 조건 (\(\star\))에 담긴 두 가지 요소를 살펴봅시다.

  • Stationarity: \(\nabla f(x^*)^\top + \lambda^{*\top} A + \mu^{*\top} C = 0\) — 라그랑지안의 기울기가 0이어야 합니다.
  • Complementary Slackness: \(\lambda^{*\top}(Ax^* - b) = 0\) — 각 \(i\)에 대해 \(\lambda^*_i > 0\)이면 반드시 \(a_i^\top x^* = b_i\) (해당 부등식이 등호 활성화), \(a_i^\top x^* < b_i\)이면 반드시 \(\lambda^*_i = 0\)이어야 합니다. 이를 상보적 여유(Complementary Slackness)라 부릅니다.

2.2 일반 볼록 제약 조건 (General Convex Constraints)

이제 보다 일반적인 형태로 확장합니다.

\[ \begin{aligned} \text{minimize} \quad & f(x) \\ \text{subject to} \quad & g_i(x) \leq 0, \quad i = 1, \ldots, m \\ & h_j(x) = 0, \quad j = 1, \ldots, \ell \end{aligned} \tag{16.2} \]

여기서 \(f\)와 \(g_1, \ldots, g_m\)은 볼록 함수, \(h_1, \ldots, h_\ell\)은 어파인(affine) 함수입니다.

정의 16.2 — Slater 조건 (Slater’s Condition)

\(g_1, \ldots, g_k\)는 어파인, \(g_{k+1}, \ldots, g_m\)은 어파인이 아닌 볼록 함수라 할 때, 다음 조건을 만족하는 \(\bar{x}\)가 존재하면 문제 (16.2)는 Slater 조건을 만족한다고 말합니다.

\[ g_i(\bar{x}) \leq 0 \text{ for } i = 1, \ldots, k, \quad g_i(\bar{x}) < 0 \text{ for } i = k+1, \ldots, m, \quad h_j(\bar{x}) = 0 \text{ for } j = 1, \ldots, \ell. \]

직관적으로 Slater 조건은 내부점(interior point)이 존재함을 보장합니다. 비선형 부등식 제약의 경우, 경계가 아닌 실내 실현 가능 영역이 있다는 것을 의미하며, 이를 통해 강 쌍대성(Strong Duality)이 성립함을 보장할 수 있습니다.

정리 16.3 — 볼록 제약 문제의 KKT 조건

[필요조건] Slater 조건이 만족되고, \(x^*\)가 최적 실현 가능해라면, 다음을 만족하는 \(\lambda^* \in \mathbb{R}^m_+\)와 \(\mu^* \in \mathbb{R}^\ell\) 이 존재합니다.

\[ \nabla f(x^*) + \sum_{i=1}^m \lambda^*_i \nabla g_i(x^*) + \sum_{j=1}^\ell \mu^*_j \nabla h_j(x^*) = 0 \quad \text{and} \quad \lambda^*_i g_i(x^*) = 0 \text{ for all } i. \tag{$\star\star$} \]

[충분조건] \(x^*\)가 실현 가능해이고, 위 조건 (\(\star\star\))를 만족하는 \(\lambda^* \in \mathbb{R}^m_+\)와 \(\mu^* \in \mathbb{R}^\ell\) 이 존재한다면, \(x^*\)는 최적해입니다.

KKT 조건 (\(\star\star\))는 다음 네 가지 요소로 구성됩니다.

  1. Stationarity: 라그랑지안의 기울기가 0
  2. Primal Feasibility: \(g_i(x^*) \leq 0\), \(h_j(x^*) = 0\)
  3. Dual Feasibility: \(\lambda^* \geq 0\)
  4. Complementary Slackness: \(\lambda^*_i g_i(x^*) = 0\)

핵심 포인트: 볼록 문제에서 Slater 조건이 만족되면, KKT 조건은 최적성의 필요충분조건이 됩니다.

3. 안장점 문제 (Saddle Point Problem)

안장점 문제의 출발점

다음 부등식 제약 최소화 문제를 생각합니다.

\[ \text{minimize}_{x} \quad f(x) \quad \text{subject to} \quad g_i(x) \leq 0, \quad i = 1, \ldots, m. \tag{16.3} \]

라그랑지안(Lagrangian)을 \(L(x, \lambda) = f(x) + \sum_{i=1}^m \lambda_i g_i(x)\)로 정의하면, 다음이 성립합니다.

\[ \max_{\lambda \geq 0} L(x, \lambda) = \begin{cases} f(x) & \text{if } g_i(x) \leq 0 \text{ for all } i \\ +\infty & \text{if } g_i(x) > 0 \text{ for some } i \end{cases} \]

  • \(g_i(x) > 0\)인 제약이 하나라도 있다면, \(\lambda_i \to +\infty\)로 보냄으로써 \(L(x, \lambda)\)를 무한히 크게 만들 수 있습니다.
  • \(g_i(x) \leq 0\)이 모든 \(i\)에 대해 만족되면, \(\max_{\lambda \geq 0} L(x, \lambda)\)는 \(\lambda = 0\)에서 달성되어 \(f(x)\)와 같아집니다.

이로부터 다음이 성립합니다.

\[ \min_x \max_{\lambda \geq 0} L(x, \lambda) = \min_x \{f(x) : g_i(x) \leq 0 \text{ for all } i\}. \]

즉, 원래의 제약 최소화 문제는 Primal 문제 \(\min_x \max_{\lambda \geq 0} L(x, \lambda)\)와 동일합니다.

반면, 라그랑지안 쌍대 문제(Lagrangian dual)는 \(q(\lambda) = \min_x L(x, \lambda)\)를 정의할 때 \(\max_{\lambda \geq 0} q(\lambda)\)를 구하는 것입니다.

약 쌍대성(Weak Duality) 정리는 다음을 보장합니다.

\[ \min_x \max_{\lambda \geq 0} L(x, \lambda) \geq \max_{\lambda \geq 0} \min_x L(x, \lambda). \]

강 쌍대성(Strong Duality)이 성립하면 등호가 성립합니다.

\[ \min_x \max_{\lambda \geq 0} L(x, \lambda) = \max_{\lambda \geq 0} \min_x L(x, \lambda). \]

이 구조가 바로 안장점 문제(Saddle Point Problem)의 핵심입니다.

3.1 영합 게임 (Zero-Sum Game)

안장점 문제의 직관적인 예시로 영합 게임(Zero-Sum Game)을 살펴봅니다.

게임 설정

  • Player 1: \(d\)가지 전략 \(i \in [d]\) 중 하나를 선택
  • Player 2: \(m\)가지 전략 \(j \in [m]\) 중 하나를 선택
  • Player 1이 전략 \(i\)를, Player 2가 전략 \(j\)를 선택하면, Player 1은 \(a_{ij}\)를 잃고 Player 2는 \(a_{ij}\)를 얻습니다.

두 플레이어는 혼합 전략(mixed strategy)을 사용할 수 있습니다.

  • Player 1: \(x \in \Delta_d = \{x \in [0,1]^d : \mathbf{1}^\top x = 1\}\)
  • Player 2: \(y \in \Delta_m = \{y \in [0,1]^m : \mathbf{1}^\top y = 1\}\)

이때 기댓값으로 Player 1의 손실(= Player 2의 이득)은 \(x^\top A y\)입니다.

미니맥스 정리 (von Neumann’s Minimax Theorem)

Player 2의 전략 \(y\)가 주어졌을 때, Player 1은 손실을 최소화하려 합니다. Player 2는 이를 알고 자신의 이득을 극대화하려 합니다. 이때 누가 먼저 전략을 정하느냐에 상관없이 균형이 동일함을 von Neumann의 미니맥스 정리가 보장합니다.

\[ \max_{y \in \Delta_m} \min_{x \in \Delta_d} x^\top A y = \min_{x \in \Delta_d} \max_{y \in \Delta_m} x^\top A y. \]

이 결과는 선형 함수 \(x^\top A y\)가 \(x\)에 대해 선형(볼록), \(y\)에 대해 선형(오목)이기 때문에 성립합니다.

3.2 안장점 최적성 (Saddle Point Optimality)

이제 일반적인 함수 \(\varphi(x, y)\) — \(x\)에 대해서는 볼록, \(y\)에 대해서는 오목 — 에 대한 안장점 문제를 정형화합니다.

\[ \min_{x \in X} \max_{y \in Y} \varphi(x, y) \tag{16.4} \]

여기서 \(X\)와 \(Y\)는 볼록 집합입니다.

정리 16.4 — 약 쌍대성 (Weak Duality)

\[ \min_{x \in X} \max_{y \in Y} \varphi(x, y) \geq \max_{y \in Y} \min_{x \in X} \varphi(x, y). \]

증명 스케치:

임의의 \((x, y) \in X \times Y\)에 대해 \(\varphi(x, y) \geq \min_{x \in X} \varphi(x, y)\)이 성립합니다. 양변에 \(y\)에 대한 최댓값을 취하면,

\[\max_{y \in Y} \varphi(x, y) \geq \max_{y \in Y} \min_{x \in X} \varphi(x, y).\]

이 부등식은 모든 \(x \in X\)에 대해 성립하므로, 좌변에 \(x\)에 대한 최솟값을 취하더라도 부등식이 유지됩니다. \(\square\)

안장점의 정의

\((x^*, y^*) \in X \times Y\)가 다음을 만족하면 안장점(Saddle Point)이라 합니다.

\[\varphi(x^*, y) \leq \varphi(x^*, y^*) \leq \varphi(x, y^*) \quad \forall (x, y) \in X \times Y.\]

즉, \(y^*\)를 고정하면 \(x^*\)는 최소화 방향, \(x^*\)를 고정하면 \(y^*\)는 최대화 방향에서 최적이라는 의미입니다. 안장점이 존재하면 다음이 성립합니다.

\[\varphi(x^*, y^*) = \max_{y \in Y} \varphi(x^*, y) = \min_{x \in X} \varphi(x, y^*).\]

정리 16.5 — 안장점과 강 쌍대성

\((x^*, y^*)\)가 안장점이면 다음이 성립합니다.

\[ \min_{x \in X} \max_{y \in Y} \varphi(x, y) = \varphi(x^*, y^*) = \max_{y \in Y} \min_{x \in X} \varphi(x, y). \]

증명 스케치:

안장점의 정의로부터 \(\max_{y \in Y} \varphi(x^*, y) \leq \varphi(x^*, y^*) \leq \min_{x \in X} \varphi(x, y^*)\)이므로,

\[\min_{x \in X} \max_{y \in Y} \varphi(x, y) \leq \varphi(x^*, y^*) \leq \max_{y \in Y} \min_{x \in X} \varphi(x, y).\]

정리 16.4의 약 쌍대성(반대 방향 부등식)과 결합하면 세 값이 모두 같아야 합니다. \(\square\)

Primal/Dual 관점과 \(\epsilon\)-안장점

안장점 문제는 다음 두 최적화 문제를 결합합니다.

  • Primal 문제: \(\min_{x \in X} \hat{\varphi}(x) := \max_{y \in Y} \varphi(x, y)\)
  • Dual 문제: \(\max_{y \in Y} \check{\varphi}(y) := \min_{x \in X} \varphi(x, y)\)

임의의 \((\bar{x}, \bar{y})\)에 대해, 이중 간격(Duality Gap)을 다음과 같이 정의합니다.

\[0 \leq \hat{\varphi}(\bar{x}) - \check{\varphi}(\bar{y}) = \max_{y \in Y} \varphi(\bar{x}, y) - \min_{x \in X} \varphi(x, \bar{y}).\]

\((\bar{x}, \bar{y})\)가 \(\epsilon\)-안장점이라는 것은 이 이중 간격이 \(\epsilon\) 이하임을 의미합니다.

\[0 \leq \max_{y \in Y} \varphi(\bar{x}, y) - \min_{x \in X} \varphi(x, \bar{y}) \leq \epsilon.\]

\((\bar{x}, \bar{y})\)가 \(\epsilon\)-안장점이면, 다음이 성립합니다.

  • \(\hat{\varphi}(\bar{x}) - \min_{x \in X} \hat{\varphi}(x) \leq \epsilon\) (Primal 근사 오차 \(\leq \epsilon\))
  • \(\max_{y \in Y} \check{\varphi}(y) - \check{\varphi}(\bar{y}) \leq \epsilon\) (Dual 근사 오차 \(\leq \epsilon\))

3.3 안장점 문제를 위한 Primal-Dual 알고리즘

알고리즘 동기

안장점 문제를 직접 푸는 방법을 생각해 봅시다. Primal 변수 \(x\)와 Dual 변수 \(y\)를 동시에 업데이트하는 것이 핵심 아이디어입니다.

  • \(x\)는 \(\varphi(\cdot, y)\)를 최소화하는 방향(부분기울기의 음의 방향)으로 이동
  • \(y\)는 \(\varphi(x, \cdot)\)를 최대화하는 방향(부분기울기의 양의 방향)으로 이동

알고리즘 1 — Primal-Dual 부분기울기법 (Primal-Dual Subgradient Method)

NoteAlgorithm 1: Primal-Dual Subgradient Method

초기화: \(x_1 \in X\), \(y_1 \in Y\)

for \(t = 1, \ldots, T-1\) do

  1. \(g_{x,t} \in \partial_x \varphi(x_t, y_t)\) 및 \(g_{y,t} \in \partial_y \varphi(x_t, y_t)\) 계산
    • \(\partial_x \varphi\): 고정된 \(y\)에 대한 \(\varphi\)의 부분미분(subdifferential)
    • \(\partial_y \varphi\): 고정된 \(x\)에 대한 \(\varphi\)의 상부분미분(superdifferential)
  2. 업데이트: \[x_{t+1} = \text{proj}_X(x_t - \eta_t g_{x,t})\] \[y_{t+1} = \text{proj}_Y(y_t + \eta_t g_{y,t})\]

end for

반환: \(x_{T+1}\)

\(x\)는 기울기를 빼고(최소화), \(y\)는 기울기를 더합니다(최대화). 투영(projection)은 해가 실현 가능 집합 \(X\), \(Y\)를 벗어나지 않도록 보장합니다.

정리 16.6 — Primal-Dual 부분기울기법의 수렴 보장

가중 평균을 다음과 같이 정의합니다.

\[\bar{x}_T = \left(\sum_{t=1}^T \eta_t\right)^{-1} \sum_{t=1}^T \eta_t x_t, \qquad \bar{y}_T = \left(\sum_{t=1}^T \eta_t\right)^{-1} \sum_{t=1}^T \eta_t y_t.\]

그러면 임의의 \((x, y) \in X \times Y\)에 대해 다음이 성립합니다.

\[ \varphi(\bar{x}_T, y) - \varphi(x, \bar{y}_T) \leq \frac{1}{2 \sum_{t=1}^T \eta_t} \left( \|(x_1, y_1) - (x, y)\|_2^2 + \sum_{t=1}^T \eta_t^2 \|(g_{x,t}, g_{y,t})\|_2^2 \right). \]

상수 스텝 사이즈 설정: 모든 부분기울기에 대해 \(\|(g_x, g_y)\|_2^2 \leq L^2\)이고 \(\|(x_1, y_1) - (x, y)\|_2^2 \leq R^2\)이 보장될 때, \(\eta_t = R / (L\sqrt{T})\)로 설정하면 다음이 성립합니다.

\[ \varphi(\bar{x}_T, y) - \varphi(x, \bar{y}_T) \leq \frac{LR}{\sqrt{T}}. \]

특히 이중 간격(duality gap)에 대해서,

\[ \max_{y \in Y} \varphi(\bar{x}_T, y) - \min_{x \in X} \varphi(x, \bar{y}_T) \leq \frac{LR}{\sqrt{T}}. \]

  • \(T = O(1/\epsilon^2)\)으로 설정하면 \((\bar{x}_T, \bar{y}_T)\)는 \(\epsilon\)-안장점이 됩니다.
  • 이는 부분기울기법의 표준적인 \(O(1/\sqrt{T})\) 수렴률과 동일합니다.

핵심 포인트: 단순히 현재 반복점 \((x_t, y_t)\)를 반환하는 것이 아니라, 가중 평균 \((\bar{x}_T, \bar{y}_T)\)를 반환해야 수렴이 보장됩니다.

4. Fenchel 켤레 기반 라그랑지안 쌍대성 (Lagrangian Duality via Fenchel Conjugate)

쌍대 함수의 켤레 표현

다음 문제를 고려합니다.

\[ \begin{aligned} \text{minimize} \quad & f(x) \\ \text{subject to} \quad & Ax = b \\ & Cx \leq d \end{aligned} \tag{16.5} \]

라그랑지안 쌍대 함수(Lagrangian dual function)를 켤레 함수(Fenchel conjugate)로 표현하면 유용한 구조를 발견할 수 있습니다.

\[ q(\lambda, \mu) = \min_x \left\{ f(x) + \lambda^\top(Cx - d) + \mu^\top(Ax - b) \right\} \]

이를 단계적으로 변환합니다.

\[ \begin{aligned} q(\lambda, \mu) &= -d^\top \lambda - b^\top \mu + \min_x \left\{ f(x) + (C^\top \lambda + A^\top \mu)^\top x \right\} \\ &= -d^\top \lambda - b^\top \mu - \sup_x \left\{ -f(x) - (C^\top \lambda + A^\top \mu)^\top x \right\} \\ &= -d^\top \lambda - b^\top \mu - f^*(-C^\top \lambda - A^\top \mu) \end{aligned} \]

여기서 Fenchel 켤레 함수(Fenchel conjugate)는 \(f^*(v) = \sup_x \{v^\top x - f(x)\}\)로 정의됩니다.

핵심 통찰: 쌍대 함수가 켤레 함수 \(f^*\)를 통해 명시적으로 표현됩니다. 이는 켤레 함수의 볼록성으로 인해 쌍대 문제가 항상 볼록 문제임을 보장합니다.

등호 제약만 있는 경우

부등식 제약이 없는 경우(\(Cx \leq d\) 제거), 쌍대 함수와 쌍대 문제는 다음과 같이 단순화됩니다.

\[q(\mu) = -b^\top \mu - f^*(-A^\top \mu)\]

\[ \text{쌍대 문제:} \quad \max_\mu \left\{ -b^\top \mu - f^*(-A^\top \mu) \right\} \tag{16.6} \]

이를 최소화 문제로 변환하면 다음과 같이 표현됩니다.

\[\text{minimize} \quad f^*(-A^\top \mu) + b^\top \mu.\]

\(f^*\)는 볼록 함수이므로, 이 쌍대 문제는 볼록 최소화 문제입니다.

4.1 쌍대 경사법 (Dual Gradient Method)

부분기울기법을 쌍대 문제에 적용

이제 쌍대 문제 \(\min_\mu \{f^*(-A^\top \mu) + b^\top \mu\}\)에 부분기울기법(subgradient method)을 적용합니다.

주어진 \(\mu_t\)에서 부분기울기 \(g_t \in \partial \{f^*(-A^\top \mu_t) + b^\top \mu_t\}\)를 구해야 합니다.

부분기울기 계산: 연쇄 법칙

\[ \partial \left\{ f^*(-A^\top \mu) + b^\top \mu \right\} \bigg|_{\mu = \mu_t} = -A \cdot \partial f^*(-A^\top \mu_t) + b \]

따라서,

\[g_t = -Ax_t + b \quad \text{for some } x_t \in \partial f^*(-A^\top \mu_t).\]

\(x_t\)의 의미: 라그랑지안 최소화

\(x_t \in \partial f^*(-A^\top \mu_t)\)는 켤레 함수의 부분미분 관계에 의해 다음과 동치입니다.

\[-A^\top \mu_t \in \partial f(x_t) \iff 0 \in \partial f(x_t) + A^\top \mu_t \iff x_t \in \underset{x}{\text{argmin}} \left\{ f(x) + \mu_t^\top A x \right\}.\]

\(\mu_t^\top b\)는 \(x\)와 무관한 상수이므로, 이는 다음과 동치입니다.

\[x_t \in \underset{x}{\text{argmin}} \left\{ f(x) + \mu_t^\top (Ax - b) \right\} = \underset{x}{\text{argmin}} L(x, \mu_t).\]

즉, \(x_t\)는 라그랑지안 \(L(x, \mu_t)\)의 최소화 해입니다.

알고리즘 2 — 쌍대 문제에 대한 부분기울기법

NoteAlgorithm 2: Subgradient Method for the Dual Problem

초기화: \(\mu_1\)

for \(t = 1, \ldots, T-1\) do

  1. Primal 업데이트: 라그랑지안을 최소화하여 \(x_t\)를 구합니다. \[x_t \in \underset{x}{\text{argmin}} \left\{ f(x) + \mu_t^\top (Ax - b) \right\}\]
  2. Dual 업데이트: 쌍대 부분기울기 \(Ax_t - b\)를 이용하여 \(\mu_t\)를 업데이트합니다. \[\mu_{t+1} = \mu_t + \eta_t (Ax_t - b)\]

end for

직관적 해석:

  • \(Ax_t - b\)는 제약 위반(constraint violation)의 정도를 나타냅니다.
    • \(Ax_t > b\)이면 제약이 위반되었으므로 \(\mu\)를 증가시켜 다음 반복에서 해당 제약에 더 높은 페널티를 부여합니다.
    • \(Ax_t < b\)이면 반대로 \(\mu\)를 감소시킵니다.
  • 각 반복에서 제약 없는 최적화 문제(라그랑지안 최소화)를 풀면 되므로, 복잡한 제약 구조를 가진 원래 문제를 다루기 훨씬 쉬워집니다.

왜 쌍대 접근법이 유용한가? 원래 문제에 복잡한 제약 조건이 있을 때, 쌍대 문제는 이 제약을 목적함수에 흡수시켜 각 반복에서 제약 없는 최적화만 수행하면 됩니다. 제약 없는 최적화는 일반적으로 훨씬 다루기 쉽습니다.
