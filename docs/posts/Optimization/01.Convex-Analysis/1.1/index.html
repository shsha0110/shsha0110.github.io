들어가며 (Overview)

최적화 문제를 풀 때 우리가 가장 먼저 던지는 질문은 “이 문제가 얼마나 다루기 쉬운가”입니다. 일반적인 비선형 최적화는 지역 최솟값(local minimum)과 전역 최솟값(global minimum)이 다를 수 있어 본질적으로 어렵습니다. 그러나 볼록(convex) 구조를 가진 문제에서는 “지역 최솟값이 곧 전역 최솟값”이라는 강력한 성질이 성립하고, 효율적인 알고리즘과 풍부한 쌍대성(duality) 이론이 따라옵니다.

이 강의에서는 그 출발점이 되는 다음 네 가지를 다룹니다.

  • 볼록 집합 (Convex sets)
  • 볼록 함수와 그 성질 (Convex functions and properties)
  • 볼록 함수의 1차·2차 특성화 (First-order and second-order characterizations)
  • 볼록성을 보존하는 연산 (Operations preserving convexity)

핵심 직관은 단 하나, “두 점을 이은 선분(line segment)” 입니다. 집합이든 함수든, “임의의 두 점을 이어보았을 때 무엇이 어디에 놓이는가”라는 질문 하나로 볼록성을 판별하게 됩니다.

1. 볼록 집합 (Convex Sets)

1.1 정의 (Definition)

볼록 집합의 정의

가장 기본이 되는 정의부터 시작하겠습니다.

정의 1.1 (Convex set). 집합 \(X \subseteq \mathbb{R}^d\) 가 볼록(convex) 하다는 것은, 임의의 \(u, v \in X\) 와 임의의 \(\lambda \in [0, 1]\) 에 대해 \[ \lambda u + (1 - \lambda) v \in X \] 이 성립함을 의미합니다.

  • 직관적으로, 집합에 속한 임의의 두 점을 이은 선분이 통째로 집합 안에 들어 있으면 그 집합은 볼록합니다.
  • 여기서 \(\lambda u + (1-\lambda)v\) 는 \(\lambda\) 가 \(0\) 에서 \(1\) 로 움직임에 따라 \(v\) 에서 \(u\) 로 이동하는 점을 나타냅니다. 즉 \(\{\lambda u + (1-\lambda)v : 0 \le \lambda \le 1\}\) 은 두 점 \(u, v\) 를 잇는 선분 그 자체입니다.

볼록 결합 (Convex combination)

선분이라는 개념을 두 점에서 여러 점으로 일반화한 것이 볼록 결합입니다.

정의 1.2 (Convex combination). 벡터 \(v^1, \dots, v^k \in \mathbb{R}^d\) 가 주어졌을 때, 선형 결합 \(\lambda_1 v^1 + \cdots + \lambda_k v^k\) 가 \[ \sum_{i=1}^{k} \lambda_i = 1 \quad \text{그리고} \quad \lambda_i \ge 0 \;\; (i = 1, \dots, k) \] 를 만족하면, 이를 \(v^1, \dots, v^k\) 의 볼록 결합(convex combination) 이라 부릅니다.

  • 계수 \(\lambda_i\) 가 모두 음이 아니고(non-negative), 합이 정확히 1 이라는 두 조건이 핵심입니다. 이는 확률분포의 조건(\(p_i \ge 0\), \(\sum p_i = 1\))과 동일하며, 볼록 결합을 점들의 “가중 평균(weighted average)”으로 해석할 수 있게 해 줍니다.
  • 두 점 \(u, v\) 의 볼록 결합 전체는 앞서 본 선분 \(\{\lambda u + (1-\lambda)v : 0 \le \lambda \le 1\}\) 과 정확히 일치합니다.

볼록 껍질 (Convex hull)

정의 1.3 (Convex hull). 집합 \(X\) 의 볼록 껍질(convex hull) \(\operatorname{conv}(X)\) 는 \(X\) 의 점들로 만들 수 있는 모든 볼록 결합의 집합으로 정의됩니다. \[ \operatorname{conv}(X) = \left\{ \sum_{i=1}^{n} \lambda_i v^i \;:\; n \in \mathbb{N},\; v^1, \dots, v^n \in X,\; \sum_{i=1}^{n} \lambda_i = 1,\; \lambda_1, \dots, \lambda_n \ge 0 \right\}. \]

  • \(\operatorname{conv}(X)\) 는 \(X\) 가 볼록하든 아니든 항상 볼록한 집합입니다. 직관적으로 \(X\) 를 감싸는 “가장 작은 볼록 집합”이라고 생각할 수 있습니다 (고무줄로 점들을 둘러쌌을 때 만들어지는 영역을 떠올리면 좋습니다).

1.2 원뿔과 아핀 부분공간 (Cones and Affine Subspaces)

볼록 결합에서 “계수의 합이 1”이라는 제약을 풀거나 “비음수”라는 제약을 푸는 방식에 따라 서로 다른 기하학적 대상이 등장합니다.

원뿔 (Cone)

정의 1.4 (Cone). 집합 \(C \subseteq \mathbb{R}^d\) 가 원뿔(cone) 이라는 것은, 임의의 \(v \in C\) 와 임의의 \(\alpha > 0\) 에 대해 \(\alpha v \in C\) 가 성립함을 의미합니다. 더 나아가 \(C\) 가 볼록하기까지 하면, 이를 볼록 원뿔(convex cone) 이라 부릅니다.

  • 원뿔은 원점에서 출발하는 반직선(ray)을 따라 무한히 뻗어 나가는 성질을 가집니다. 모든 원뿔이 볼록한 것은 아니라는 점에 유의해야 합니다 (예: 서로 떨어진 두 반직선의 합집합은 원뿔이지만 볼록하지 않습니다).

원뿔 결합과 원뿔 껍질 (Conic combination & conic hull)

정의 1.5 (Conic combination). 벡터 \(v^1, \dots, v^k \in \mathbb{R}^d\) 에 대해, \(\alpha_1 v^1 + \cdots + \alpha_k v^k\) 형태의 점이 \(\alpha_1, \dots, \alpha_k \ge 0\) 을 만족하면 이를 원뿔 결합(conic combination) 이라 합니다.

  • 즉, 임의의 비음수 선형 결합(nonnegative linear combination) 이 곧 원뿔 결합입니다. 볼록 결합과 비교하면 “합이 1”이라는 제약이 사라진 형태입니다.

정의 1.6 (Conic hull). 집합 \(X\) 의 원뿔 껍질(conic hull) \(\operatorname{cone}(X)\) 는 \(X\) 의 점들로 만들 수 있는 모든 원뿔 결합의 집합입니다. \[ \operatorname{cone}(X) = \left\{ \sum_{i=1}^{n} \alpha_i v^i \;:\; n \in \mathbb{N},\; v^1, \dots, v^n \in X,\; \alpha_1, \dots, \alpha_n \ge 0 \right\}. \]

  • \(\operatorname{conv}(X)\) 와 마찬가지로 \(\operatorname{cone}(X)\) 역시 항상 볼록합니다.

아핀 결합과 아핀 부분공간 (Affine combination & affine subspace)

정의 1.7 (Affine combination). 벡터 \(v^1, \dots, v^k \in \mathbb{R}^d\) 에 대해, \(\theta_1 v^1 + \cdots + \theta_k v^k\) 형태의 점이 \(\theta_1 + \cdots + \theta_k = 1\) 을 만족하면 이를 아핀 결합(affine combination) 이라 합니다.

  • 볼록 결합과 달리, 아핀 결합은 음수 계수(negative multipliers)를 허용합니다. 계수의 합이 1이라는 조건만 유지하고 비음수 조건은 버린 형태입니다.

정의 1.8 (Affine hull). 집합 \(X\) 의 아핀 껍질(affine hull) 은 \(X\) 의 점들로 만들 수 있는 모든 아핀 결합의 집합이며, \(X\) 가 생성하는 아핀 부분공간(affine subspace spanned by \(X\)) 이라고도 부릅니다.

  • 이전 강의에서 유한개의 벡터가 생성하는 선형 부분공간(linear subspace) 을 정의했는데, 이를 임의의 집합으로 확장한 것이 선형 껍질(linear hull) 이며, 이는 \(X\) 가 생성하는 선형 부분공간과 동일합니다.

이제 네 가지 “껍질”의 관계를 한눈에 비교해 보겠습니다.

마지막으로, 아핀 부분공간의 대수적 표현에 대한 정리입니다.

정리 1.9. 아핀 부분공간은 선형 부분공간의 평행이동(translation) 입니다. 즉, 아핀 부분공간 \(V \subseteq \mathbb{R}^d\) 에 대해 적절한 행렬 \(A\) 와 벡터 \(b\) 가 존재하여 \[ V = \{ x \in \mathbb{R}^d : A x = b \} \] 로 표현됩니다.

  • 이는 연립 일차방정식의 해집합이 곧 아핀 부분공간임을 뜻합니다. 만약 \(b = 0\) 이라면 원점을 지나는 선형 부분공간이 되고, \(b \ne 0\) 인 경우 그 부분공간이 원점에서 벗어나 평행이동된 형태가 됩니다.

1.3 예시 (Examples)

앞에서 본 볼록 껍질·원뿔 껍질·아핀(선형) 부분공간은 모두 볼록 집합의 예시였습니다. 이 외에도 자주 등장하는 볼록 집합들을 정리합니다.

볼록 집합의 예시

  1. 공집합(empty set) 과 한원소 집합(singleton) \(\{v\}\).
  2. 노름 공(Norm ball): \(\{ x \in \mathbb{R}^d : \|x - c\| \le r \}\). 여기서 \(c\) 는 중심, \(r\) 은 반지름입니다.
  3. 타원체(Ellipsoid): \(\{ x \in \mathbb{R}^d : (x - c)^\top P (x - c) \le 1 \}\). 여기서 \(P\) 는 양의 정부호(positive definite) 행렬이고 \(c\) 는 중심입니다.
  4. 초평면(Hyperplane): \(\{ x \in \mathbb{R}^d : a^\top x = b \}\), 단 \(a \in \mathbb{R}^d\), \(b \in \mathbb{R}\).
  5. 반공간(Half-space): \(\{ x \in \mathbb{R}^d : a^\top x \le b \}\), 단 \(a \in \mathbb{R}^d\), \(b \in \mathbb{R}\).
  6. 다면체(Polyhedron): 유한개의 반공간의 교집합으로, \(\{ x \in \mathbb{R}^d : A x \le b \}\) 형태입니다. 여기서 \(A \in \mathbb{R}^{m \times d}\), \(b \in \mathbb{R}^m\) 이며, \(A x \le b\) 는 각 행에 대한 부등식 \(a_k^\top x \le b_k\) (\(k \in [m]\)) 들을 한꺼번에 표기한 것입니다.
  7. 폴리토프(Polytope): 유계인(bounded) 다면체입니다. 동치로, 어떤 유한 벡터 집합의 볼록 껍질로도 정의할 수 있습니다.
  8. 심플렉스(Simplex): \(\{ x \in \mathbb{R}^d : \mathbf{1}^\top x = 1,\; x \ge 0 \}\) 형태의 집합으로, 표준 단위벡터 \(e^1, \dots, e^d\) 의 볼록 껍질과 같습니다. (확률 심플렉스, 즉 가능한 확률분포 전체의 집합이 대표적입니다.)
  9. 비음 직교공간(Nonnegative orthant): \(\mathbb{R}^d_+ = \{ x \in \mathbb{R}^d : x \ge 0 \}\).
  10. 양의 직교공간(Positive orthant): \(\mathbb{R}^d_{++} = \{ x \in \mathbb{R}^d : x > 0 \}\).

볼록 원뿔의 예시 (원뿔이면서 볼록한 집합)

  1. 노름 원뿔(Norm cone): \(\{ (x, t) \in \mathbb{R}^d \times \mathbb{R} : \|x\| \le t \}\). 노름이 유클리드 노름일 때 이를 특별히 2차 원뿔(second-order cone) 이라 부릅니다.
  2. 양의 준정부호 원뿔(Positive semidefinite cone): 고정된 차원의 모든 대칭 양의 준정부호(PSD) 행렬들의 집합입니다.

2. 볼록 함수 (Convex Functions)

2.1 정의 (Definition)

집합에서 함수로 시선을 옮기겠습니다. 함수의 볼록성은 “그래프가 아래로 볼록(밥그릇 모양)”하다는 직관에 대응합니다.

정의 1.10 (Convex function). 함수 \(f : \mathbb{R}^d \to \mathbb{R}\) 가 볼록(convex) 하다는 것은, 정의역 \(\operatorname{dom}(f)\) 가 볼록 집합이고, 모든 \(x, y \in \operatorname{dom}(f)\) 에 대해 \[ f(\lambda x + (1 - \lambda) y) \le \lambda f(x) + (1 - \lambda) f(y) \quad (0 \le \lambda \le 1) \] 이 성립함을 의미합니다.

  • 부등식의 의미를 풀어 보면, \(x\) 와 \(y\) 사이의 한 점에서 함수값 \(f(\lambda x + (1-\lambda)y)\) 이 두 점 \((x, f(x))\) 와 \((y, f(y))\) 를 잇는 직선(현, chord) 아래에 놓인다는 뜻입니다.
  • 정의역 \(\operatorname{dom}(f)\) 가 볼록해야 한다는 조건이 반드시 필요합니다. 그래야 \(\lambda x + (1-\lambda)y\) 도 정의역 안에 있어 \(f\) 의 값을 정의할 수 있기 때문입니다.

정의 1.11 (Concave function). 함수 \(f : \mathbb{R}^d \to \mathbb{R}\) 가 오목(concave) 하다는 것은 \(-f\) 가 볼록함을 의미합니다.

이어서, 볼록성의 강도를 세분화하는 두 개념을 봅니다.

정의 1.12. 함수 \(f : \mathbb{R}^d \to \mathbb{R}\) 가

  • 순볼록(strictly convex) 하다는 것은, \(\operatorname{dom}(f)\) 가 볼록이고 서로 다른 임의의 \(x, y \in \operatorname{dom}(f)\) 에 대해 \[ f(\lambda x + (1 - \lambda) y) < \lambda f(x) + (1 - \lambda) f(y) \quad (0 < \lambda < 1) \] 가 성립함을 의미합니다 (부등호가 등호 없는 강부등호 라는 점이 핵심).
  • 강볼록(strongly convex) 하다는 것은, 어떤 \(\alpha > 0\) 과 노름 \(\|\cdot\|\) 에 대해 \(f(x) - \alpha \|x\|^2\) 이 볼록함을 의미합니다.
  • 세 개념 사이에는 다음 포함 관계가 성립합니다. \[ \text{강볼록(strongly convex)} \;\Rightarrow\; \text{순볼록(strictly convex)} \;\Rightarrow\; \text{볼록(convex)} \]
  • 강볼록은 함수에서 “최소한 \(\alpha\|x\|^2\) 만큼의 곡률(이차항)”을 빼내도 여전히 볼록할 만큼, 그래프가 충분히 위로 휘어 있다는 뜻입니다. 이 성질은 이후 최적화 알고리즘의 수렴 속도 분석에서 결정적인 역할을 합니다.

2.2 예시 (Examples)

일변수 함수 (on \(\mathbb{R}\))

  • 지수함수: 임의의 \(a \in \mathbb{R}\) 에 대해 \(e^{ax}\) 는 볼록.
  • 거듭제곱 함수: \(a \ge 1\) 일 때 \(x^a\) 는 \(\mathbb{R}_+\) 에서 볼록이고, \(a < 0\) 일 때 \(x^a\) 는 \(\mathbb{R}_{++}\) 에서 볼록. 반면 \(0 \le a < 1\) 일 때 \(x^a\) 는 \(\mathbb{R}_+\) 에서 오목.
  • 로그함수: \(\log x\) 는 \(\mathbb{R}_{++}\) 에서 오목.
  • 음의 엔트로피(negative entropy): \(x \log x\) 는 \(\mathbb{R}_{++}\) 에서 볼록.

다변수 함수 (on \(\mathbb{R}^d\))

  • 선형함수: \(a^\top x + b\) (\(a \in \mathbb{R}^d\), \(b \in \mathbb{R}\))는 볼록인 동시에 오목합니다 (정의의 부등식이 항상 등호로 성립).
  • 이차함수: \(\tfrac{1}{2} x^\top A x + b^\top x + c\) 는 \(A \succeq 0\) (양의 준정부호), \(b \in \mathbb{R}^d\), \(c \in \mathbb{R}\) 일 때 볼록.
  • 최소제곱 손실(least squares loss): \(\|b - A x\|_2^2\) 는 임의의 \(A\) 에 대해 볼록.
  • 노름: 임의의 노름 \(\|\cdot\|\) 은 볼록합니다. 노름이 삼각부등식(subadditive) 과 동차성(homogeneous) 을 만족하기 때문입니다.
  • 대칭행렬의 최대 고유값(maximum eigenvalue).
  • 지시함수(Indicator function): \(C\) 가 볼록일 때, 지시함수 \[ I_C(x) = \begin{cases} 0, & x \in C \\ \infty, & x \notin C \end{cases} \] 는 볼록합니다. (제약조건 \(x \in C\) 를 목적함수에 흡수시키는 장치로 자주 쓰입니다.)
  • 지지함수(Support function): 볼록 집합 \(C\) 에 대해 \[ I_C^*(x) = \sup_{y \in C} \left\{ y^\top x \right\}. \]
  • 켤레함수(Conjugate function): 임의의 함수 \(f : \mathbb{R}^d \to \mathbb{R}\) 에 대해 켤레함수 \(f^*\) 는 \[ f^*(x) = \sup_{y \in \mathbb{R}^d} \left\{ y^\top x - f(y) \right\}. \]
  • 지지함수와 켤레함수는 모두 선형함수들의 상한(supremum) 형태입니다. 뒤에서 다룰 “볼록성을 보존하는 연산”을 미리 적용해 보면, 볼록 함수족의 점별 상한(pointwise supremum)은 항상 볼록하므로 이 두 함수도 자동으로 볼록함을 알 수 있습니다.

2.3 볼록 함수의 성질 (Properties of Convex Functions)

에피그래프 (Epigraph)

볼록 함수를 볼록 집합으로 환원하는 다리 역할을 하는 개념이 에피그래프입니다.

정의 1.13 (Epigraph). 함수 \(f : \mathbb{R}^d \to \mathbb{R}\) 의 에피그래프(epigraph) 는 \[ \operatorname{epi}(f) = \{ (x, t) \in \operatorname{dom}(f) \times \mathbb{R} : f(x) \le t \} \] 로 정의됩니다.

  • 에피그래프는 함수 그래프와 그 위쪽 영역 전체를 한데 묶은 집합입니다 (“epi-”는 그리스어로 “위(above)”를 뜻합니다).

연습문제 1.14. \(f\) 가 볼록 함수일 필요충분조건은 그 에피그래프 \(\operatorname{epi}(f)\) 가 볼록 집합인 것임을 증명하시오.

  • 이 동치 관계는 함수의 볼록성에 관한 명제를 집합의 볼록성에 관한 명제로 자유롭게 번역할 수 있게 해 줍니다. 증명의 아이디어는, 함수의 볼록성 부등식과 에피그래프의 두 점 \((x, s), (y, t)\) 에 대한 볼록 결합 \((\lambda x + (1-\lambda)y,\; \lambda s + (1-\lambda)t)\) 가 다시 에피그래프에 속한다는 조건이 서로 동치임을 보이는 데 있습니다.

예제 1.15. 노름 원뿔 \(\{ (x, t) \in \mathbb{R}^d \times \mathbb{R} : \|x\| \le t \}\) 이 볼록 원뿔이었음을 떠올려 봅시다. 이 원뿔은 정확히 함수 \(f(x) = \|x\|\) 의 에피그래프이므로, 연습문제 1.14에 의해 임의의 노름 \(f(x) = \|x\|\) 는 볼록 함수임이 따라옵니다.

준위집합 (Level set)

참고 1.16 (Level set). 함수 \(f : \mathbb{R}^d \to \mathbb{R}\) 의 준위집합(level set) 은 임의의 \(\alpha \in \mathbb{R}\) 에 대해 \[ \{ x \in \operatorname{dom}(f) : f(x) \le \alpha \} \] 로 정의됩니다. \(f\) 가 볼록이면 모든 준위집합이 볼록합니다. 그러나 그 역은 성립하지 않습니다.

  • 즉, “모든 준위집합이 볼록”하다고 해서 함수가 볼록한 것은 아닙니다. 이렇게 모든 준위집합이 볼록한 (그러나 함수 자체는 볼록하지 않을 수 있는) 함수를 유사볼록(quasiconvex) 함수라 부릅니다.

3. 볼록 함수의 1차 및 2차 특성화 (First-order and Second-order Characterizations)

정의 1.10의 부등식은 모든 \(\lambda \in [0,1]\) 에 대해 확인해야 하므로 직접 다루기가 번거롭습니다. 함수가 미분 가능할 경우, 기울기(gradient) 나 헤시안(Hessian) 만으로 볼록성을 판정하는 훨씬 간편한 도구를 얻을 수 있습니다.

3.1 1차 특성화 (First-order characterization)

정리 1.17. \(f : \mathbb{R}^d \to \mathbb{R}\) 를 미분 가능한 함수라 하자. 그러면 \(f\) 가 볼록일 필요충분조건은 \(\operatorname{dom}(f)\) 가 볼록이고, 모든 \(x, y \in \operatorname{dom}(f)\) 에 대해 \[ f(y) \ge f(x) + \nabla f(x)^\top (y - x) \] 가 성립하는 것이다.

  • 우변 \(f(x) + \nabla f(x)^\top (y - x)\) 은 점 \(x\) 에서 그은 1차 테일러 근사(접평면) 입니다. 따라서 이 정리는 “볼록 함수의 그래프는 항상 자신의 모든 접평면 위쪽에 놓인다” 는 뜻입니다. 접선이 그래프를 아래에서 떠받치는(global underestimator) 모습입니다.

증명.

(\(\Rightarrow\)) 볼록 \(\Rightarrow\) 1차 부등식.

Step 1 — \(d = 1\) 인 경우. \(f\) 가 볼록이면, 임의의 \(x, y \in \operatorname{dom}(f)\) 와 \(\lambda \in (0, 1]\) 에 대해 \[ f\big(x + \lambda(y - x)\big) = f\big((1 - \lambda)x + \lambda y\big) \le (1 - \lambda) f(x) + \lambda f(y) \] 가 성립합니다. 우변의 \((1 - \lambda) f(x)\) 항을 좌변으로 옮긴 뒤 양변을 \(\lambda\) 로 나누면 \[ f(y) \ge f(x) + \frac{f\big(x + \lambda(y - x)\big) - f(x)}{\lambda} \] 를 얻습니다. 이제 \(\lambda \to 0^+\) 극한을 취하면, \(f\) 가 미분 가능하므로 우변의 차분몫(difference quotient)은 방향도함수로 수렴합니다. \[ f(y) \ge f(x) + \lim_{\lambda \to 0^+} \frac{f\big(x + \lambda(y - x)\big) - f(x)}{\lambda} = f(x) + (y - x) f'(x). \]

Step 2 — 일반적인 경우 (\(d \ge 1\)). \(\lambda \in [0, 1]\) 에 대해 일변수 함수 \(g\) 를 다음과 같이 정의합니다. \[ g(\lambda) := f\big(x + \lambda(y - x)\big). \] 먼저 \(f\) 가 볼록이면 \(g\) 도 볼록임을 보입니다. \(\alpha \in [0, 1]\) 과 \(\lambda_1, \lambda_2 \in [0, 1]\) 에 대해 \[ \begin{aligned} g\big(\alpha \lambda_1 + (1 - \alpha) \lambda_2\big) &= f\big(x + (\alpha \lambda_1 + (1 - \alpha)\lambda_2)(y - x)\big) \\ &= f\Big(\alpha\big(x + \lambda_1(y - x)\big) + (1 - \alpha)\big(x + \lambda_2(y - x)\big)\Big) \\ &\le \alpha\, f\big(x + \lambda_1(y - x)\big) + (1 - \alpha)\, f\big(x + \lambda_2(y - x)\big) \\ &= \alpha\, g(\lambda_1) + (1 - \alpha)\, g(\lambda_2), \end{aligned} \] 이므로 \(g\) 는 볼록합니다. 또한 연쇄법칙(chain rule) 에 의해 \(g\) 는 미분 가능하며 \[ g'(\lambda) = (y - x)^\top \nabla f\big(x + \lambda(y - x)\big) \] 입니다. Step 1의 \(d = 1\) 결과를 일변수 함수 \(g\) 에 적용하면 \(g(1) \ge g(0) + g'(0)\) 이고, 이는 \[ f(y) \ge f(x) + \nabla f(x)^\top (y - x) \] 를 의미합니다. (여기서 \(g(1) = f(y)\), \(g(0) = f(x)\), \(g'(0) = \nabla f(x)^\top(y-x)\) 임을 대입했습니다.)

(\(\Leftarrow\)) 1차 부등식 \(\Rightarrow\) 볼록. \(x, y \in \operatorname{dom}(f)\) 와 \(\lambda \in [0, 1]\) 을 잡고 \(z := \lambda x + (1 - \lambda) y\) 라 둡니다. 가정에 의해 점 \(z\) 를 기준점으로 한 두 부등식 \[ f(x) \ge f(z) + \nabla f(z)^\top (x - z), \qquad f(y) \ge f(z) + \nabla f(z)^\top (y - z) \] 이 성립합니다. 첫 번째 부등식에 \(\lambda\) 를, 두 번째에 \((1 - \lambda)\) 를 곱한 뒤 더하면 \[ \lambda f(x) + (1 - \lambda) f(y) \ge f(z) + \nabla f(z)^\top \big(\lambda x + (1 - \lambda) y - z\big). \] 그런데 \(z\) 의 정의에 의해 괄호 안 \(\lambda x + (1-\lambda)y - z = 0\) 이므로, 우변은 \(f(z) = f\big(\lambda x + (1-\lambda)y\big)\) 와 같습니다. 따라서 \[ \lambda f(x) + (1 - \lambda) f(y) \ge f\big(\lambda x + (1 - \lambda) y\big) \] 이 되어 \(f\) 는 볼록입니다. \(\blacksquare\)

기울기의 단조성 (Monotonicity of the gradient)

1차 특성화를 두 점에 대칭적으로 적용하면, 볼록성의 또 다른 동치 조건을 얻습니다.

정리 1.18. \(f : \mathbb{R}^d \to \mathbb{R}\) 를 미분 가능한 함수라 하자. 그러면 \(f\) 가 볼록일 필요충분조건은 \(\operatorname{dom}(f)\) 가 볼록이고, 모든 \(x, y \in \operatorname{dom}(f)\) 에 대해 \[ \langle \nabla f(x) - \nabla f(y),\; x - y \rangle \ge 0 \] 이 성립하는 것이다.

  • 이는 기울기 사상 \(\nabla f\) 가 단조(monotone) 함을 뜻합니다. \(d = 1\) 일 때는 \(\big(f'(x) - f'(y)\big)(x - y) \ge 0\), 즉 도함수 \(f'\) 가 비감소(non-decreasing) 라는 익숙한 조건으로 환원됩니다.

증명.

(\(\Rightarrow\)) 정리 1.17을 \(x, y\) 의 역할을 바꿔 두 번 적용하면 \[ f(y) \ge f(x) + \nabla f(x)^\top (y - x), \qquad f(x) \ge f(y) + \nabla f(y)^\top (x - y). \] 두 부등식을 더하면 \(f(x), f(y)\) 항이 소거되고 \[ 0 \ge \nabla f(x)^\top (y - x) + \nabla f(y)^\top (x - y) = -\big(\nabla f(x) - \nabla f(y)\big)^\top (x - y), \] 즉 \(\big(\nabla f(x) - \nabla f(y)\big)^\top (x - y) \ge 0\) 을 얻습니다.

(\(\Leftarrow\)) 미적분학의 기본정리(fundamental theorem of calculus) 를 이용합니다. 합성함수 \(\lambda \mapsto f\big(x + \lambda(y - x)\big)\) 에 대해 \[ \int_0^1 \nabla f\big(x + \lambda(y - x)\big)^\top (y - x)\, d\lambda = \int_0^1 \frac{d}{d\lambda} f\big(x + \lambda(y - x)\big)\, d\lambda = f(y) - f(x) \] 가 성립합니다. 한편, 임의의 \(\lambda > 0\) 에 대해 가정(단조성)을 점 \(x + \lambda(y-x)\) 와 \(x\) 에 적용하면 \[ \nabla f\big(x + \lambda(y - x)\big)^\top (y - x) - \nabla f(x)^\top (y - x) = \frac{1}{\lambda} \Big\langle \nabla f\big(x + \lambda(y - x)\big) - \nabla f(x),\; \lambda(y - x) \Big\rangle \ge 0 \] 이므로 \[ \nabla f\big(x + \lambda(y - x)\big)^\top (y - x) \ge \nabla f(x)^\top (y - x) \] 가 모든 \(\lambda > 0\) 에서 성립합니다 (\(\lambda = 0\) 일 때는 등호로 자명하게 성립). 이를 위 적분식에 대입하면 \[ f(y) - f(x) = \int_0^1 \nabla f\big(x + \lambda(y - x)\big)^\top (y - x)\, d\lambda \ge \nabla f(x)^\top (y - x). \] 이는 정리 1.17의 1차 부등식이므로 \(f\) 는 볼록입니다. \(\blacksquare\)

3.2 2차 특성화 (Second-order characterization)

두 번 미분 가능한 함수에 대해서는, 헤시안 행렬의 부호만으로 볼록성을 판정할 수 있습니다.

정리 1.19. \(f : \mathbb{R}^d \to \mathbb{R}\) 를 두 번 미분 가능한 함수라 하자(헤시안 \(\nabla^2 f\) 가 정의역의 모든 점에서 존재하고 \(\operatorname{dom}(f)\) 가 열린집합이라 가정). 그러면 \(f\) 가 볼록일 필요충분조건은 \(\operatorname{dom}(f)\) 가 볼록이고, 모든 \(x \in \operatorname{dom}(f)\) 에 대해 \[ \nabla^2 f(x) \succeq 0 \] (헤시안이 양의 준정부호)인 것이다.

  • 양의 준정부호(positive semidefinite, PSD) \(\nabla^2 f(x) \succeq 0\) 의 정의는, 임의의 \(v \in \mathbb{R}^d\) 에 대해 \(v^\top \nabla^2 f(x)\, v \ge 0\) 이라는 뜻입니다. 직관적으로는 모든 방향에서의 곡률(이차도함수)이 음이 아니다, 즉 어느 방향으로 잘라 보아도 단면이 위로 볼록하다는 의미입니다. \(d=1\) 에서는 친숙한 조건 \(f''(x) \ge 0\) 이 됩니다.

증명.

(\(\Rightarrow\)) 볼록 \(\Rightarrow\) \(\nabla^2 f \succeq 0\).

Step 1 — \(d = 1\) 인 경우. 정리 1.17에 의해 \[ f(x) \ge f(y) + f'(y)(x - y), \qquad f(y) \ge f(x) + f'(x)(y - x) \] 이 성립합니다. 두 부등식을 더한 뒤 양변을 \((y - x)^2 > 0\) 으로 나누면 \[ \frac{f'(y) - f'(x)}{y - x} \ge 0 \] 을 얻습니다. 이제 \(y \to x\) 극한을 취하면 좌변은 이차도함수의 정의에 수렴하므로 \(f''(x) \ge 0\) 입니다.

Step 2 — 일반적인 경우. \(x \in \operatorname{dom}(f)\) 와 임의의 방향 \(v \in \mathbb{R}^d\) 를 고정합니다. \(\operatorname{dom}(f)\) 가 열린집합이므로 충분히 작은 \(\epsilon > 0\) 이 존재하여 모든 \(\lambda \in (-\epsilon, \epsilon)\) 에 대해 \(x + \lambda v \in \operatorname{dom}(f)\) 입니다. 이때 일변수 함수 \[ g(\lambda) = f(x + \lambda v) \] 를 정의하면, \(f\) 가 볼록이므로 \(g\) 도 볼록입니다(정리 1.17 증명의 Step 2와 동일한 논리). 연쇄법칙을 두 번 적용하면 \[ g'(\lambda) = v^\top \nabla f(x + \lambda v), \qquad g''(\lambda) = v^\top \nabla^2 f(x + \lambda v)\, v \] 입니다. Step 1의 \(d = 1\) 결과를 \(g\) 에 적용하면 \(g''(0) \ge 0\), 즉 \[ g''(0) = v^\top \nabla^2 f(x)\, v \ge 0. \] \(v\) 가 임의였으므로 \(\nabla^2 f(x) \succeq 0\) 이 증명됩니다.

(\(\Leftarrow\)) \(\nabla^2 f \succeq 0 \Rightarrow\) 볼록. 미적분학의 기본정리를 기울기 사상에 적용하면, \(\varphi(\lambda) := \nabla f\big(x + \lambda(y - x)\big)\) 에 대해 \(\varphi'(\lambda) = \nabla^2 f\big(x + \lambda(y-x)\big)(y - x)\) 이므로 \[ \int_0^1 \nabla^2 f\big(x + \lambda(y - x)\big)(y - x)\, d\lambda = \nabla f(y) - \nabla f(x) \] 입니다. 양변에 \((y - x)\) 를 내적하면 \[ \big\langle \nabla f(y) - \nabla f(x),\; y - x \big\rangle = \int_0^1 (y - x)^\top \nabla^2 f\big(x + \lambda(y - x)\big)(y - x)\, d\lambda \ge 0, \] 여기서 부등식은 피적분함수가 \(\nabla^2 f \succeq 0\) (PSD)에 의해 점마다 비음수이기 때문에 성립합니다. 이는 정리 1.18의 기울기 단조성 조건이므로, \(f\) 는 볼록입니다. \(\blacksquare\)

4. 정리 (Summary)

이번 강의에서 다룬 핵심을 한 문장씩 정리하면 다음과 같습니다.

  • 볼록 집합은 “임의의 두 점을 잇는 선분을 모두 포함”하는 집합이며, 결합 계수의 제약(비음수 / 합 1)을 조절하면 볼록 결합·원뿔 결합·아핀 결합으로 이어진다.
  • 볼록 함수는 “현이 그래프 위에 놓이는” 함수이며, 에피그래프가 볼록 집합이라는 조건과 동치다.
  • 1차 특성화: 볼록 ⟺ 그래프가 모든 접평면 위에 놓임 (\(f(y) \ge f(x) + \nabla f(x)^\top(y-x)\)) ⟺ 기울기가 단조.
  • 2차 특성화: 볼록 ⟺ 헤시안이 모든 점에서 양의 준정부호 (\(\nabla^2 f(x) \succeq 0\)).

이 도구들은 다음 강의에서 다룰 볼록성을 보존하는 연산(operations preserving convexity) 과 결합하여, 복잡한 함수의 볼록성을 손쉽게 증명하는 토대가 됩니다.
