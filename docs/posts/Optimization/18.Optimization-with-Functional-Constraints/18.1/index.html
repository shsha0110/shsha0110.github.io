1. 들어가며: 기능적 제약조건이 있는 최적화

  • 이번 포스트에서는 기능적 제약조건(Functional Constraints)이 존재하는 볼록 최적화(Convex Optimization) 문제를 해결하는 두 가지 주요 알고리즘인 Nesterov의 이분법(Bisection Method)과 Polyak의 스위칭 알고리즘(Switching Algorithm)에 대해 자세히 다룹니다.
  • 일반적으로 우리가 다루고자 하는 최적화 문제의 구조는 다음과 같습니다:

\[ \begin{aligned} \text{minimize} \quad & f(x) \\ \text{subject to} \quad & g(x) \le 0 \\ & x \in \mathcal{X} \end{aligned} \quad \cdots (18.1) \]

  • 여기서 함수 \(f: \mathbb{R}^d \rightarrow \mathbb{R}\) 와 \(g: \mathbb{R}^d \rightarrow \mathbb{R}\) 는 모두 볼록 함수(convex functions)이며, 집합 \(\mathcal{X} \subseteq \mathbb{R}^d\) 는 볼록 집합(convex set)입니다. 설명의 편의를 위해 \(f\)와 \(g\)가 모두 미분 가능(differentiable)하다고 가정합니다.

  • 이 문제의 최적해를 \(x^*\)라고 표기합시다. 즉, 다음이 성립합니다: \[x^* \in \arg\min \{ f(x) : g(x) \le 0, x \in \mathcal{X} \}.\]

  • 우리의 목표는 정확한 \(x^*\)를 찾는 대신, 허용 오차 \(\epsilon\) 내에 들어오는 \(\epsilon\)-근사해(approximate solution) \(\hat{x} \in \mathcal{X}\)를 찾는 것입니다. 수학적으로 이는 다음 두 조건을 만족하는 \(\hat{x}\)를 찾는 것을 의미합니다: \[g(\hat{x}) \le \epsilon \quad \text{and} \quad f(\hat{x}) - f(x^*) \le \epsilon.\]

  • 이는 제약조건을 최대 \(\epsilon\) 만큼만 위반하면서, 목적 함수 값도 최적값 대비 \(\epsilon\) 이내의 차이를 가지는 실용적인 해를 찾는 과정입니다.

2. 기존 방법론의 한계와 새로운 접근법

  • (18.1)과 같은 제약조건 최적화 문제는 기본적으로 투영된 경사 하강법(Projected Gradient Descent)을 사용하여 풀 수 있습니다.

  • 하지만, 실행 가능 영역(feasible set)인 \(\{x \in \mathcal{X} : g(x) \le 0\}\)의 형태가 기하학적으로 복잡할 경우, 이 집합 위로의 투영(projection) 연산 자체가 계산적으로 매우 비효율적(inefficient)이 될 수 있습니다.

  • 따라서 투영 연산의 복잡도를 \(\mathcal{X}\) 집합 수준으로 유지하면서 목적 함수 \(f\)와 제약 함수 \(g\)를 영리하게 다루는 대안적 방법론이 필요합니다. 이 포스트에서는 두 가지 대안을 살펴봅니다:

      1. Nesterov’s Bisection Method: 이분법을 통해 최적값을 추정하며 근사해를 찾는 방법.
      1. Polyak’s Switching Algorithm: 조건에 따라 \(f\)와 \(g\)의 기울기(gradient)를 번갈아 사용하는 방법.

3. Nesterov의 이분법 (Nesterov’s Bisection Method)

  • Nesterov의 이분법은 최적값 \(f^* = f(x^*)\)를 알고 있다는 가정에서 출발하여, 이를 모를 경우 이분법(Bisection)을 통해 \(f^*\)를 점진적으로 추정해 나가는 알고리즘입니다.

3.1. 핵심 아이디어와 보조 정리

  • 만약 우리가 \(f^*\)의 정확한 값을 안다고 가정해 봅시다. 그러면 다음 새로운 함수 \(h(x)\)를 정의할 수 있습니다: \[h(x) := \max\{g(x), f(x) - f^*\}.\]

  • 이 함수 \(h(x)\)를 최소화하는 문제는 원래의 문제 (18.1)과 깊은 연관이 있습니다.

Lemma 18.1.

\[\min_{x\in\mathcal{X}} h(x) = h(x^*) = 0.\]

Proof.

    1. 최적해 \(x^*\)는 제약조건을 만족하므로 \(g(x^*) \le 0\)이며, \(f(x^*) - f^* = 0\)입니다. 따라서 \(\max\{g(x^*), 0\} = 0\)이 되어 \(h(x^*) = 0\)이 성립합니다.
    1. 임의의 \(x \in \mathcal{X}\)에 대하여, 만약 \(g(x) \le 0\)을 만족한다면(실행 가능한 해라면), 최적값 \(f^*\)의 정의에 의해 \(f(x) \ge f^*\)이므로 \(f(x) - f^* \ge 0\)이 됩니다. 따라서 \(h(x) = \max\{g(x), f(x) - f^*\} \ge 0\)입니다.
    1. 반대로 \(g(x) > 0\)이라면 0보다 큰 값과 비교하므로 당연히 \(h(x) > 0\)이 됩니다.
    1. 결론적으로 모든 \(x \in \mathcal{X}\)에 대해 \(h(x) \ge 0\)이며, \(x^*\)에서 그 값이 0이 되므로 \(\min_{x\in\mathcal{X}} h(x) = h(x^*) = 0\)이 증명됩니다.
  • 이 보조 정리에 따르면, \(f^*\)를 안다면 \(\mathcal{X}\) 위에서 \(h(x)\)를 최소화하는 문제로 치환하여 풀 수 있습니다. 함수 \(h(x)\)는 두 볼록 함수의 최댓값이므로 역시 볼록 함수입니다. 따라서 투영된 준경사법(Projected Subgradient Method)을 적용하면 \(\mathcal{O}(1/\epsilon^2)\) 번의 반복만으로 \(\epsilon\)-근사해를 구할 수 있습니다.

3.2. 이분법 알고리즘 설계

  • 문제는 우리가 \(f^*\)를 모른다는 것입니다. Nesterov 알고리즘은 임의의 값 \(v \in \mathbb{R}\)에 대해 다음 함수를 정의하고, \(v\)를 조절하여 \(f^*\)를 이분법으로 찾습니다: \[h_v(x) := \max\{g(x), f(x) - v\}.\]

  • 먼저 \(f^*\)의 하한(lower bound) \(l\)과 상한(upper bound) \(u\)를 설정합니다 (\(l \le f^* \le u\)). 예를 들어, \(l = \min_{x\in\mathcal{X}} f(x)\)로, \(u = f(x_0)\) (단, \(x_0\)는 \(g(x_0) \le 0\)인 실행 가능해)로 설정할 수 있습니다.

  • Algorithm 1: Bisection-based method

    • Input: 하한 및 상한 \(l, u\), 목표 정확도 \(\epsilon > 0\).
    • Initialize: 반복 횟수 \(N = \lceil \log_2 \frac{u-l}{\epsilon/2} \rceil\).
    • For \(t = 1, \dots, N\) do:
        1. 중간값 설정: \(v = (l+u)/2\)
        1. 투영된 준경사법(Projected Subgradient Method)을 사용하여 \(\min_{x\in\mathcal{X}} h_v(x)\)의 \(\epsilon/2\)-근사해 \(x_v\)를 찾습니다.
        1. If \(h_v(x_v) > \epsilon/2\) then:
        • \(l = v\) (하한 업데이트)
        1. Else:
        • \(u = v\), \(x_u = x_v\) (상한 및 후보해 업데이트)
    • End For
    • Return \(x_u\)

  • 알고리즘 내부에서 \(h_v(x)\)를 최소화하기 위해 준경사(Subgradient)를 계산해야 합니다. 점별 최댓값(pointwise maximum) 함수의 준미분(Subdifferential)은 다음과 같이 정의됩니다.

  • Lemma 18.2. 임의의 \(v \in \mathbb{R}\)에 대해 \(h_v\)의 \(x\)에서의 준미분은 다음과 같습니다: \[ \partial h_v(x) = \begin{cases} \{\nabla g(x)\} & \text{if } g(x) > f(x) - v \\ \{\nabla f(x)\} & \text{if } g(x) < f(x) - v \\ \text{conv}\{\nabla g(x), \nabla f(x)\} & \text{if } g(x) = f(x) - v \end{cases} \]

    • 이 Lemma 덕분에, 각 지점에서 \(g(x)\)와 \(f(x)-v\)의 크기를 비교하여 단순히 \(\nabla g(x)\)나 \(\nabla f(x)\)를 취하는 것만으로 준경사를 쉽게 계산할 수 있습니다.

3.3. 수렴성 및 증명

Theorem 18.3. 알고리즘 1은 \(N = \mathcal{O}(\log(1/\epsilon))\) 번의 이분법 반복 후 (18.1)의 \(\epsilon\)-근사해를 반환합니다.

각 하위 문제(subproblem)를 투영된 준경사법으로 푸는 데 \(\mathcal{O}(1/\epsilon^2)\)이 소요되므로, 총 반복 횟수는 \(\mathcal{O}((1/\epsilon^2)\log(1/\epsilon))\)입니다.

Proof.

  • 증명의 핵심은 매 스텝마다 \(l \le f^*\) 및 \(h_u(x_u) \le \epsilon/2\) 라는 불변성(invariant)이 유지됨을 귀납법으로 보이는 것입니다.

    1. 임의의 \(v \in \mathbb{R}\)에 대해 하위 문제의 최적값을 \(h^*(v) := \min_{x\in\mathcal{X}} h_v(x)\)라 합시다. \(h^*(v)\)는 \(v\)에 대해 비증가(non-increasing) 함수이며, \(v = f^*\)일 때 \(h^*(f^*) = 0\)이 됩니다.
    1. 하한 \(l\)의 유지: 스텝 \(t\) 시작 시 \(l \le f^*\)라고 가정합시다. 만약 \(h_v(x_v) > \epsilon/2\)라면, \(x_v\)가 \(\epsilon/2\)-근사해이므로 진짜 최솟값 \(h^*(v)\)는 \(h^*(v) \ge h_v(x_v) - \epsilon/2 > 0\)이 됩니다. \(h^*(v) > 0\)이라는 것은 \(v < f^*\)임을 뜻하므로, 다음 스텝에서 \(l = v\)로 업데이트해도 여전히 \(l < f^*\)가 성립합니다. 반대로 \(h_v(x_v) \le \epsilon/2\)이면 \(l\)은 그대로 유지되므로 \(l \le f^*\)가 유지됩니다.
    1. 상한 \(u\)의 유지: 초기 \(u\)는 \(f^* \le u\)이므로 \(h^*(u) \le h^*(f^*) = 0\)입니다. 따라서 \(\epsilon/2\)-근사해 \(x_u\)는 \(h_u(x_u) \le h^*(u) + \epsilon/2 \le \epsilon/2\)를 만족합니다. 만약 \(h_v(x_v) \le \epsilon/2\) 라면 \(u=v\)가 되고 \(x_u=x_v\)가 되므로 조건이 유지되며, 아닐 경우 \(u\)는 변하지 않으므로 여전히 성립합니다.
    1. 결과적으로 종료 시점 \(N\)에서 구획 길이는 \(u - l \le \epsilon/2\)를 만족합니다.
    1. 최종 \(x_u\)에 대하여 다음이 성립합니다: \[g(x_u) \le h_u(x_u) \le \epsilon/2 < \epsilon\] \[f(x_u) - f^* \le h_u(x_u) + u - f^* \le \epsilon/2 + (u - l) \le \epsilon/2 + \epsilon/2 = \epsilon\]

  • 따라서 \(x_u\)는 우리가 원하던 \(\epsilon\)-근사해가 됩니다.

4. Polyak의 스위칭 알고리즘 (Polyak’s Switching Algorithm)

  • Nesterov의 알고리즘은 총 \(\mathcal{O}((1/\epsilon^2)\log(1/\epsilon))\)의 반복을 요구합니다. 여기서 추가로 붙은 \(\log(1/\epsilon)\) 인자(factor)는 \(f^*\)를 추정하기 위한 이분법 때문에 발생한 것입니다.
  • Polyak(1967)은 이 이분법을 아예 생략하고, 볼록 최적화의 이론적 최적 반복 횟수인 \(\mathcal{O}(1/\epsilon^2)\)만에 문제를 해결하는 우아한 알고리즘을 제안했습니다.

4.1. 핵심 아이디어 및 알고리즘

  • Polyak 알고리즘의 철학은 매우 직관적입니다. 제약조건 함수 \(g\)의 값이 오차 허용치 \(\epsilon\)을 초과하여 위반되고 있다면 목적 함수 \(f\)는 신경 쓰지 않고 \(g\)를 줄이는 데 집중(Gradient Descent on \(g\))합니다. 반대로 제약조건이 \(\epsilon\) 이내로 만족(\(g(x) \le \epsilon\))된다면, 비로소 목적 함수 \(f\)를 줄이는 데 집중(Gradient Descent on \(f\))하는 것입니다.

  • Algorithm 2: Polyak’s Switching Algorithm

    • Input: 초기해 \(x_1 \in \mathcal{X}\), 목표 정확도 \(\epsilon > 0\), 학습률(step size) \(\eta > 0\), 총 반복 횟수 \(T\).
    • For \(t = 1, \dots, T\) do:
        1. If \(g(x_t) \le \epsilon\) then:
        • 방향 설정: \(d_t = \nabla f(x_t)\)
        1. Else:
        • 방향 설정: \(d_t = \nabla g(x_t)\)
        1. 업데이트: \(x_{t+1} = \text{proj}_{\mathcal{X}}(x_t - \eta d_t)\)
    • End For
    • Return \(\hat{x} = \arg\min \{ f(x_t) : g(x_t) \le \epsilon, t = 1, \dots, T \}\)

  • 반환 시에는 알고리즘이 탐색했던 경로 중 \(g(x_t) \le \epsilon\)을 만족했던 지점들 중 가장 목적 함수 \(f(x_t)\) 값이 작았던 해를 선택하여 반환합니다.

4.2. 수렴성 및 증명

Theorem 18.4.

함수 \(f\)와 \(g\)가 \(L\)-립시츠 연속(Lipschitz continuous)이라고 가정합시다. Step size를 \(\eta = \epsilon/L^2\)으로 설정하고 알고리즘 2를 \(T = \mathcal{O}(1/\epsilon^2)\) 반복 수행하면, (18.1)의 \(\epsilon\)-근사해를 반환합니다.

Proof.

    1. \(L\)-립시츠 조건에 의해 모든 \(t\)에 대해 기울기의 노름은 \(\|d_t\| \le L\)입니다. \(\mathcal{X}\)위로의 투영 연산은 비팽창성(non-expansiveness)을 가지므로 최적해 \(x^*\)와의 거리를 다음처럼 전개할 수 있습니다: \[ \begin{aligned} \|x_{t+1} - x^*\|^2 &= \|\text{proj}_{\mathcal{X}}(x_t - \eta d_t) - \text{proj}_{\mathcal{X}}(x^*)\|^2 \\ &\le \|x_t - \eta d_t - x^*\|^2 \\ &= \|x_t - x^*\|^2 - 2\eta d_t^\top(x_t - x^*) + \eta^2 \|d_t\|^2 \\ &\le \|x_t - x^*\|^2 - 2\eta d_t^\top(x_t - x^*) + \eta^2 L^2 \end{aligned} \]
    1. 위 식을 재배열하여 \(t=1\)부터 \(T\)까지 더하고 \(T\)로 나누어 평균을 구하면 (Telescoping sum): \[\frac{1}{T}\sum_{t=1}^T d_t^\top(x_t - x^*) \le \frac{1}{2\eta T}\|x_1 - x^*\|_2^2 + \frac{\eta}{2}L^2\]
    • 평균이 위 우변보다 작으므로, 시퀀스 중 최솟값 역시 우변보다 작거나 같습니다: \[\min_{1 \le t \le T} d_t^\top(x_t - x^*) \le \frac{1}{2\eta T}\|x_1 - x^*\|_2^2 + \frac{\eta}{2}L^2\]
    1. 이제 알고리즘의 스위칭 조건에 따라 좌변의 의미를 해석해 봅니다.
    • Case 1 (\(g(x_t) \le \epsilon\)): 이 경우 \(d_t = \nabla f(x_t)\)입니다. \(f\)의 볼록성(convexity)에 의해: \[f(x_t) - f(x^*) \le \nabla f(x_t)^\top (x_t - x^*) = d_t^\top (x_t - x^*)\]
    • Case 2 (\(g(x_t) > \epsilon\)): 이 경우 \(d_t = \nabla g(x_t)\)입니다. \(g\)의 볼록성과 최적해 조건 \(g(x^*) \le 0\)을 활용하면: \[\epsilon < g(x_t) \le d_t^\top (x_t - x^*) + g(x^*) \le d_t^\top (x_t - x^*)\]
    1. 두 케이스를 종합하면, 각 \(t\)에 대해 기울기 내적 \(d_t^\top (x_t - x^*)\)는 \(\epsilon\) 이거나 (제약을 위반한 경우), 제약을 만족하는 경우들 중 최솟값인 \(\min \{f(x_t) - f(x^*) : g(x_t) \le \epsilon\}\) 보다 항상 크거나 같습니다: \[\min_{1 \le t \le T} d_t^\top (x_t - x^*) \ge \min \left\{ \epsilon, \min_{t: g(x_t) \le \epsilon} \{f(x_t) - f(x^*)\} \right\}\]
    1. 증명 2번 식과 증명 4번 식을 결합하고, \(\eta = \epsilon/L^2\), \(T \ge \frac{2L^2}{\epsilon^2}\|x_1 - x^*\|_2^2\) 를 대입합니다: \[ \min \left\{ \epsilon, \min_{t: g(x_t) \le \epsilon} \{f(x_t) - f(x^*)\} \right\} \le \frac{1}{4}\epsilon + \frac{1}{2}\epsilon = \frac{3}{4}\epsilon < \epsilon \]
    1. 위 식에서 좌변이 \(\epsilon\)보다 엄격하게 작으므로, \(\min \{\}\) 안의 값이 \(\epsilon\)일 수는 없습니다. 따라서 다음 결론을 얻습니다: \[\min \{f(x_t) - f(x^*) : g(x_t) \le \epsilon, t = 1, \dots, T\} < \epsilon\]
    • 이는 우리가 반환하는 해 \(\hat{x}\)가 \(f(\hat{x}) - f(x^*) < \epsilon\)을 만족하는 동시에 \(g(\hat{x}) \le \epsilon\)을 만족하는 유효한 \(\epsilon\)-근사해임을 증명합니다.

5. 요약 및 결론

  • 이번 포스트에서는 실행 가능 영역으로의 복잡한 투영 연산을 우회하여 기능적 제약조건이 있는 최적화 문제를 푸는 두 알고리즘을 알아보았습니다.
    • Nesterov의 이분법: 목적 함수의 최적값을 이분법으로 좁혀 나가며 \(\mathcal{O}((1/\epsilon^2)\log(1/\epsilon))\) 반복 내에 해를 찾습니다.
    • Polyak의 스위칭 알고리즘: 제약조건 위반 여부에 따라 \(f\)와 \(g\)의 기울기를 스마트하게 전환하여 불필요한 이분법 스텝을 제거, 이론적 한계인 \(\mathcal{O}(1/\epsilon^2)\) 반복을 달성합니다.
  • 두 알고리즘 모두 볼록성과 함수 최댓값, 준미분의 성질을 절묘하게 엮어낸 훌륭한 방법론들입니다. 특히 Polyak 알고리즘은 구현이 매우 단순하면서도 최적 복잡도를 보장하므로, 머신러닝의 다양한 제약 최적화 문제에서 강력한 베이스라인으로 활용될 수 있습니다.
