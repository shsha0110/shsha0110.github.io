들어가며 (Introduction)

이번 실습은 ItDL(Introduction to Deep Learning) 강의의 “Transformer backward” 세션입니다. 지금까지의 강의에서 우리는 Transformer를 구성하는 모든 building block(Embedding, Linear, Attention, FeedForward, RMSNorm, RotaryEmbedding)의 forward와 backward를 하나씩 직접 구현해 왔습니다. 이번 시간에는 이 부품들을 조립하여 end-to-end Transformer 전체의 역전파(backward)를 완성하는 것이 목표입니다.

PyTorch의 autograd가 자동으로 해 주는 일을 굳이 손으로 짜는 이유는 다음과 같습니다.

  • 연쇄법칙(chain rule)의 본질을 코드 수준에서 체득하기 위함입니다. 역전파란 결국 손실 \(L\)에 대한 각 변수의 편미분을 출력 쪽에서 입력 쪽으로 차례차례 전파하는 과정일 뿐입니다.
  • 특히 Transformer의 핵심인 residual connection(잔차 연결)이 그래디언트 흐름에 어떤 “고속도로(highway)”를 만들어 주는지를 명확히 볼 수 있습니다.
  • softmax + cross-entropy의 그래디언트가 왜 그토록 깔끔하게 떨어지는지(softmax 확률 − 정답 one-hot) 직접 유도해 봅니다.

공통 규약: Module의 backward 인터페이스

본 실습의 프레임워크에서 모든 연산은 Module을 상속하며, 두 개의 메서드를 가집니다.

  • forward(input) → output: 순전파를 수행하고, backward에서 필요한 중간값(activation)을 self에 저장합니다.
  • backward(grad_output) → grad_input: 출력에 대한 손실의 그래디언트 \(\dfrac{\partial L}{\partial \text{output}}\) 를 입력받아, 입력에 대한 그래디언트 \(\dfrac{\partial L}{\partial \text{input}}\) 를 반환합니다. 동시에 내부적으로 학습 파라미터의 그래디언트를 누적합니다.

이 규약은 자동미분에서 말하는 VJP(Vector-Jacobian Product) 와 정확히 일치합니다. 즉 모듈 \(f\)가 야코비안 \(J_f\)를 가질 때, f.backward는 야코비안을 명시적으로 만들지 않고 곱 \(J_f^\top \cdot \text{grad\_output}\) 만을 효율적으로 계산하는 함수입니다.

표기 약속: 이하 어떤 텐서 \(v\)에 대해 \(\bar v := \dfrac{\partial L}{\partial v}\) 로 줄여 쓰겠습니다. (\(L\)은 최종 스칼라 손실)

대상 아키텍처

이번에 다루는 구조는 RMSNorm + RoPE(Rotary Position Embedding) + SwiGLU 계열 FeedForward + Pre-Norm 잔차 블록으로, 사실상 LLaMA 계열의 디코더 전용(decoder-only) Transformer입니다. 전체 흐름은 다음과 같습니다.

tokens → Embedding → [TransformerBlock × n_layers] → RMSNorm → Linear(output) → logits → CrossEntLoss → loss

아래 그림은 이번 실습에서 구현할 backward의 전체 신호 흐름을 개념적으로 정리한 것입니다.

1. 각 Transformer 블록의 역전파 (Backward of each Transformer block)

먼저 가장 작은 조립 단위인 TransformerBlock의 backward를 구현합니다. 지금까지 만든 부품들의 forward/backward를 수동으로 다시 계산하지 않고, 각 서브모듈의 backward()를 호출하는 방식으로 연결하는 것이 핵심입니다.

1.1 forward 구조 다시 보기 (Pre-Norm Residual Block)

def forward(self, x, cos, sin, mask=None):
    x_norm = self.attention_norm(x)
    attn_residual = self.attention(x_norm, cos, sin, mask)
    h = x + attn_residual

    h_norm = self.ffn_norm(h)
    mlp_residual = self.feed_forward(h_norm)
    out = h + mlp_residual
    return out

이를 수식으로 정리하면 다음과 같습니다. 이는 Pre-Norm 구조로, 정규화(Norm)를 서브모듈 앞에 두고 그 결과를 잔차로 더합니다.

\[ \begin{aligned} x_{\text{norm}} &= \text{RMSNorm}_{\text{attn}}(x) \\ a &= \text{Attention}(x_{\text{norm}}, \cos, \sin, \text{mask}) \\ h &= x + a \qquad &&\text{(첫 번째 잔차 연결)} \\ h_{\text{norm}} &= \text{RMSNorm}_{\text{ffn}}(h) \\ m &= \text{FFN}(h_{\text{norm}}) \\ \text{out} &= h + m \qquad &&\text{(두 번째 잔차 연결)} \end{aligned} \]

1.2 핵심 보조정리: 잔차 연결의 그래디언트 규칙

블록 전체를 미분하기 전에, 반복적으로 등장하는 잔차 연결의 미분 공식을 정리해 두면 코드가 한눈에 읽힙니다.

함수가 \(y = x + f(x)\) 형태일 때, 연쇄법칙에 의해

\[ \bar{x} = \frac{\partial L}{\partial x} = \underbrace{\frac{\partial L}{\partial y}}_{\text{항등 경로(skip)}} + \underbrace{J_f^\top \, \frac{\partial L}{\partial y}}_{\text{함수 경로}} = \bar y + f.\text{backward}(\bar y) \]

  • 항등 경로(\(\bar y\)): \(y = x + f(x)\)에서 \(x\)가 그대로 더해지므로(\(\partial y / \partial x\)의 항등 부분), 출력 그래디언트가 아무 손실 없이 그대로 입력으로 흘러갑니다. 이것이 잔차 연결이 깊은 망에서 그래디언트 소실(vanishing gradient)을 막아 주는 이유입니다.
  • 함수 경로(\(f.\text{backward}(\bar y)\)): \(f\)를 통과한 그래디언트로, 정의상 서브모듈의 backward가 반환하는 값입니다.

즉 잔차 연결의 backward는 “위에서 내려온 그래디언트를 그대로 통과시키면서, 동시에 서브모듈 분기로도 흘려보내 둘을 더한다”로 요약됩니다.

1.3 블록 backward의 단계별 유도

forward는 \(x \to (\text{attn 잔차}) \to h \to (\text{ffn 잔차}) \to \text{out}\) 순서였으므로, backward는 정확히 역순으로 진행합니다. 입력은 ${} = $ grad_output 입니다.

(1) 두 번째 잔차 out = h + m 통과

\(m = \text{FFN}(h_{\text{norm}})\)이므로 \(\bar m = \bar{\text{out}}\) 입니다. 이를 FFN의 backward에 넣어 그 입력 \(h_{\text{norm}}\)에 대한 그래디언트를 얻습니다.

\[ \overline{h_{\text{norm}}} = \text{feed\_forward.backward}(\bar{\text{out}}) \]

이제 \(h\)에 대한 그래디언트는 (i) 잔차 항등 경로 \(\bar{\text{out}}\) 와 (ii) \(h_{\text{norm}} = \text{RMSNorm}_{\text{ffn}}(h)\) 분기를 합친 것입니다.

\[ \bar h = \bar{\text{out}} + \text{ffn\_norm.backward}(\overline{h_{\text{norm}}}) \]

(2) 첫 번째 잔차 h = x + a 통과

\(a = \text{Attention}(x_{\text{norm}}, \cos, \sin, \text{mask})\)이므로 \(\bar a = \bar h\) 입니다. Attention의 backward는 입력이 셋(\(x_{\text{norm}}, \cos, \sin\))이므로 그래디언트도 셋을 반환합니다.

\[ \bigl(\overline{x_{\text{norm}}},\; \overline{\cos},\; \overline{\sin}\bigr) = \text{attention.backward}(\bar h) \]

(마스크 mask는 상수이므로 그래디언트가 없습니다.) 마지막으로 \(x\)에 대한 그래디언트는 다시 잔차 규칙을 적용합니다.

\[ \bar x = \bar h + \text{attention\_norm.backward}(\overline{x_{\text{norm}}}) \]

(3) 최종 코드

위 유도가 그대로 코드가 됩니다.

def backward(self, grad_output):
    grad_h_norm = self.feed_forward.backward(grad_output)
    grad_h = grad_output + self.ffn_norm.backward(grad_h_norm)

    grad_x_norm, grad_cos, grad_sin = self.attention.backward(grad_h)
    grad_x = grad_h + self.attention_norm.backward(grad_x_norm)

    return grad_x, grad_cos, grad_sin
  • grad_output +, grad_h + 부분이 바로 잔차 항등 경로입니다. 이 한 글자(+)가 그래디언트 고속도로 역할을 합니다.
  • \(\overline{\cos}, \overline{\sin}\) 까지 함께 반환하는 이유는, 상위 모듈(Transformer)에서 위치 정보의 그래디언트를 어떻게 처리할지 결정하도록 인터페이스를 열어 두기 위함입니다. (3절에서 다룹니다.)

아래 그림은 이 backward 흐름을 시각화한 것입니다.

테스트(test_module)는 모든 학습 파라미터(wq, wk, wv, wo, w1, w2, w3 등)와 입력에 대해 수치 미분(finite difference)으로 구한 그래디언트와 우리가 구현한 해석적 그래디언트를 비교하며, 17개 항목이 모두 통과(✓ test passed)함을 확인합니다.

2. 교차 엔트로피 손실의 역전파 (Backward of cross entropy loss)

지난 강의에서 배웠듯, 교차 엔트로피 손실(cross-entropy loss) 은 분류(classification) 과제의 표준 손실 함수입니다. 언어 모델에서는 각 위치(token position)마다 다음 토큰을 맞히는 다중 분류 문제로 볼 수 있습니다. 이 손실의 그래디언트를 직접 유도합니다.

2.1 forward: softmax → log → 정답 선택 → 평균

def forward(self, logits, labels):
    self.bsz, self.seqlen, self.vocab_size = logits.shape
    logits = logits.reshape(-1, self.vocab_size)   # (N, V),  N = bsz*seqlen
    self.labels = labels.reshape(-1)               # (N,)

    exp_logits = torch.exp(logits)
    sum_exp_logits = exp_logits.sum(-1, keepdim=True)
    self.softmax = exp_logits / sum_exp_logits     # p

    log_probs = torch.log(self.softmax)
    log_probs = log_probs[torch.arange(self.labels.shape[0]), self.labels]
    loss = -log_probs.mean()
    return loss

수식으로 정리하겠습니다. 토큰 위치를 \(i = 1, \dots, N\) (여기서 \(N = \text{bsz} \times \text{seqlen}\)), 어휘 인덱스를 \(c = 1, \dots, V\) 라 하면,

\[ p_{i,c} = \text{softmax}(z_i)_c = \frac{e^{z_{i,c}}}{\sum_{k=1}^{V} e^{z_{i,k}}}, \qquad L = -\frac{1}{N}\sum_{i=1}^{N} \log p_{i,\,y_i} \]

여기서 \(z_{i,c}\) 는 logit, \(y_i\) 는 위치 \(i\)의 정답 레이블입니다.

2.2 backward: “softmax − one-hot” 유도

목표는 logit에 대한 그래디언트 \(\bar z_{i,j} = \dfrac{\partial L}{\partial z_{i,j}}\) 입니다. 코드는 이를 두 단계(log-prob에 대한 그래디언트 → log-softmax 야코비안 통과)로 계산합니다.

Step 1. log-probability에 대한 그래디언트

\(L = -\frac{1}{N}\sum_i \log p_{i,y_i}\) 이므로, 각 위치의 정답 항 \(\log p_{i, y_i}\) 에 대한 미분만 \(-\frac{1}{N}\) 이고 나머지는 0입니다. 이를 어휘 차원 \(c\)에 대한 벡터로 쓰면 (정답 위치만 켜진 one-hot):

\[ g_{i,c} := \frac{\partial L}{\partial \log p_{i,c}} = -\frac{1}{N}\,\mathbb{1}[\,c = y_i\,] \]

코드에서는 이를 정확히 다음과 같이 구성합니다.

grad_log_prob = -torch.ones(self.bsz * self.seqlen) / (self.bsz * self.seqlen)  # -1/N
one_hot_mat = one_hot(self.labels, num_classes=self.vocab_size).to(torch.float32)
grad_log_prob = grad_log_prob.unsqueeze(-1) * one_hot_mat                        # g_{i,c}

Step 2. log-softmax의 야코비안

핵심은 log-softmax의 편미분입니다. \(\log p_{i,c} = z_{i,c} - \log \sum_k e^{z_{i,k}}\) 이므로,

\[ \frac{\partial \log p_{i,c}}{\partial z_{i,j}} = \underbrace{\delta_{cj}}_{z_{i,c}\text{의 직접 항}} - \underbrace{\frac{e^{z_{i,j}}}{\sum_k e^{z_{i,k}}}}_{\text{정규화 항}} = \delta_{cj} - p_{i,j} \]

여기서 \(\delta_{cj}\) 는 크로네커 델타(\(c = j\)일 때 1, 아니면 0)입니다.

Step 3. 연쇄법칙으로 합치기

\[ \bar z_{i,j} = \sum_{c=1}^{V} g_{i,c}\,\frac{\partial \log p_{i,c}}{\partial z_{i,j}} = \sum_{c} g_{i,c}\bigl(\delta_{cj} - p_{i,j}\bigr) = g_{i,j} - p_{i,j}\sum_{c} g_{i,c} \]

이 일반형이 코드의 다음 한 줄에 그대로 대응합니다.

grad_logits = grad_log_prob - grad_log_prob.sum(dim=-1, keepdim=True) * self.softmax
  • grad_log_prob \(= g_{i,j}\)
  • grad_log_prob.sum(dim=-1, keepdim=True) \(= \sum_c g_{i,c}\)
  • * self.softmax \(= \cdots \times p_{i,j}\)

Step 4. 깔끔한 닫힌 형태 확인

\(g_{i,c} = -\frac{1}{N}\mathbb{1}[c=y_i]\) 를 대입하면 \(\sum_c g_{i,c} = -\frac{1}{N}\) 이므로,

\[ \boxed{\;\bar z_{i,j} = \frac{1}{N}\bigl(p_{i,j} - \mathbb{1}[\,j = y_i\,]\bigr)\;} \]

즉 logit의 그래디언트는 “예측 확률 \(-\) 정답 one-hot” 을 샘플 수 \(N\)으로 나눈 것이라는 그 유명한 결과입니다. 직관적으로, 모델이 정답 클래스에 확신을 가질수록(\(p_{i,y_i} \to 1\)) 그래디언트가 0에 가까워지고, 오답 클래스에 확률을 줄수록 그쪽을 끌어내리는 방향의 그래디언트가 생깁니다. (코드는 굳이 Step 4까지 단순화하지 않고 Step 3의 일반형을 그대로 두었는데, 이는 임의의 상위 그래디언트 grad_output에 대해서도 동작하도록 더 범용적으로 작성한 것입니다.)

마무리: 형태 복원과 상위 그래디언트 곱

grad_logits = grad_logits.reshape(self.bsz, self.seqlen, self.vocab_size) * grad_output
grad_labels = self.labels.reshape(self.bsz, self.seqlen) * grad_output
  • (N, V) 로 펼쳤던 결과를 다시 (bsz, seqlen, V) 로 복원하고, 상위에서 내려온 grad_output(손실이 최종 목적함수이면 보통 1)을 곱합니다.
  • grad_labels: 레이블은 정수 인덱스라서 본질적으로 미분 불가능합니다. 여기 반환되는 값은 실제 학습에 쓰이는 그래디언트가 아니라, 그래디언트 검증 API의 텐서 형태(shape)를 맞추기 위한 형식적 자리표시입니다. 레이블에는 학습되는 파라미터가 없으므로 무시해도 됩니다.

테스트에서는 input_0(=logits)에 대한 그래디언트가 수치 미분과 일치함을 확인합니다(✓ CrossEntLoss input_0 test passed).

3. 전체 모듈의 역전파 (Backward of entire module)

지금까지 만든 모든 것을 결합하여 완전한 Transformer를 만듭니다. 이제 블록과 손실의 backward가 준비되었으니, 전체 모델의 backward는 forward의 정확한 역순 순회로 자연스럽게 완성됩니다.

3.1 forward 구조

def forward(self, tokens, labels=None):
    bsz, seqlen = tokens.shape
    h = self.embed(tokens)                      # 토큰 임베딩
    pos_ids = torch.arange(seqlen).reshape(1, -1)
    cos, sin = self.rope(pos_ids)               # RoPE 위치 인코딩

    mask = None
    if seqlen > 1:                              # causal mask (미래 토큰 차단)
        mask = torch.full((seqlen, seqlen), float("-inf"))
        mask = torch.triu(mask, diagonal=1)

    for i in range(self.n_layers):              # n개 블록 통과
        layer = getattr(self, f'layer_{i}')
        h = layer(h, cos, sin, mask)

    h = self.norm(h)                            # 최종 RMSNorm
    logits = self.output(h).squeeze(0)          # 출력 Linear → logits

    if labels is not None:
        loss = self.loss_fn(logits, labels)
        return logits, loss
    else:
        return logits

순전파의 데이터 흐름을 요약하면 다음과 같습니다.

\[ \text{tokens} \xrightarrow{\text{embed}} h_0 \xrightarrow{\text{layer}_0 \cdots \text{layer}_{L-1}} h_L \xrightarrow{\text{norm}} \hat h \xrightarrow{\text{output}} \text{logits} \xrightarrow{\text{loss\_fn}} \text{loss} \]

3.2 backward: 역순 순회

backward는 위 화살표를 모두 거꾸로 따라가며, 출력 쪽 그래디언트를 입력 쪽으로 전파합니다.

def backward(self, grad_logits, grad_loss=None):
    if grad_loss is not None:
        _grad_logits, grad_labels = self.loss_fn.backward(grad_loss)
        grad_logits += _grad_logits
    grad_h = self.output.backward(grad_logits)
    grad_h = self.norm.backward(grad_h)

    for i in reversed(range(self.n_layers)):
        layer = getattr(self, f'layer_{i}')
        grad_h, grad_cos, grad_sin = layer.backward(grad_h)

    grad_input = self.embed.backward(grad_h)

    return grad_input, grad_labels

단계별로 살펴보겠습니다.

  • (1) 손실로부터의 진입: forward가 logits와 loss 두 출력을 낼 수 있으므로, backward도 두 갈래의 상위 그래디언트를 받습니다. grad_loss가 주어지면(보통 1), loss_fn.backward(grad_loss)로 logits에 대한 그래디언트를 구해 외부에서 들어온 grad_logits에 더합니다(+=). 이는 logits가 (i) 손실 함수와 (ii) (선택적으로) 외부 경로 양쪽으로 흘러가므로, 두 경로의 그래디언트를 합산해야 한다는 다변수 연쇄법칙의 결과입니다.

  • (2) 출력 Linear와 최종 Norm: output.backward → norm.backward 순서로 통과시켜, 마지막 블록의 출력 \(h_L\)에 대한 그래디언트 grad_h를 얻습니다.

  • (3) 블록 역순 순회: reversed(range(self.n_layers))로 마지막 블록부터 첫 블록까지 거꾸로 순회합니다. 각 블록의 backward(1절에서 구현)가 이전 블록 출력에 대한 그래디언트를 반환하므로, grad_h를 계속 갱신하며 흘려보냅니다.

  • (4) 위치 그래디언트의 폐기: 각 블록은 \(\overline{\cos}, \overline{\sin}\) 도 반환하지만, 여기서는 매 반복마다 덮어쓰고 사용하지 않습니다. RoPE의 \(\cos, \sin\) 은 위치 인덱스(pos_ids)로부터 결정되는 고정·비학습(non-learnable) 상수이며, 위치 자체는 우리가 미분하려는 입력이 아니기 때문입니다. 따라서 누적할 필요가 없습니다.

  • (5) 임베딩까지: 마지막으로 embed.backward(grad_h)로 토큰 임베딩 테이블의 그래디언트를 누적하고, 입력에 대한 그래디언트 grad_input을 반환합니다.

3.3 검증

test_module("Transformer", ...)은 임베딩 테이블, 각 블록의 모든 어텐션/FFN 파라미터, 최종 출력 Linear에 이르기까지 32개 항목 전부에 대해 해석적 그래디언트와 수치 그래디언트가 일치함을 확인합니다(✓ ... test passed). 이는 우리가 1·2절에서 조립한 backward가 end-to-end로 정확함을 의미합니다.

정리 (Summary)

이번 실습에서 배운 핵심을 세 줄로 압축하면 다음과 같습니다.

  • 잔차 블록의 backward는 “직진(skip) 경로 + 서브모듈 경로의 합” 이며, 이 덧셈이 깊은 Transformer에서 그래디언트가 잘 흐르게 하는 비결입니다(\(\bar x = \bar y + f.\text{backward}(\bar y)\)).
  • softmax + cross-entropy의 logit 그래디언트는 \(\frac{1}{N}(p - \text{one-hot})\), 즉 “예측 확률에서 정답을 빼고 평균”이라는 놀랍도록 단순한 형태로 정리됩니다.
  • 전체 모델의 backward는 forward의 정확한 역순 순회이며, 비학습 상수(RoPE의 \(\cos/\sin\), causal mask)는 그래디언트를 무시하고, 한 변수가 여러 경로로 갈라지면 그래디언트는 합산합니다.

autograd가 내부적으로 수행하는 일을 직접 손으로 짜 봄으로써, “역전파는 마법이 아니라 연쇄법칙의 체계적 적용”이라는 점을 코드 한 줄 한 줄에서 확인할 수 있었습니다.
