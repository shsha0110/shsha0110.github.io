들어가며

이번 강의에서는 함수 제약 조건(functional constraints)이 있는 볼록 최적화 문제를 다룹니다. 단순한 집합 제약(set constraint)과 달리, \(g(x) \leq 0\)과 같은 볼록 함수 부등식 제약이 포함된 경우 사영(projection) 자체가 복잡해질 수 있어, 투영 경사 하강법(projected gradient descent)을 그대로 적용하기 어렵습니다.

이 문제를 해결하기 위해 두 가지 알고리즘을 살펴봅니다.

  • Nesterov의 이분법 기반 알고리즘 (Bisection-based Method): 최적값 \(f^*\)를 이분 탐색으로 추정하여 부문제(subproblem)를 반복적으로 풀어 나갑니다.
  • Polyak의 전환 알고리즘 (Switching Algorithm): \(f^*\)를 추정하지 않고 목적 함수와 제약 함수 간 경사를 직접 전환하여, 이론적으로 최적인 \(O(1/\varepsilon^2)\) 반복 복잡도를 달성합니다.

1. 문제 설정 (Problem Setup)

우리가 풀고자 하는 문제는 다음과 같습니다.

\[ \begin{aligned} \min_{x} \quad & f(x) \\ \text{subject to} \quad & g(x) \leq 0 \\ & x \in \mathcal{X} \end{aligned} \tag{18.1} \]

가정

  • \(f, g : \mathbb{R}^d \to \mathbb{R}\)은 모두 볼록 함수(convex function)이며 미분 가능(differentiable)하다고 가정합니다.
  • \(\mathcal{X} \subseteq \mathbb{R}^d\)는 볼록 집합(convex set)입니다.

목표

  • \(x^* \in \arg\min\{f(x) : g(x) \leq 0,\ x \in \mathcal{X}\}\)를 최적해라 할 때,
  • \(\varepsilon\)-근사 해(approximate solution) \(\hat{x}\)를 구하는 것이 목표입니다:

\[ g(\hat{x}) \leq \varepsilon \quad \text{and} \quad f(\hat{x}) - f(x^*) \leq \varepsilon. \]

즉, 실현 불가능성(infeasibility)과 목적 함수 오차 모두 \(\varepsilon\) 이내로 제어하는 점을 찾아야 합니다.

왜 투영 경사 하강법이 비효율적인가?

투영 경사 하강법(projected gradient descent)은 실현 가능 집합 \(\{x \in \mathcal{X} : g(x) \leq 0\}\) 에 대한 사영 연산을 매 반복마다 수행해야 합니다. 그런데 \(g\)가 복잡한 볼록 함수라면, 이 사영 자체를 계산하는 것이 또 다른 최적화 문제가 되어 전체 알고리즘이 비효율적으로 변할 수 있습니다. 이를 피하기 위해 아래 두 알고리즘을 사용합니다.

2. Nesterov의 이분법 기반 알고리즘 (Nesterov’s Bisection Method)

2.1 핵심 아이디어

만약 최적값 \(f^* = f(x^*)\)를 미리 알고 있다면, 문제 (18.1)의 \(\varepsilon\)-근사 해를 구하는 것은 다음의 단일 볼록 함수를 최소화하는 것과 동치입니다.

\[ h(x) := \max\{g(x),\ f(x) - f^*\} \]

이 함수 \(h\)는 두 볼록 함수의 점별 최대(pointwise maximum)이므로, 역시 볼록 함수입니다.

Lemma 18.1

\[\min_{x \in \mathcal{X}} h(x) = h(x^*) = 0\]

증명:

  • \(g(x^*) \leq 0\)이고 \(f(x^*) - f^* = 0\)이므로 \(h(x^*) = \max\{g(x^*), 0\} = 0\).
  • 임의의 \(x \in \mathcal{X}\)에 대해, 만약 \(g(x) \leq 0\)이면, \(f^*\)의 정의에 의해 \(f(x) - f^* \geq 0\)이므로 \(h(x) \geq 0\).
  • 따라서 \(\min_{x \in \mathcal{X}} h(x) = 0 = h(x^*)\). \(\square\)

이 보조정리는 \(h\)를 \(\mathcal{X}\) 위에서 최소화하면, 그 해가 곧 원래 문제 (18.1)의 해와 동치임을 보장합니다. \(h\)의 최소화에는 사영 준경사 하강법(projected subgradient method)을 적용할 수 있고, \(f\)와 \(g\)가 Lipschitz 연속이라면 \(O(1/\varepsilon^2)\) 반복 내에 \(\varepsilon\)-근사 해를 얻을 수 있습니다.

결론적으로, \(f^*\)만 잘 추정할 수 있다면 문제가 크게 단순화됩니다. Nesterov의 알고리즘은 바로 이 \(f^*\)를 이분 탐색(bisection)으로 추정합니다.

2.2 \(h_v\)의 정의와 준경사 (Subgradient of \(h_v\))

임의의 스칼라 \(v \in \mathbb{R}\)에 대해, \(f^*\) 대신 \(v\)를 대입한 함수를 정의합니다.

\[ h_v(x) := \max\{g(x),\ f(x) - v\} \]

이 함수의 준미분(subdifferential)은 다음과 같이 계산됩니다.

Lemma 18.2

\[ \partial h_v(x) = \begin{cases} \{\nabla g(x)\} & \text{if } g(x) > f(x) - v \\ \{\nabla f(x)\} & \text{if } g(x) < f(x) - v \\ \text{conv}\{\nabla g(x), \nabla f(x)\} & \text{if } g(x) = f(x) - v \end{cases} \]

  • 이는 볼록 함수의 점별 최대(pointwise max)에 대한 표준적인 준미분 공식입니다.
  • 실제로는 \(\nabla f(x)\)와 \(\nabla g(x)\)만 계산하면 준경사를 얻을 수 있어, 사영 준경사 하강법의 서브루틴으로 바로 활용 가능합니다.

2.3 알고리즘 상세 (Algorithm 1)

이분법을 적용하려면 \(f^*\)에 대한 하한 \(\ell\)과 상한 \(u\)가 필요합니다.

  • 예를 들어, \(\ell = \min_{x \in \mathcal{X}} f(x)\), \(u = f(x_0)\) (\(g(x_0) \leq 0\)인 실현 가능 초기점 \(x_0\))로 설정할 수 있습니다.
NoteAlgorithm 1: Bisection-based Method

입력: \(f^*\)에 대한 초기 하한/상한 \(\ell, u\), 정확도 \(\varepsilon > 0\)

반복 횟수 설정: \[N = \left\lceil \log_2 \frac{u - \ell}{\varepsilon/2} \right\rceil\]

알고리즘:

for t = 1, ..., N do
    v = (ℓ + u) / 2
    준경사 하강법으로 min_{x ∈ X} h_v(x)의 ε/2-근사 해 x_v를 구한다.

    if h_v(x_v) > ε/2 then
        ℓ = v       ← v가 f*의 하한임을 의미
    else
        u = v       ← v 이하에서 충분히 좋은 해가 있음
    end if
end for

return x_u

각 단계의 직관

조건 해석 업데이트
\(h_v(x_v) > \varepsilon/2\) \(v < f^*\)임을 의미 (최적값 추정 과소) \(\ell \leftarrow v\) (하한 올리기)
\(h_v(x_v) \leq \varepsilon/2\) \(x_v\)가 충분히 좋은 해 \(u \leftarrow v\) (상한 내리기)

매 반복마다 구간 \([u - \ell]\)이 절반으로 줄어들기 때문에, \(N = O(\log(1/\varepsilon))\) 번만에 \(u - \ell \leq \varepsilon/2\)가 됩니다.

2.4 수렴 분석 (Theorem 18.3)

Theorem 18.3

\(N = O(\log(1/\varepsilon))\)번의 이분법 반복 후, Algorithm 1은 문제 (18.1)의 \(\varepsilon\)-근사 해를 반환합니다. 각 부문제를 준경사 하강법으로 \(O(1/\varepsilon^2)\)회 안에 풀면, 총 반복 횟수는

\[O\!\left(\frac{1}{\varepsilon^2} \log \frac{1}{\varepsilon}\right)\]

입니다.

증명 개요

증명의 핵심은 모든 시간 단계에서 다음 두 불변조건(invariant)을 유지하는 것입니다.

\[\ell \leq f^* \quad \text{and} \quad h_u(x_u) \leq \varepsilon/2.\]

[\(\ell \leq f^*\) 유지]

  • 초기에 \(\ell \leq f^*\)가 성립한다고 가정합니다(귀납법).
  • \(h_v(x_v) > \varepsilon/2\)인 경우: \(x_v\)는 \(\min_{x \in \mathcal{X}} h_v(x)\)의 \(\varepsilon/2\)-근사 해이므로,

\[h^*(v) \geq h_v(x_v) - \varepsilon/2 > 0\]

이 성립합니다. \(h^*(v) > 0\)은 \(v < f^*\)를 의미하므로, \(\ell = v\)로 놓아도 \(\ell \leq f^*\)가 유지됩니다. - \(h_v(x_v) \leq \varepsilon/2\)인 경우: \(\ell\)은 그대로이므로 불변조건 유지.

[\(h_u(x_u) \leq \varepsilon/2\) 유지]

  • \(h^*(v)\)는 \(v\)에 대해 단조 감소 함수임에 주목합니다.
    • \(v\)가 커질수록 \(f(x) - v\)가 작아지므로 \(h_v\)의 최솟값도 감소합니다.
  • 초기 \(u\)에 대해 \(f^* \leq u\)이므로 \(h^*(u) \leq h^*(f^*) = 0\), 즉 \(h_u(x_u) \leq 0 + \varepsilon/2 = \varepsilon/2\).
  • \(u\)가 \(v\)로 갱신되는 경우에도 \(h_v(x_v) \leq \varepsilon/2\)이 성립하므로 불변조건 유지.

[최종 오차 경계]

\(N\)회 반복 후 \(u - \ell \leq \varepsilon/2\)이므로,

\[ g(x_u) \leq h_u(x_u) \leq \varepsilon/2 \leq \varepsilon \]

\[ f(x_u) - f^* \leq \underbrace{h_u(x_u)}_{\leq \varepsilon/2} + \underbrace{(u - f^*)}_{\leq u - \ell \leq \varepsilon/2} \leq \varepsilon \]

따라서 \(x_u\)는 \(\varepsilon\)-근사 해입니다. \(\square\)

복잡도 요약

단계 반복 횟수
이분법 (bisection) \(O(\log(1/\varepsilon))\)
각 부문제 (subgradient method) \(O(1/\varepsilon^2)\)
총 반복 횟수 \(O\!\left(\frac{1}{\varepsilon^2} \log \frac{1}{\varepsilon}\right)\)

이 \(O(\log(1/\varepsilon))\) 추가 인자가 Algorithm 1의 이론적 한계입니다. 다음 절의 Polyak 알고리즘은 이를 극복합니다.

3. Polyak의 전환 알고리즘 (Polyak’s Switching Algorithm)

3.1 동기 (Motivation)

Algorithm 1은 \(f^*\)를 추정하는 이분법 단계 때문에 최적 복잡도 \(O(1/\varepsilon^2)\)에 비해 \(O(\log(1/\varepsilon))\) 배 더 많은 반복이 필요합니다.

Polyak의 전환 알고리즘은 \(f^*\)를 추정하지 않고도 \(O(1/\varepsilon^2)\)의 최적 반복 복잡도를 달성합니다.

핵심 아이디어는 매우 직관적입니다.

  • 현재 점 \(x_t\)가 실현 가능 영역(feasible region) 안에 있으면 (\(g(x_t) \leq \varepsilon\)), 목적 함수 \(f\)를 줄이는 방향으로 경사 하강.
  • 현재 점이 실현 불가능 영역(infeasible region)에 있으면 (\(g(x_t) > \varepsilon\)), 제약 함수 \(g\)를 줄이는 방향으로 경사 하강.

이 두 가지를 상황에 따라 전환(switching)하며 반복합니다.

3.2 알고리즘 상세 (Algorithm 2)

NoteAlgorithm 2: Polyak’s Switching Algorithm

입력: 초기 해 \(x_1 \in \mathcal{X}\), 정확도 \(\varepsilon > 0\), 스텝 사이즈 \(\eta > 0\), 총 반복 횟수 \(T\)

알고리즘:

for t = 1, ..., T do
    if g(x_t) ≤ ε then
        d_t = ∇f(x_t)      ← 목적 함수 경사 사용
    else
        d_t = ∇g(x_t)      ← 제약 함수 경사 사용
    end if

    x_{t+1} = proj_X(x_t - η * d_t)    ← X 위로 사영
end for

return x̂ = argmin{f(x_t) : g(x_t) ≤ ε, t = 1, ..., T}

반환: 지금까지 실현 가능했던(\(g(x_t) \leq \varepsilon\)) 점들 중 \(f\) 값이 가장 작은 점.

직관적 이해

[이미지 생성 필요: 2차원 공간에서 볼록 실현 가능 집합과, 전환 알고리즘의 이동 궤적을 보여주는 다이어그램. 실현 가능 영역 안팎에서의 경사 방향 전환을 화살표로 표시.]

3.3 수렴 분석 (Theorem 18.4)

Theorem 18.4

\(f\)와 \(g\)가 모두 \(L\)-Lipschitz 연속이라 하자. 스텝 사이즈를

\[\eta = \frac{\varepsilon}{L^2}\]

로 설정하고 Algorithm 2를

\[T = O\!\left(\frac{1}{\varepsilon^2}\right)\]

번 반복하면, \(\varepsilon\)-근사 해를 반환합니다.

증명

[Step 1: 반복 점화식 유도]

\(\|\mathbf{d}_t\| \leq L\)임을 먼저 관찰합니다 (Lipschitz 연속성에 의해 경사의 크기가 \(L\) 이하). 사영 연산자의 비팽창성(non-expansiveness), 즉 \(\|\text{proj}_\mathcal{X}(a) - \text{proj}_\mathcal{X}(b)\| \leq \|a - b\|\)를 이용하면:

\[ \|x_{t+1} - x^*\|^2 = \|\text{proj}_\mathcal{X}(x_t - \eta d_t) - \text{proj}_\mathcal{X}(x^*)\|^2 \leq \|x_t - \eta d_t - x^*\|^2 \]

이를 전개하면:

\[ \|x_{t+1} - x^*\|^2 \leq \|x_t - x^*\|^2 - 2\eta\, d_t^\top(x_t - x^*) + \eta^2 \|d_t\|^2 \leq \|x_t - x^*\|^2 - 2\eta\, d_t^\top(x_t - x^*) + \eta^2 L^2 \]

[Step 2: 내적 항 합산]

위 부등식을 \(t = 1, \ldots, T\)에 대해 합산하고 텔레스코핑(telescoping)하면:

\[ \sum_{t=1}^{T} d_t^\top(x_t - x^*) \leq \frac{\|x_1 - x^*\|_2^2}{2\eta} + \frac{\eta T L^2}{2} \]

양변을 \(T\)로 나누면:

\[ \frac{1}{T}\sum_{t=1}^{T} d_t^\top(x_t - x^*) \leq \frac{\|x_1 - x^*\|_2^2}{2\eta T} + \frac{\eta L^2}{2} \]

따라서 최솟값에 대해서도:

\[ \min_{1 \leq t \leq T} d_t^\top(x_t - x^*) \leq \frac{\|x_1 - x^*\|_2^2}{2\eta T} + \frac{\eta L^2}{2} \tag{*} \]

[Step 3: 내적 항의 하한 분석]

각 \(t\)에 대해 두 가지 경우를 나눕니다.

  • 경우 1: \(g(x_t) \leq \varepsilon\)인 경우 → \(d_t = \nabla f(x_t)\). \(f\)의 볼록성에 의해:

\[f(x_t) - f(x^*) \leq \nabla f(x_t)^\top (x_t - x^*) = d_t^\top(x_t - x^*)\]

  • 경우 2: \(g(x_t) > \varepsilon\)인 경우 → \(d_t = \nabla g(x_t)\). \(g\)의 볼록성 및 \(g(x^*) \leq 0\)에 의해:

\[\varepsilon < g(x_t) \leq g(x_t) - g(x^*) \leq \nabla g(x_t)^\top (x_t - x^*) = d_t^\top(x_t - x^*)\]

두 경우를 결합하면:

\[ d_t^\top(x_t - x^*) \geq \min\!\left\{\varepsilon,\ \min\{f(x_t) - f(x^*) : g(x_t) \leq \varepsilon\}\right\} \]

[Step 4: 최종 부등식 도출]

Step 2의 결과 \((*)\)와 Step 3을 결합하면:

\[ \min\!\left\{\varepsilon,\ \min\{f(x_t) - f(x^*) : g(x_t) \leq \varepsilon,\ t = 1,\ldots,T\}\right\} \leq \frac{\|x_1 - x^*\|_2^2}{2\eta T} + \frac{\eta L^2}{2} \]

여기서 \(\eta = \varepsilon / L^2\), \(T \geq \frac{2L^2}{\varepsilon^2}\|x_1 - x^*\|_2^2\)으로 설정하면 우변은:

\[ \frac{\varepsilon}{4} + \frac{\varepsilon}{2} < \varepsilon \]

따라서:

\[ \min\!\left\{\varepsilon,\ \min\{f(x_t) - f(x^*) : g(x_t) \leq \varepsilon,\ t = 1,\ldots,T\}\right\} < \varepsilon \]

\(\min\{...\}\) 전체가 \(\varepsilon\)보다 작으므로, 두 번째 항도 반드시 \(\varepsilon\)보다 작아야 합니다. 즉,

\[ \min\{f(x_t) - f(x^*) : g(x_t) \leq \varepsilon,\ t = 1,\ldots,T\} < \varepsilon \]

이는 Algorithm 2의 출력 \(\hat{x}\)가 \(\varepsilon\)-근사 해임을 의미합니다. \(\square\)

  • 단, 스텝 사이즈 \(\eta = \varepsilon / L^2\)를 설정하려면 \(\varepsilon\)과 \(L\)을 미리 알아야 합니다.

4. 정리

이번 강의에서는 볼록 함수 제약 조건이 있는 최적화 문제를 풀기 위한 두 가지 접근법을 살펴보았습니다.

  • Nesterov의 이분법 기반 알고리즘은 이분 탐색으로 \(f^*\)를 추정한 뒤, 각 단계에서 준경사 하강법을 적용합니다. 총 복잡도는 \(O\!\left(\frac{1}{\varepsilon^2}\log\frac{1}{\varepsilon}\right)\)입니다.

  • Polyak의 전환 알고리즘은 \(f^*\) 추정 없이 목적 함수와 제약 함수 경사를 동적으로 전환하여, 볼록 최적화의 이론적 최적 복잡도인 \(O(1/\varepsilon^2)\)을 달성합니다.

두 알고리즘 모두, 복잡한 실현 가능 집합에 대한 직접적인 사영 없이 볼록 함수 제약 문제를 효율적으로 처리할 수 있다는 점에서 실용적 가치가 큽니다.
