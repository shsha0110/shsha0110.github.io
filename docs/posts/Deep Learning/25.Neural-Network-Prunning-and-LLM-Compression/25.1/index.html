들어가며 (Introduction)

이번 강의의 목표는 가지치기(Pruning)를 하나의 최적화 문제로 이해하는 것입니다. 즉, 핵심 질문은 다음과 같습니다.

성능은 최대한 보존하면서, 배포 비용(deployment cost)을 줄이기 위해 어떤 구성 요소를 제거할 것인가?

강의 전체를 관통하는 핵심 메시지는 다음 한 문장으로 요약됩니다.

\[ \text{파라미터 수 감소} \;\not\Rightarrow\; \text{추론 속도 향상} \]

즉, 단순히 파라미터를 줄이는 것만으로는 빨라지지 않습니다. 가지치기로 만들어진 구조(structure)가 하드웨어와 소프트웨어 스택에 맞아떨어질 때만 실제 가속이 일어납니다. 이 원칙을 머릿속에 두고 아래 내용을 따라가면 전체 흐름이 일관되게 이해됩니다.

강의는 다음 순서로 진행됩니다.

1. 가지치기의 기초 (Pruning fundamentals)

1.1 신경망 가지치기란 무엇인가 (What is neural network pruning?)

가지치기(Pruning) 는 학습이 끝난 신경망에서 파라미터나 구성 요소를 제거하는 기법입니다. 수학적으로는 이진 마스크(binary mask) \(M\) 을 곱하는 연산으로 정의됩니다.

\[ W \;\longrightarrow\; M \odot W, \]

여기서

  • \(W\) 는 원래의 가중치 텐서,
  • \(M\) 은 원소가 \(\{0, 1\}\) 인 동일한 크기의 이진 마스크,
  • \(\odot\) 는 원소별 곱(Hadamard product)입니다.

\(M\) 의 원소가 0이면 해당 위치의 가중치가 제거(zero-out)되고, 1이면 유지됩니다.

제거의 대상(prunable object)은 다양한 수준일 수 있습니다.

  • 개별 가중치(individual weight)
  • 채널(channel) 또는 필터(filter)
  • 어텐션 헤드(attention head)
  • MLP 뉴런(neuron)
  • 은닉 차원(hidden dimension)
  • 레이어 또는 블록 전체(entire layer or block)

1.2 압축 vs. 가속 (Compression vs. acceleration)

가지치기는 여러 종류의 배포 비용을 줄이는 것을 목표로 할 수 있습니다. 각 목표가 무엇을 줄이는지 구분하는 것이 중요합니다.

목표 (Goal) 무엇이 줄어드는가?
Model size 저장되는 파라미터의 수
Runtime memory 활성값 메모리 및 KV 캐시 / 중간 텐서
FLOPs 산술 연산의 수
Latency 실제 추론 소요 시간(wall-clock)
Energy 쿼리/샘플당 총 에너지

여기서 반드시 기억해야 할 결정적 구분이 있습니다.

  • 성긴(sparse) 모델은 0이 아닌 파라미터의 수가 더 적을 수는 있지만,
  • 표준 하드웨어에서 반드시 더 빠른 것은 아닙니다.

\[ \text{compression} \;\not\Rightarrow\; \text{acceleration}. \]

즉, 압축이 곧 가속을 의미하지는 않습니다. 이 점이 본 강의가 반복적으로 강조하는 핵심 통찰입니다.

1.3 가지치기의 입도 (Granularity of pruning)

제거하는 단위의 크기, 즉 입도(granularity) 에 따라 가지치기는 세 가지로 분류됩니다.

종류 제거 대상 결과 모델 표준 하드웨어 가속?
Unstructured 개별 가중치 성긴 행렬(sparse matrices) 보통 제한적
Semi-structured 고정된 성긴 패턴 (예: 2:4) 하드웨어 친화적 성긴 행렬 지원 시 가능
Structured 채널, 헤드, 뉴런, 레이어 더 작은 조밀(dense) 모델 보통 더 쉬움
  • 비정형(Unstructured) 가지치기는 가장 유연하지만, 불규칙한 희소성 때문에 가속이 어렵습니다.
  • 정형(Structured) 가지치기는 제거 단위가 크고 유연성이 떨어지지만, 기존의 조밀(dense) 커널로 가속하기가 훨씬 쉽습니다.

배포 원칙(Deployment principle): 정형 가지치기는 덜 유연하지만, 기존 dense 커널로 가속하기 훨씬 수월합니다.

1.5 무엇을 제거할지 어떻게 결정하는가 (Importance score)

대부분의 가지치기 기법은 중요도 점수(importance score) 를 정의하여, 점수가 낮은 구성 요소를 제거합니다.

점수 유형 예시
Magnitude (크기) \(\lvert w_i \rvert\)

일반적인 가지치기 파이프라인은 다음과 같습니다.

\[ \text{학습/로드} \to \text{구성요소 점수화} \to \text{낮은 점수 제거} \to \text{미세조정(fine-tune)} \]

1.6 일반화된 가지치기 목적함수 (A generic pruning objective)

가지치기 가능한 구성 요소를 \(c\) 로 인덱싱하고, 마스크 변수 \(m_c \in \{0, 1\}\) 가 구성 요소 \(c\) 의 유지 여부를 나타낸다고 합시다.

  • \(m_c = 1\) : 구성 요소 \(c\) 를 유지
  • \(m_c = 0\) : 구성 요소 \(c\) 를 제거

이때 가지치기는 다음 최적화 문제로 형식화됩니다.

\[ \min_{m,\, \theta'} \; L\bigl(f_{\theta', m}\bigr) \]

여기서 \(\theta'\) 는 (제거 후) 남은 파라미터, \(f_{\theta', m}\) 은 마스크 \(m\) 이 적용된 모델, \(L\) 은 손실입니다. 그리고 다음과 같은 자원 제약(resource constraint) 을 만족해야 합니다.

\[ \mathrm{Cost}(m) \;\leqslant\; B. \]

비용 \(\mathrm{Cost}(m)\) 의 예시로는 파라미터 수(#params), FLOPs, 지연(latency), 메모리 등이 있으며, \(B\) 는 허용되는 예산(budget)입니다.

핵심 난점(Main difficulty): 마스크 \(m\) 은 이산적(discrete)이고 고차원입니다. 따라서 정확한 최적화는 일반적으로 조합 최적화(combinatorial optimization) 문제가 됩니다.

이 조합적 난점을 어떻게 다룰 것인가가 이후 등장하는 모든 기법(특히 동적 계획법 기반의 깊이 압축)의 출발점입니다.

2. 고전적인 CNN 가지치기 (Classical CNN pruning)

2.1 비정형 가지치기: 학습 → 가지치기 → 재학습

Han et al. (NeurIPS 2015)은 크기(magnitude) 를 기준으로 개별 연결(connection)을 가지치기하는 방법을 제안했습니다. 절차는 세 단계로 이루어집니다.

  1. 조밀한 네트워크 학습 (Train dense network)
  2. 작은 가중치 가지치기 (Prune small weights)
  3. 성긴 네트워크 재학습 (Retrain sparse network)

마스크는 임계값 \(\tau\) 를 기준으로 다음과 같이 정의됩니다.

\[ M_i = \begin{cases} 1 & \lvert w_i \rvert \geqslant \tau, \\[4pt] 0 & \lvert w_i \rvert < \tau. \end{cases} \]

즉, 절댓값이 임계값보다 작은(=덜 중요하다고 판단되는) 가중치를 제거합니다. 가지치기된 모델은

\[ \tilde{W} = M \odot W \]

로 표현됩니다.

  • 강점: 매우 높은 희소성(sparsity)을 달성할 수 있습니다.
  • 약점: 불규칙한 희소성(irregular sparsity)은 전용 커널 없이는 가속이 어렵습니다.

이는 1.2절에서 본 “compression ≠ acceleration” 원칙의 대표적인 사례입니다.

2.2 정형 CNN 가지치기: 필터 / 채널 가지치기

합성곱 레이어의 가중치는 다음 형태를 가집니다.

\[ W^{(l)} \in \mathbb{R}^{C_{\text{out}} \times C_{\text{in}} \times K \times K}, \]

여기서 \(C_{\text{out}}\) 은 출력 채널 수, \(C_{\text{in}}\) 은 입력 채널 수, \(K\) 는 커널 크기입니다.

필터 가지치기(filter pruning) 는 출력 채널 하나를 통째로 제거합니다.

\[ W^{(l)}_{c, :, :, :} \;\text{제거}. \]

간단한 중요도 점수로는 필터 노름(filter norm) 을 사용합니다.

\[ \mathrm{score}(c) = \bigl\lVert W^{(l)}_{c, :, :, :} \bigr\rVert_1. \]

즉, \(L_1\) 노름이 작은 필터(전체적으로 작은 가중치를 가진 필터)를 제거합니다.

정형 가지치기가 가속될 수 있는 이유: 채널을 제거하면 다음 레이어가 더 작은 조밀한 합성곱이 됩니다. 이는 표준 라이브러리가 효율적으로 실행할 수 있습니다.

이것이 비정형 가지치기와의 결정적 차이입니다. (Li et al., ICLR 2017)

2.3 채널 가지치기는 인접 레이어에 영향을 준다 (Coupling)

채널 가지치기에서 반드시 주의할 점은, 레이어 \(l\) 의 출력 채널 \(c\) 를 제거하면 레이어 \(l+1\) 의 대응하는 입력 채널도 함께 제거되어야 한다는 것입니다.

  • 채널 \(c\) 를 만들어내는 생산자(producing) 필터 (\(W^{(l)}\) 의 일부)
  • 채널 \(c\) 를 소비하는 소비자(consuming) 입력 슬라이스 (\(W^{(l+1)}\) 의 일부)

이 둘은 일관되게(consistently) 함께 제거되어야 합니다.

커플링(Coupling): 정형 가지치기는 종종 여러 텐서에 걸쳐 결합된 행, 열, 채널, 차원을 함께 제거해야 합니다.

2.4 정확도–효율성 트레이드오프 (Accuracy–efficiency trade-off)

가지치기는 본질적으로 파레토 트레이드오프(Pareto trade-off) 를 만듭니다.

\[ \text{더 높은 압축} \;\Longleftrightarrow\; \text{더 큰 정확도 하락} \]

좋은 가지치기 방법은 이 곡선을 위쪽이자 오른쪽(upward and right) 으로 이동시킵니다.

3. CNN 깊이 압축 (CNN depth compression)

3.1 또 다른 가지치기 대상: 깊이 (Depth)

지금까지의 채널 가지치기는 네트워크의 폭(width) 을 줄였습니다. 이번에는 깊이(depth), 즉 순차적으로 수행되는 연산의 개수를 줄이는 접근을 봅니다.

\[ \text{폭 가지치기: } C \to C', \qquad \text{깊이 가지치기: } L \to L'. \]

깊이가 중요한 이유: FLOPs가 비슷하더라도, 순차 연산(sequential operations)의 수가 적으면 지연(latency)과 활성값 메모리(activation memory) 를 줄일 수 있습니다.

이는 현대 가속기에서 연산 자체보다 순차적 의존성과 메모리 이동이 병목인 경우가 많기 때문입니다.

3.2 언제 합성곱 레이어를 병합할 수 있는가? (When can layers be merged?)

핵심 아이디어는 두 선형 합성곱 사이에 비선형 활성화가 없으면 하나로 병합(merge)할 수 있다 는 것입니다.

\[ f_{\theta_2} \circ f_{\theta_1} = f_{\theta_2 * \theta_1}, \]

여기서 \(*\) 는 두 커널의 합성을 나타냅니다. 만약 두 커널이 모두 크기 \(K\) 라면, 병합된 커널의 크기는

\[ K_{\text{merged}} = 2K - 1 \]

이 됩니다. (예: \(K=3\) 인 두 합성곱을 병합하면 \(K_{\text{merged}} = 5\))

3.3 왜 활성화가 정확한 병합을 막는가 (Why activations block merging)

합성곱은 선형(linear) 연산입니다.

\[ f_\theta(ax + by) = a f_\theta(x) + b f_\theta(y). \]

따라서 두 선형 연산의 합성은 다시 하나의 선형 연산으로 표현 가능합니다. 그러나 ReLU와 같은 비선형 활성화는 선형이 아닙니다.

\[ \mathrm{ReLU}(ax + by) \neq a\,\mathrm{ReLU}(x) + b\,\mathrm{ReLU}(y). \]

그러므로 활성화 \(\sigma\) 가 사이에 끼어 있으면,

\[ f_{\theta_2} \circ \sigma \circ f_{\theta_1} \]

은 일반적으로 하나의 합성곱으로 접을 수 없습니다.

깊이 압축 아이디어: 선택된 활성화를 항등 함수(identity)로 대체한 뒤, 그렇게 만들어진 연속된 합성곱 레이어들을 추론 시점(inference time)에 병합합니다.

3.4 깊이 압축 목적함수 (Depth compression objective)

\(A \subseteq [L-1]\) 을 온전히 유지되는 활성화 레이어의 집합이라 합시다. 각 레이어 \(l\) 에 대해 활성화는 다음과 같이 정의됩니다.

\[ \sigma^A_l = \begin{cases} \sigma_l & l \in A \quad (\text{활성화 유지}), \\[4pt] \mathrm{id} & l \notin A \quad (\text{항등으로 대체}). \end{cases} \]

압축된 네트워크는 다음과 같이 표현됩니다.

\[ f_A = \prod_{l=1}^{L} \sigma^A_l \circ f_{\theta_l}. \]

(여기서 \(\prod\) 은 함수의 순차적 합성을 의미합니다.) 지연 제약을 둔 형식화는 다음과 같습니다.

\[ \max_{A} \; \mathrm{Acc}(f_A) \quad \text{s.t.} \quad T(f_A) \leqslant T_0, \]

즉 지연 예산 \(T_0\) 이하에서 정확도를 최대화하는 활성화 집합 \(A\) 를 찾는 문제입니다.

3.5 대리 함수: 블록 중요도와 블록 지연 (Surrogate)

\(A\) 에 속한 활성화들이 유지되면, 네트워크는 활성화를 경계로 하는 여러 블록(block) 으로 분할됩니다. 레이어 \(i+1\) 부터 \(j\) 까지의 블록에 대해 다음을 정의합니다.

  • \(I[i, j]\) : 내부 활성화를 항등으로 대체했을 때의 중요도(importance)
  • \(T[i, j]\) : 병합된 블록의 지연(latency)

그러면 전체 정확도와 지연을 블록 단위 합으로 근사합니다.

\[ \mathrm{Acc}(f_A) \approx \sum_{(i,j) \in \mathrm{blocks}(A)} I[i, j], \]

\[ T(f_A) \approx \sum_{(i,j) \in \mathrm{blocks}(A)} T[i, j]. \]

문제의 환원(Reduction): 이 근사를 통해 가지치기 문제는 지연 제약 하의 분할 문제(latency-constrained segmentation problem) 로 바뀝니다. 분할 문제는 동적 계획법으로 효율적으로 풀 수 있습니다.

3.6 동적 계획법 점화식 (Dynamic programming recurrence)

다음을 정의합니다.

\[ D[l, t] = \text{지연 예산 } t \text{ 하에서 레이어 } l \text{까지의 최대 중요도}. \]

마지막 블록이 레이어 \(l'\) 이후에 시작하여 \(l\) 에서 끝난다면, 점화식은 다음과 같습니다.

\[ D[l, t] = \max_{0 \leqslant l' < l} \Bigl( D[l', \, t - T[l', l]] + I[l', l] \Bigr). \]

  • \(D[l', t - T[l', l]]\) : 이전 경계 \(l'\) 까지의 최적 중요도 (블록의 지연을 예산에서 차감)
  • \(I[l', l]\) : 새로 추가되는 블록의 중요도

3.7 함정: 모든 병합이 지연을 줄이지는 않는다 (Pitfall)

표기 주의: 이 슬라이드에서는 합성곱 가중치를 \(\theta \in \mathbb{R}^{C_{\text{in}} \times C_{\text{out}} \times K \times K}\) 로 씁니다. 이는 앞서의 \(W \in \mathbb{R}^{C_{\text{out}} \times C_{\text{in}} \times K \times K}\) 와 첫 두 축을 맞바꾼 것일 뿐, 같은 가중치입니다(\(W[o,i,:,:] = \theta[i,o,:,:]\)).

다음 두 합성곱을 생각해봅시다.

  • 첫 번째: \(100 \to 1\), \(K = 3\)
  • 두 번째: \(1 \to 100\), \(K = 3\)

이 둘을 병합하면 유효 합성곱은

\[ 100 \to 100, \qquad K_{\text{merged}} = 3 + 3 - 1 = 5 \]

가 되고, 병합된 가중치의 형태는

\[ W_{\text{merged}} \in \mathbb{R}^{100 \times 100 \times 5 \times 5} \]

가 됩니다. 병합 전에는 중간 채널이 1개에 불과해 매우 가벼웠지만, 병합 후에는 \(100 \times 100 \times 5 \times 5\) 라는 훨씬 큰 텐서가 됩니다.

시사점(Takeaway): 병합은 레이어의 개수를 줄이지만, 개별 레이어의 비용을 오히려 증가시킬 수 있습니다. 따라서 깊이 압축은 반드시 지연 인식(latency-aware) 이어야 합니다.

3.8 2단계 지연 인식 깊이 압축 (Two-stage DP)

Kim et al. (ICML 2023)의 원래 깊이 압축 방법은 두 종류의 집합을 도입합니다.

  • \(A\) : 유지되는 활성화 레이어
  • \(S\) : 유지되는 병합 경계(merge boundaries)

\(S\) 의 목적은 해로운 병합(harmful merge)을 피하는 것입니다. 즉 3.7절에서 본 것처럼, 무작정 합치면 비용이 폭증할 수 있으므로, 중간에 병합 경계를 남겨 비용을 통제합니다.

1단계 DP: 내부 활성화가 없는 블록에 대한 최소 지연을 계산합니다.

\[ T_{\text{opt}}[i, j] = \min_{S} \sum_k T[s_{k-1}, s_k]. \]

2단계 DP: 지연 예산 하에서 활성화 집합 \(A\) 를 선택합니다.

\[ D[l, t] = \max_{l' < l} \; D[l', \, t - T_{\text{opt}}[l', l]] + I[l', l]. \]

핵심은, 2단계 DP에서 단순한 \(T[l', l]\) 대신 1단계에서 미리 최적화한 \(T_{\text{opt}}[l', l]\) 을 사용한다는 점입니다.

3.9 대표적인 깊이 압축 결과 (Representative results)

표에서 일관되게 관찰되는 점은, 모든 GPU에서 Ours 행이 비교 대상보다 더 빠르면서 정확도도 동등하거나 높다는 것입니다. 이는 지연 인식 DP가 단순한 휴리스틱 병합보다 우월함을 실증합니다.

4. LayerMerge

4.1 깊이 압축에서 LayerMerge로

기존 깊이 압축은 주로 활성화(activation)만 가지치기했습니다. LayerMerge 는 여기서 한 걸음 더 나아가, 합성곱 레이어 자체를 항등 커널로 대체하여 가지치기하는 것까지 허용합니다.

아이디어(Idea): 합성곱과 활성화 레이어를 동시에(jointly) 가지치기한 뒤, 테스트 시점에 연속된 선형 합성곱 블록을 병합합니다.

4.2 LayerMerge: 이산 선택 문제 (Discrete selection problem)

LayerMerge는 두 개의 집합을 동시에 최적화합니다.

  • \(A\) : 활성화 레이어를 유지하는 위치
  • \(C\) : 합성곱 레이어를 유지하는 위치

각 가지치기는 항등 대체로 표현됩니다.

  • 합성곱 레이어 \(l\) 을 가지치기: \(\;f_{\theta_l} \to \mathrm{id}\)
  • 활성화 레이어 \(l\) 을 가지치기: \(\;\sigma_l \to \mathrm{id}\)

난점(Challenge): 활성화와 합성곱의 최적 부분집합을 동시에 선택하는 것은 조합적(combinatorial) 입니다.

4.3 LayerMerge 대리 함수: 커널 크기 상태 (Kernel-size state)

순진하게(naively) 접근하면, 블록의 중요도와 지연은 어떤 내부 합성곱이 유지되는지(\(C\))에 따라 달라집니다.

\[ I[i, j, C], \qquad T[i, j, C]. \]

그러나 \(C\) 의 선택 가능성은 블록 길이에 대해 지수적(exponential) 으로 많습니다.

핵심 관찰(Key observation): 블록 내부에 활성화가 없을 때, 유지된 합성곱 집합 \(C\) 는 주로 병합 결과의 커널 크기 \(k\) 를 통해서만 최종 레이어에 영향을 줍니다.

따라서 상태를 \(C\) 전체가 아니라 커널 크기 \(k\) 로 요약하여 룩업 테이블(lookup table)을 사용합니다.

\[ I[i, j, k], \qquad T[i, j, k]. \]

이로써 상태 공간이 지수적에서 다룰 수 있는(feasible) 크기로 축소됩니다. 이것이 LayerMerge가 조합적 폭발을 회피하는 핵심 트릭입니다.

4.4 LayerMerge DP 점화식

다음을 정의합니다.

\[ M[l, t] = \text{지연 예산 } t \text{ 하에서 처음 } l \text{개 레이어에 대한 최대 중요도}. \]

마지막 압축 블록이 \(l'+1\) 부터 \(l\) 까지이고 병합된 커널 크기가 \(k\) 일 때, 점화식은 다음과 같습니다.

\[ M[l, t] = \max_{\substack{0 \leqslant l' < l \\ k \in \mathcal{K}_{l'l}}} \Bigl( M[l', \, t - T[l', l, k]] + I[l', l, k] \Bigr). \]

여기서 \(\mathcal{K}_{l'l}\) 은 블록 \((l', l]\) 에서 가능한 커널 크기들의 집합입니다.

해석: 이전 경계 \(l'\) 과 커널 크기 상태 \(k\) 를 함께 선택하여, 지연 예산 하에서 최선의 중요도를 주는 조합을 찾습니다. 즉 3.6절의 DP에 커널 크기라는 차원이 하나 추가된 형태입니다.

4.5 LayerMerge 결과 (Classification)

두 네트워크 모두에서 LayerMerge가 활성화만 가지치기하는 Depth 방법과 합성곱만 가지치기하는 LayerOnly를 모두 능가한다는 점이 핵심입니다. 이는 두 종류의 가지치기를 결합(joint)하는 것의 이득을 보여줍니다.

4.6 분류를 넘어서: LayerMerge의 확장 (Beyond classification)

LayerMerge의 결과는 이미지 분류와 확산 모델 생성(diffusion-model generation) 예시를 모두 포함하며, 적용 범위가 특정 과제에 국한되지 않음을 보여줍니다.

5. LLM 가지치기 (LLM pruning)

5.1 왜 LLM 가지치기는 다른가 (Why pruning LLMs is different)

CNN에서는 가지치기가 주로 합성곱 필터나 채널을 대상으로 합니다. 그러나 LLM에서는 배포 비용이 다음 요소들에 의해 지배됩니다.

  • 어텐션과 MLP 블록의 조밀한 행렬 곱(dense matrix multiplications)
  • 가중치를 위한 메모리 대역폭(memory bandwidth)
  • 생성 중의 KV 캐시 메모리(KV-cache memory)
  • 자기회귀 디코딩 지연(autoregressive decoding latency)

실용적 제약(Practical constraint): 가지치기된 LLM은 하드웨어가 지원하는 희소성을 사용하거나, 더 작은 조밀(dense) 모델이 되어야 실질적인 이득을 얻습니다.

5.2 트랜스포머 블록 해부 (Transformer block anatomy)

가지치기 가능한 트랜스포머 구성 요소: 가중치, 어텐션 헤드, MLP 뉴런, 은닉 차원, 레이어 전체.

5.3 LLM 가지치기 분류 체계 (Taxonomy)

계열 제거 대상 결과 대표 기법
Unstructured 개별 가중치 성긴 행렬 magnitude, SparseGPT, Wanda
Semi-structured 고정 패턴 가중치 하드웨어 친화적 희소성 2:4 sparsity
Structured width 헤드 / MLP 뉴런 / 은닉 차원 더 작은 조밀 모델 LLM-Pruner, SliceGPT, Sheared LLaMA
Structured depth 트랜스포머 블록 더 얕은 조밀 모델 ShortGPT, layer dropping

핵심 질문(Main question): 우리는 성긴 모델(sparse model) 을 원하는가, 아니면 더 작은 조밀 모델(smaller dense model) 을 원하는가? 이 선택이 어떤 기법을 쓸지를 결정합니다.

5.4 사후 학습(Post-training) LLM 가지치기

거대 언어 모델을 전부 재학습하는 것은 매우 비쌉니다. 그래서 많은 LLM 가지치기 기법은 사후 학습(post-training) 방식을 취합니다.

\[ \text{사전학습 LLM} \to \text{작은 보정(calibration) 집합} \to \text{가지치기된 LLM}. \]

보정 데이터(calibration data) 는 활성값 통계를 제공합니다.

\[ X \in \mathbb{R}^{n \times d}, \]

여기서 \(n\) 은 보정 샘플 수, \(d\) 는 입력 차원입니다. 가지치기 결정은 가중치와 활성값 모두에 의존할 수 있습니다.

활성값이 중요한 이유: 드물게 사용되는 입력 방향에 연결된 가중치는, 자주 사용되는 방향에 연결된 같은 크기의 가중치보다 덜 중요할 수 있습니다. 즉 가중치 크기만으로는 중요도를 충분히 판단할 수 없습니다.

5.5 크기 가지치기 vs. 활성값 인식 가지치기 (Wanda)

선형 레이어 \(y = XW\) (\(W \in \mathbb{R}^{d_{\text{in}} \times d_{\text{out}}}\))를 생각합시다.

단순 크기 가지치기는 다음 점수를 사용합니다.

\[ \mathrm{score}(W_{ij}) = \lvert W_{ij} \rvert. \]

Wanda (Sun et al., 2023)는 활성값 인식 점수를 사용합니다.

\[ \mathrm{score}(W_{ij}) = \lvert W_{ij} \rvert \cdot \lVert X_{:,i} \rVert_2, \]

여기서 \(X_{:,i}\) 는 입력 차원 \(i\) 에 대한 보정 활성값(열 벡터)이고, \(\lVert \cdot \rVert_2\) 는 \(L_2\) 노름입니다.

해석: 큰 가중치는 중요하지만, 큰 활성값 차원에 붙어 있는 가중치는 더욱 중요합니다. Wanda는 재학습 없이(no-retraining) 이 간단한 점수만으로 효과적인 가지치기를 달성합니다.

5.6 SparseGPT: 재구성 기반 가지치기 (Reconstruction-based)

입력 활성값 \(X\) 를 가진 레이어에 대해, SparseGPT (Frantar & Alistarh, 2023)는 가중치를 가지치기하면서도 레이어 출력을 보존하는 것을 목표로 합니다.

\[ XW \approx X\tilde{W}. \]

지역적 재구성 목적함수는 다음과 같습니다.

\[ \min_{\tilde{W}} \; \bigl\lVert XW - X\tilde{W} \bigr\rVert_F^2 \quad \text{s.t.} \quad \tilde{W} \text{ 가 성김(sparse)}, \]

여기서 \(\lVert \cdot \rVert_F\) 는 프로베니우스 노름(Frobenius norm)입니다. SparseGPT는 근사적 2차 정보(approximate second-order information) 를 사용하여, 가지치기 후 남은 가중치를 업데이트합니다.

핵심 아이디어: 단지 가중치를 삭제하는 데 그치지 않고, 남은 가중치를 조정하여 원래의 레이어 출력을 재구성합니다. 이것이 단순 크기 가지치기 대비 정확도를 크게 끌어올리는 비결입니다.

보충: 왜 2차 정보인가?

재구성 오차 \(\lVert XW - X\tilde{W} \rVert_F^2\) 를 가중치에 대해 전개하면, 헤시안에 해당하는 항이 입력 공분산 \(X^\top X\) 형태로 등장합니다. SparseGPT는 이 정보를 근사적으로 활용하여, 한 가중치를 0으로 만들었을 때 나머지 가중치를 어떻게 보정해야 출력 변화가 최소가 되는지를 결정합니다. 이는 고전적인 Optimal Brain Surgeon 계열 아이디어의 대규모 확장입니다.

5.7 준정형 희소성: 2:4 가지치기 (Semi-structured sparsity)

  • 그룹 정의: 4개 그룹이란 보통 한 차원을 따라 연속된 4개의 스칼라 가중치 \((W_{i,j}, W_{i,j+1}, W_{i,j+2}, W_{i,j+3})\) 를 의미합니다.
  • 2:4 규칙: 모든 4개 가중치 그룹 안에서 2개는 0이 아닌 값으로 유지, 2개는 0으로 가지치기합니다.

왜 중요한가: 2:4 희소성은 임의의 비정형 희소성보다 하드웨어 친화적입니다. 희소 패턴이 고정 크기 그룹 내로 제약되기 때문에, (NVIDIA Ampere 이후의) 전용 텐서 코어가 이를 가속할 수 있습니다.

5.8 트랜스포머의 정형 가지치기는 커플링을 요구한다

CNN에서와 마찬가지로(2.3절), 트랜스포머의 정형 가지치기도 결합된 구조를 함께 제거해야 합니다. MLP 중간 뉴런 \(j\) 를 가지치기하려면 다음을 모두 제거해야 합니다.

  • \(W_{\text{up}}\) 의 열(column) \(j\)
  • \(W_{\text{down}}\) 의 행(row) \(j\)

수식으로 보면 MLP 블록은 다음과 같습니다.

\[ h = \mathrm{GELU}(x W_{\text{up}}), \qquad y = h W_{\text{down}}. \]

여기서 GELU는 트랜스포머 MLP 내부의 비선형 활성화입니다. 중간 뉴런 \(j\) 를 가지치기한다는 것은 \(h_j\), \(W_{\text{up}}\) 의 대응 열, \(W_{\text{down}}\) 의 대응 행을 함께 제거하는 것을 의미합니다.

커플링 구조: 트랜스포머 가지치기는 종종 고립된 텐서가 아니라 파라미터 그룹을 가지치기하는 문제입니다.

5.9 LLM-Pruner: 회복 학습이 있는 정형 가지치기

LLM-Pruner (Ma et al., 2023)는 다음과 같은 정형 그룹을 제거합니다: 어텐션 헤드, MLP 뉴런, 결합된 은닉 차원.

전형적인 정형 가지치기 파이프라인은 다음과 같습니다.

\[ \text{결합 그룹 발견} \to \text{그룹 점수화} \to \text{낮은 점수 제거} \to \text{LoRA 회복 튜닝}. \]

왜 회복 학습(recovery tuning)인가? 정형 가지치기는 아키텍처 자체를 바꾸기 때문에 성능 손실이 발생합니다. 그러나 소량의 파라미터 효율적 미세조정(LoRA 등) 만으로도 손실된 성능의 상당 부분을 회복할 수 있습니다.

5.10 SliceGPT: 더 작고 조밀한 모델 만들기

SliceGPT (Ashkboos et al., 2024)는 가중치 행렬을 성기게 만드는 대신, 은닉 차원(hidden dimension) 자체를 줄입니다.

\[ d_{\text{model}} \to d'_{\text{model}}. \]

그러면 조밀한 행렬이 더 작아집니다.

\[ W \in \mathbb{R}^{d \times d} \;\longrightarrow\; W' \in \mathbb{R}^{d' \times d'}. \]

배포 이점: 결과 모델이 여전히 조밀(dense) 하므로, 표준 dense 행렬 곱 커널을 그대로 사용할 수 있습니다. 이는 표현 차원(representation-dimension) 수준의 정형 가지치기로 볼 수 있습니다.

5.11 LLM을 위한 레이어 가지치기 (Layer pruning)

LLM에는 중복된(redundant) 트랜스포머 블록이 존재할 수 있습니다. 트랜스포머 레이어를

\[ x_{l+1} = F_l(x_l) \]

로 표현하면, 해당 블록이 입력을 얼마나 바꾸는지를 나타내는 간단한 영향력 측정(influence measure) 을 정의할 수 있습니다.

\[ \mathrm{Influence}(l) = \frac{\lVert F_l(x_l) - x_l \rVert}{\lVert x_l \rVert}. \]

  • 분자 \(\lVert F_l(x_l) - x_l \rVert\) : 블록이 입력에 가한 변화의 크기
  • 분모 \(\lVert x_l \rVert\) : 정규화를 위한 입력의 크기

영향력이 작은 레이어, 즉 \(F_l(x_l) \approx x_l\) 인 레이어는 제거 후보가 됩니다. (잔차 연결 덕분에 블록을 건너뛰어도 입력이 거의 그대로 보존되기 때문입니다.) (Men et al., ShortGPT, 2024)

CNN 깊이 압축과의 연결: CNN 깊이 압축과 LLM 레이어 가지치기는 모두 깊이 방향의 중복(redundancy along depth) 을 활용한다는 공통 원리를 공유합니다.

5.12 Sheared LLaMA: 가지치기로 더 작은 LLM 만들기

또 다른 영역은, 가지치기를 단순한 배포용 압축이 아니라 큰 모델로부터 더 작은 파운데이션 모델을 생성하는 수단으로 사용하는 것입니다.

가지치기 가능한 구조: 레이어, 어텐션 헤드, MLP 중간 차원, 은닉 차원.

파이프라인은 다음과 같습니다.

\[ \text{큰 사전학습 LLM} \to \text{정형 가지치기} \to \text{계속 사전학습(continued pretraining)} \to \text{작은 LLM}. \]

메시지: 가지치기는 최종 압축 단계로만 쓰이는 것이 아니라, 효율적인 작은 모델을 초기화(initialize)하는 방법으로도 활용될 수 있습니다. (Xia et al., Sheared LLaMA, 2023)

5.13 LLM 가지치기 평가 (Evaluation)

CNN 가지치기는 주로 정확도와 지연을 보고하지만, LLM 가지치기는 일반적으로 다음을 보고합니다.

  • 언어 모델링 코퍼스에서의 퍼플렉서티(perplexity)
  • 제로샷/퓨샷 벤치마크 정확도
  • 지시 따르기(instruction-following) 또는 추론 품질
  • 메모리 풋프린트(memory footprint)
  • 디코딩 처리량(decoding throughput)
  • 생성 토큰당 지연(latency per generated token)

주의(Caution): 파라미터 수를 개선하는 가지치기 방법이라도, 가지치기된 구조가 하드웨어 효율적이지 않으면 tokens/sec를 개선하지 못할 수 있습니다. (1.2절의 원칙이 LLM에서도 그대로 적용됩니다.)

6.4 강의 요약 (Lecture summary)

  • 가지치기는 성능을 보존하려 노력하면서 가중치나 구성 요소를 제거합니다.
  • 비정형 희소성은 파라미터를 줄이지만, 표준 하드웨어를 가속하지 못할 수 있습니다.
  • 정형 가지치기는 더 작은 조밀 모델을 만들어 배포가 쉬운 경우가 많습니다.
  • CNN 깊이 압축은 활성화를 제거하고 합성곱을 병합하되, 반드시 지연 인식이어야 합니다.
  • LayerMerge는 합성곱과 활성화 레이어를 동시에 가지치기합니다.
  • LLM 가지치기는 가중치 희소성, 헤드/뉴런 가지치기, 은닉 차원 가지치기, 레이어 가지치기를 포괄합니다.
  • CNN과 LLM 모두에서 핵심 지표는 파라미터 수가 아니라 배포 파레토 프론티어(deployment Pareto frontier) 입니다.

6.5 최종 시사점 (Final takeaway)

가지치기는 단순히 작은 가중치를 삭제하는 작업이 아닙니다. 좋은 가지치기는 다음 세 요소의 결합입니다.

\[ \text{좋은 가지치기} = \text{중요도 추정} + \text{구조적 탐색} + \text{하드웨어 인식 배포} \]

현대 모델에서 CNN 가지치기와 LLM 가지치기는 같은 원리를 공유합니다.

원리(Principle): 추론 시스템이 실제로 활용할 수 있는 형태로 중복(redundancy)을 제거하라.

이 한 문장이 본 강의 전체를 관통하는 결론입니다. 파라미터를 줄이는 것 자체가 목적이 아니라, 그 감소가 실제 배포 환경에서 측정 가능한 이득(지연, 메모리, 처리량) 으로 이어지도록 만드는 것이 가지치기 연구의 본질입니다.
