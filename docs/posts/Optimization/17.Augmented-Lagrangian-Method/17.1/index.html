1. Introduction

  • 최적화 및 기계학습 모델링을 수행하다 보면, 목적 함수(Objective function)는 여러 변수들의 독립적인 합으로 나누어지지만, 제약 조건(Constraints) 때문에 변수들이 서로 얽혀 있는 상황을 자주 마주하게 됩니다. 이번 포스트에서는 서울대학교 이다빈 교수님의 수리 및 수치 최적화 강의(Lecture #17)를 바탕으로, 이러한 분리 가능한 문제(Separable problems)를 효율적으로 풀기 위한 쌍대 기울기법(Dual gradient method)에 대해 깊이 있게 살펴보겠습니다.

  • 원래 이번 강의의 전체 아웃라인은 다음과 같이 세 가지 주요 주제를 다룹니다:

      1. 분리 가능한 문제를 위한 쌍대 기울기법 (Dual gradient method for separable problems)
      1. 증강 라그랑지안 기법 (Augmented Lagrangian method)
      1. 복합 최소화 문제의 쌍대성 (Dual of composite minimization problems)

  • 이번 글에서는 제공된 노트의 첫 번째 파트인 ‘분리 가능한 문제를 위한 쌍대 기울기법’의 수학적 도출 과정과 알고리즘적 직관에 집중하여 해설합니다.

2. Core Concepts

  • 우리가 다루고자 하는 핵심적인 동기(Motivation)는 “변수 간의 연결 고리를 어떻게 끊어내어 병렬 처리가 가능하게 만들 것인가?” 입니다.

  • 만약 제약 조건이 없다면, 변수 \(x_1\)과 \(x_2\)에 대한 목적 함수를 각각 독립적으로 최소화하면 됩니다. 그러나 현실의 많은 시스템(예: 네트워크 라우팅, 자원 할당 문제, 연합 학습 등)에서는 한 변수의 결정이 다른 변수의 결정에 영향을 미치는 연결 제약(Linking constraints)이 존재합니다.

  • 이러한 상황에서 쌍대성(Duality), 특히 라그랑지안 승수(Lagrangian multiplier)를 도입하면 제약 조건을 목적 함수로 끌어올려 변수 간의 물리적 결합을 수학적으로 분리(Decoupling)할 수 있습니다.

3. Mathematical Formulation

  • 수학적으로 우리가 풀고자 하는 원문제(Primal Problem)는 다음과 같이 정의됩니다:

\[minimize \quad f_1(x_1) + f_2(x_2)\] \[subject\;to \quad A_1x_1 + A_2x_2 = b\]

  • 여기서 목적 함수 \(f_1(x_1) + f_2(x_2)\)는 분리 가능(Separable)합니다.

  • 식 \(A_1x_1 + A_2x_2 = b\)는 변수 \(x_1\)과 \(x_2\)를 묶고 있는 선형 연결 제약 조건입니다.

  • 이 문제를 풀기 위해 라그랑지안 승수(Lagrangian multiplier) \(\mu\)를 도입하여 제약 조건을 완화한 라그랑지안 쌍대 함수(Lagrangian dual function)를 구성해 봅시다. 라그랑지안 쌍대 함수는 다음과 같이 주어집니다:

\[\inf_{x_1, x_2} \{f_1(x_1) + f_2(x_2) + \mu^\top(A_1x_1 + A_2x_2 - b)\}\]

4. Detailed Derivations

  • 이제 위에서 정의한 라그랑지안 쌍대 함수를 닫힌 형태(Closed-form)나 더 다루기 쉬운 형태로 변형해 보겠습니다. 이 과정에서 볼록 해석학(Convex Analysis)의 핵심 개념인 볼록 켤레 함수(Convex Conjugate Function, Fenchel conjugate)가 사용됩니다.

4.1. 라그랑지안 쌍대 함수의 분리

  • 라그랑지안 쌍대 함수를 전개하여 \(x_1\)과 \(x_2\)에 대한 항으로 묶어보면 다음과 같이 완벽하게 두 개의 독립적인 최소화 문제로 분리됩니다:

\[= -b^\top\mu + \inf_{x_1} \{f_1(x_1) + \mu^\top A_1 x_1\} + \inf_{x_2} \{f_2(x_2) + \mu^\top A_2 x_2\}\]

4.2. 볼록 켤레(Convex Conjugate)의 적용

  • 볼록 함수 \(f(x)\)에 대한 켤레 함수 \(f^*(y)\)는 \(f^*(y) = \sup_x \{y^\top x - f(x)\}\) 로 정의됩니다. 이를 이용해 위의 \(\inf\) 항들을 \(\sup\) 형태로 변환할 수 있습니다.

\[\inf_{x_1} \{f_1(x_1) + \mu^\top A_1 x_1\} = -\sup_{x_1} \{-f_1(x_1) + (-A_1^\top\mu)^\top x_1\} = -f_1^*(-A_1^\top\mu)\]

  • 마찬가지로 \(x_2\)에 대해서도 동일한 전개가 성립합니다:

\[\inf_{x_2} \{f_2(x_2) + \mu^\top A_2 x_2\} = -\sup_{x_2} \{-f_2(x_2) + (-A_2^\top\mu)^\top x_2\} = -f_2^*(-A_2^\top\mu)\]

  • 따라서, 최종적인 라그랑지안 쌍대 함수는 다음과 같이 도출됩니다:

\[g(\mu) = -b^\top\mu - f_1^*(-A_1^\top\mu) - f_2^*(-A_2^\top\mu)\]

4.3. 쌍대 문제(Dual Problem)의 정립

  • 원문제에 대한 라그랑지안 쌍대 문제는 \(\mu\)에 대해 \(g(\mu)\)를 최대화하는 것입니다:

\[maximize \quad -f_1^*(-A_1^\top\mu) - f_2^*(-A_2^\top\mu) - b^\top\mu\]

  • 최대화 문제는 목적 함수에 음수를 취하여 최소화 문제로 동치 변환할 수 있으므로, 다음과 같은 볼록 최소화 문제(Convex minimization problem)를 얻게 됩니다:

\[minimize \quad f_1^*(-A_1^\top\mu) + f_2^*(-A_2^\top\mu) + b^\top\mu\]

  • 이로써 우리는 다루기 까다로웠던 제약 조건이 있는 원문제 대신, 제약 조건이 없는(Unconstrained) 쌍대 문제를 얻었습니다.

4.4. 쌍대 함수의 서브그라디언트(Subgradient) 계산

  • 위 쌍대 문제를 기울기법(Gradient method)이나 서브그라디언트 방법(Subgradient method)으로 풀기 위해서는 목적 함수의 기울기(또는 서브그라디언트)를 구해야 합니다.
  • 주어진 \(\mu_t\)에서 쌍대 목적 함수의 서브그라디언트 \(g_t\)는 연쇄 법칙(Chain rule)에 의해 다음과 같이 계산됩니다:

\[g_t \in \partial(f_1^*(-A_1^\top\mu_t) + f_2^*(-A_2^\top\mu_t) + b^\top\mu_t) = -A_1\partial f_1^*(-A_1^\top\mu_t) - A_2\partial f_2^*(-A_2^\top\mu_t) + b\]

  • 여기서 아주 우아한 켤레 함수의 성질(Conjugate subgradient property)이 등장합니다. \(x \in \partial f^*(y)\) 이기 위한 필요충분조건은 \(y \in \partial f(x)\) 입니다.
  • 이를 \(x_{1,t}\)에 적용해봅시다:

\[x_{1,t} \in \partial f_1^*(-A_1^\top\mu_t) \iff -A_1^\top\mu_t \in \partial f_1(x_{1,t})\]

  • 이는 결국 다음의 국소적 최소화 문제를 푸는 것과 완벽히 동치입니다:

\[x_{1,t} \in argmin_{x_1} \{f_1(x_1) + \mu_t^\top A_1 x_1\}\]

  • 유사하게 \(x_{2,t}\)에 대해서도 동일한 논리가 전개됩니다:

\[x_{2,t} \in argmin_{x_2} \{f_2(x_2) + \mu_t^\top A_2 x_2\}\]

5. Algorithm & Interpretation

  • 위의 유도 과정을 바탕으로, 쌍대 변수 \(\mu_t\)를 업데이트하는 규칙은 다음과 같이 정의됩니다:

\[\mu_{t+1} = \mu_t + \eta_t(A_1x_{1,t} + A_2x_{2,t} - b)\]

  • 이를 하나의 알고리즘 프레임워크로 묶으면 다음과 같습니다.

Algorithm 1: Subgradient method for the dual problem of a separable minimization

  • 초기화(Initialize): \(\mu_1\) 설정
  • 반복(For \(t=1,...,T-1\) do):
      1. 각 변수에 대해 다음의 독립적인 부분 문제(Subproblem)를 풉니다. \[x_{1,t} \in argmin_{x_1} \{f_1(x_1) + \mu_t^\top A_1 x_1\}\] \[x_{2,t} \in argmin_{x_2} \{f_2(x_2) + \mu_t^\top A_2 x_2\}\]
      1. 스텝 사이즈 \(\eta_t > 0\) 를 이용하여 쌍대 변수를 업데이트합니다. \[\mu_{t+1} = \mu_t + \eta_t(A_1x_{1,t} + A_2x_{2,t} - b)\]
  • 종료(End for)

해석 및 직관 (Interpretation)

  • 원문제(Primal problem)에서는 변수 \(x_1\)과 \(x_2\)가 제약 조건 \(A_1x_1 + A_2x_2 = b\)를 통해 강하게 결합되어 있어 동시에 최적화하기 까다로웠습니다. 그러나 쌍대 방법(Dual method)에서는 라그랑지안 승수 \(\mu\)를 통해 변수 \(x_1\)과 \(x_2\)를 완벽하게 분리(Separate)할 수 있었습니다.

  • 가장 중요한 실무적 이점은 병렬 연산(Parallel computation)입니다. 매 반복(Iteration) 단계에서 \(x_{1,t}\)를 계산하는 과정과 \(x_{2,t}\)를 계산하는 과정은 서로 아무런 영향을 주지 않으므로 분산 컴퓨팅 환경에서 완전히 병렬로 수행될 수 있습니다. 각 워커(Worker) 노드들이 자기 할당량(\(x_1\), \(x_2\))을 최적화하여 마스터 노드에 전달하면, 마스터 노드는 식 오차 \((A_1x_{1,t} + A_2x_{2,t} - b)\)를 계산하여 \(\mu\)를 한 번만 업데이트 해주면 됩니다.
