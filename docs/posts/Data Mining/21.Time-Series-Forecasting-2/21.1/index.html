1. Introduction

  • 시계열 예측(Time Series Forecasting)은 과거의 데이터를 기반으로 미래의 패턴을 추론하는 중요한 태스크입니다. 본 포스트에서는 가장 단순한 형태인 선형 회귀(Linear Regression)에서 출발하여, 이를 심층 신경망(Multi-layer Perceptrons, MLPs)으로 일반화하는 과정을 살펴봅니다. 더 나아가, 시계열 데이터가 가지는 순차적(sequential) 특성을 효과적으로 모델링하기 위해 상태 공간 모델(State-Space Model, SSM)의 개념을 신경망에 도입한 순환 신경망(Recurrent Neural Networks, RNN)의 구조와 특징을 수학적 수식과 함께 상세히 다루겠습니다.

2. 선형 회귀에서 다층 퍼셉트론(MLP)으로의 확장

2.1. 선형 회귀 (Linear Regression)의 재해석

  • 시계열 예측을 위한 가장 기본적인 모델은 선형 회귀입니다. 신경망의 관점에서 선형 회귀는 단일 뉴런(single neuron)으로 간주할 수 있습니다. 특정 시점 \(t\)에서의 입력 피처(feature)를 \(x_{t}\)라고 할 때, 출력 예측값 \(\hat{z}_{t}\)는 가중치(weight) 벡터 \(w\)와 편향(bias) \(b\)의 선형 결합으로 표현됩니다.

\[\hat{z}_{t} = w^{\top}x_{t} + b\]

  • 위 그림에서 보듯, 선형 회귀는 각 시점의 데이터를 독립적으로 처리하므로, 과거의 정보가 현재의 예측에 직접적으로 전달되지 않는 한계를 지닙니다.

2.2. 다층 퍼셉트론 (MLPs)을 통한 일반화

  • 선형 회귀의 단순한 맵핑(mapping)을 심층 신경망(Deep Neural Network)으로 일반화하여 모델의 표현력을 비약적으로 높일 수 있습니다. 이제 출력 \(\hat{z}_{t}\)는 입력 \(x_{t}\)에 대한 임의의 비선형 함수 \(f\)를 통해 모델링됩니다.

\[\hat{z}_{t} = f(x_{t})\]

  • 함수 \(f\)를 다층 퍼셉트론(MLP)으로 구성하면, 모델은 여러 은닉층(hidden layers)을 거치며 복잡한 패턴을 학습하게 됩니다. 이를 수식으로 전개하면 다음과 같습니다.

\[z_{t} = \sigma\left(w_{l}^{\top}\left(\sigma\left(W_{l-1}^{\top}\left(\dots W_{0}^{\top}x_{t}\right)\right)\right)\right) := \text{DEEP-NET}(x_{t})\]

  • 여기서 \(W_{k}\)는 \(k\)번째 층의 가중치 행렬이며, \(\sigma\)는 비선형 활성화 함수(Activation function, 예: ReLU, Sigmoid 등)를 의미합니다.

2.2.1. MLPs의 장단점

  • MLP를 시계열 분석에 도입할 경우 다음과 같은 트레이드오프가 발생합니다.

  • 장점 (Advantages):

    • 변수 간의 복잡한 비선형 관계를 학습할 수 있습니다.
    • 도메인 지식에 의존하는 수작업 특성 공학(Feature engineering)의 필요성을 크게 줄여줍니다.

  • 단점 (Disadvantages):

    • 충분한 패턴 학습을 위해 선형 회귀보다 훨씬 더 많은 양의 훈련 데이터가 요구됩니다.
    • 과적합 방지를 위한 정규화(regularization) 등 세심한 튜닝이 필수적입니다.
    • 입력 데이터의 스케일링(scaling)에 매우 민감합니다.
    • 모델 파라미터 증가로 인해 더 많은 컴퓨팅 자원과 시간이 소요됩니다.

3. 순환 모델(Recurrent Models)을 향하여

  • MLP는 강력한 비선형 표현력을 제공하지만, 여전히 각 시점을 독립적으로 처리하므로 시계열 고유의 순차적(sequential) 관계를 자연스럽게 반영하지 못합니다. 과거의 상태가 현재에 미치는 영향을 모델링하기 위해, 전통적인 통계학의 상태 공간 모델(State-Space Model, SSM) 구조를 살펴봅니다.

3.1. 상태 공간 모델 (State-Space Model)

  • 상태 공간 모델에서는 겉으로 관측되지 않는 잠재 상태(latent state) \(l_t\)가 존재하며, 이 상태가 시간에 따라 전이(transition)된다고 가정합니다.
    • 상태 전이 (State Transition): 과거의 상태 \(l_{t-1}\)에 노이즈 \(\epsilon_t\)가 더해져 현재 상태 \(l_t\)가 형성됩니다. \[l_{t} = l_{t-1} + \alpha \cdot \epsilon_{t}\]
    • 관측/출력 (Observation): 현재 상태 \(l_t\)와 현재 입력 \(x_t\)의 선형 결합으로 최종 관측값 \(z_t\)가 도출됩니다. \[z_{t} = v^{\top}l_{t} + w^{\top}x_{t} + \epsilon_{t}\]

4. 순환 신경망 (Recurrent Neural Networks, RNNs)

  • 상태 공간 모델(SSM)이 보여준 ‘과거 상태의 순차적 전이’라는 아이디어를, 다층 퍼셉트론(MLP)의 ‘비선형 함수 매핑’과 결합한 것이 바로 순환 신경망(RNN)입니다.

4.1. SSM과 RNN의 구조적 비교

  • 두 모델은 과거의 정보(상태)를 현재로 전달한다는 기본 철학을 공유하지만, 전이 방식과 수식 구조에서 큰 차이를 보입니다.

4.2. RNN의 수학적 공식화

  • RNN의 핵심 아이디어는 시점 \(t\)에서의 은닉 상태(hidden state) \(h_{t}\)가 이전 상태와 현재 입력의 선형 결합에 그치지 않고, 비선형 활성화 함수(Nonlinear function)를 통과하여 결정된다는 점입니다.
  • RNN의 연산 과정은 다음 두 수식으로 명확히 정의됩니다.
    1. 은닉 상태 업데이트 (Hidden State Update): \[h_{t} = \sigma(\theta_{0}h_{t-1} + \theta_{1}x_{t})\]
    • (이전 상태 \(h_{t-1}\)과 현재 피처 \(x_{t}\)에 가중치 \(\theta_0, \theta_1\)을 곱해 더한 후, 활성화 함수 \(\sigma\)를 통과시킵니다.)
    1. 출력 생성 (Output Generation): \[z_{t} = \sigma(\theta h_{t})\]
    • (업데이트된 현재 상태 \(h_{t}\)를 바탕으로 새로운 가중치 \(\theta\)를 적용하고 다시 비선형 함수를 거쳐 시점 \(t\)의 정보 \(z_t\)를 생성합니다.)

4.3. 계층(Layers)으로서의 상태 전이 (State Transition)

  • RNN을 이해하는 매우 중요한 관점은 시간의 흐름(Sequence) 자체를 신경망의 깊이(Depth)로 해석하는 것입니다.
    • RNN의 각 시점(시간 스텝 \(t\))은 마치 깊은 MLP 구조에서의 한 층(Layer)처럼 작동합니다.
    • 매 상태 전이마다 활성화 함수 \(\sigma\)가 적용되므로, 시퀀스가 길어질수록 비선형성이 계속해서 중첩·누적됩니다.

4.3.1. 순환 구조의 장단점

  • 장점 (Pros): 강력한 표현력(expressive power)을 가집니다. 시퀀스가 진행됨에 따라 은닉 상태 \(h_t\)는 과거의 모든 입력 정보를 축적하게 되어 매우 풍부한(richer) 문맥적 요약본이 됩니다.
  • 단점 (Cons): 시간 스텝이 길어지면 신경망의 층이 너무 많아지는 것과 같은 문제가 발생합니다(Too many layers). 연산 경로(computational path)가 지나치게 길어지면 역전파(Backpropagation) 과정에서 기울기 소실이나 폭발 현상이 발생하여 학습이 매우 불안정해집니다.

5. 시퀀스 요약과 Projection Head

  • 학습된 RNN을 사용하여 실제 스칼라 타겟 값(예: 미래의 매출액, 온도 등)을 예측하기 위해 Projection Head라는 개념을 도입합니다.

5.1. 시퀀스 인코딩과 요약

  • 입력 시계열 데이터가 \(x = (x_{1}, \dots, x_{t})\) 로 주어졌을 때, RNN 모델은 이를 처리하여 크기가 \(t \times h\)인 전체 은닉 상태 행렬 \(H = \text{RNN}(x)\)를 생성합니다. (여기서 \(h\)는 사용자가 지정하는 은닉 차원의 크기입니다.)

  • 일반적인 시계열 회귀/분류 태스크에서는 전체 시퀀스 출력보다는 가장 마지막 상태인 \(z_{t}\) 에 주목합니다. \(z_t\)는 입력된 전체 과거 시점들의 비선형적 변환이 모두 누적된 상태이므로, 전체 시계열의 핵심 정보를 담은 강력한 요약 벡터(Summary)로 작용하기 때문입니다.

5.2. Projection Head의 적용

  • 우리가 최종적으로 원하는 것은 \(h\) 차원의 요약 벡터 \(z_{t}\)가 아니라, 우리가 예측하고자 하는 도메인의 구체적인 스칼라(또는 특정 차원의) 타겟 값 \(y\)입니다. 이를 위해 마지막 상태 \(z_t\)에 선형 변환 층(Projection Head)을 부착합니다.

\[y = w^{\top}z_{t}\]

  • 이 수식은 단일 뉴런에 해당하며, 복잡하게 추출된 시계열 피처(feature) 벡터 \(z_t\)를 우리가 원하는 차원으로 매핑(projection)하여 최종 예측을 완성하는 역할을 합니다.
