1. Introduction: 비지도 학습 (Unsupervised Learning)

  • 지금까지의 머신러닝 모델들은 주로 입력 데이터 \(x^{(i)}\)와 그에 대응하는 정답 레이블 \(y^{(i)}\)가 쌍으로 주어지는 지도 학습(Supervised Learning) 환경을 가정했습니다. 그러나 현실 세계의 많은 데이터는 레이블이 지정되지 않은 상태로 존재합니다.

  • 비지도 학습(Unsupervised Learning)은 레이블이 없는 데이터 \(\{x^{(1)}, \dots, x^{(n)}\}\)만을 이용하여 데이터 내재적인 구조와 패턴을 학습하는 방법론입니다. 본 포스트에서는 비지도 학습의 대표적인 알고리즘인 K-means 클러스터링(K-means Clustering)과 그 확률적 확장판이라 할 수 있는 EM 알고리즘(Expectation-Maximization Algorithm), 그리고 이를 활용한 가우시안 혼합 모델(Mixture of Gaussians)에 대해 수학적으로 깊이 있게 다루어 보겠습니다.

2. K-means Clustering Algorithm

2.1. 핵심 아이디어와 알고리즘

  • 주어진 레이블 없는 데이터세트를 \(k\)개의 응집된 ’클러스터(Cluster)’로 묶는 것이 K-means의 목표입니다. 각 클러스터는 중심점(centroid) \(\mu_j\)에 의해 대표됩니다.

  • 알고리즘은 다음과 같이 아주 직관적인 두 단계를 반복합니다.

      1. 초기화(Initialization): 클러스터의 중심 \(\mu_1, \mu_2, \dots, \mu_k \in \mathbb{R}^d\)를 무작위로 설정합니다.
      1. 반복(Iterate until convergence):
      • 할당 단계(Assignment): 각 데이터 포인트 \(x^{(i)}\)를 가장 가까운 클러스터 중심 \(\mu_j\)에 할당합니다. \[c^{(i)} := \arg \min_j ||x^{(i)} - \mu_j||^2\]
      • 업데이트 단계(Update): 각 클러스터에 할당된 데이터 포인트들의 평균 좌표로 클러스터 중심 \(\mu_j\)를 이동시킵니다. \[\mu_j := \frac{\sum_{i=1}^n 1\{c^{(i)} = j\} x^{(i)}}{\sum_{i=1}^n 1\{c^{(i)} = j\}}\]

2.2. 알고리즘의 수렴성 (Distortion Function)

  • 이 직관적인 알고리즘이 반드시 수렴할까요? 이를 수학적으로 증명하기 위해 왜곡 함수(Distortion Function) \(J\)를 정의합니다.

\[J(c, \mu) = \sum_{i=1}^n ||x^{(i)} - \mu_{c^{(i)}}||^2\]

  • 함수 \(J\)는 각 데이터 포인트와 할당된 클러스터 중심 간의 거리 제곱합을 의미합니다.
    • 할당 단계는 \(\mu\)를 고정한 상태에서 \(c\)에 대해 \(J\)를 최소화하는 과정입니다.
    • 업데이트 단계는 \(c\)를 고정한 상태에서 \(\mu\)에 대해 \(J\)를 최소화하는 과정입니다.
  • 결과적으로 두 단계 모두 \(J\)의 값을 감소시키거나 유지하므로, K-means 알고리즘 진행 중 \(J\)는 단조 감소(monotonically decrease)하며 반드시 수렴하게 됩니다. 단, 전역 최적해(Global minimum)가 아닌 나쁜 지역 최소값(Local minima)에 빠질 수 있으므로, 실무에서는 여러 번 무작위 초기화를 수행한 뒤 가장 낮은 \(J(c, \mu)\)를 갖는 결과를 선택합니다.

3. EM Algorithm & Mixture of Gaussians

  • K-means는 각 데이터를 하나의 클러스터에 완전히 할당하는 ’Hard Clustering’입니다. 이를 확률적인 관점에서 ’Soft Clustering’으로 확장한 것이 가우시안 혼합 모델(GMM)과 EM 알고리즘입니다.

3.1. EM 알고리즘의 직관적 이해

  • EM(Expectation-Maximization) 알고리즘은 관측되지 않은 잠재 변수(Latent Variable) \(z\)가 존재할 때 확률 모델의 파라미터를 추정하는 방법론입니다.
    • E-step (Expectation): 현재 파라미터를 바탕으로, 각 데이터에 대한 잠재 변수 \(z^{(i)}\)의 값을 “추측(guess)”합니다.
    • M-step (Maximization): E-step에서의 추측이 맞다고 가정하고, 그 추측을 바탕으로 모델의 파라미터를 업데이트(최대우도추정)합니다.

3.2. 가우시안 혼합 모델 (Mixture of Gaussians, GMM)

  • 데이터가 \(k\)개의 서로 다른 정규 분포(가우시안)가 섞여서 생성되었다고 가정해 봅시다.

  • 데이터 생성 과정은 다음과 같이 모델링됩니다:

      1. 잠재 변수 \(z^{(i)} \sim \text{Multinomial}(\phi)\) (즉, \(P(z^{(i)} = j) = \phi_j\))에 따라 어느 클러스터에서 데이터를 생성할지 선택합니다.
      1. 선택된 클러스터의 분포에 따라 \(x^{(i)} | z^{(i)} = j \sim \mathcal{N}(\mu_j, \Sigma_j)\)에서 데이터를 샘플링합니다.

  • 결과적인 결합 확률 분포는 다음과 같습니다. \[p(x^{(i)}, z^{(i)}) = p(x^{(i)}|z^{(i)})p(z^{(i)})\]

  • 목적은 로그 우도 함수를 최대화하는 파라미터 \(\phi, \mu, \Sigma\)를 찾는 것입니다. \[l(\phi, \mu, \Sigma) = \sum_{i=1}^n \log \sum_{z^{(i)}=1}^k p(x^{(i)}|z^{(i)}; \mu, \Sigma)p(z^{(i)}; \phi)\]

  • 하지만 \(\log\) 안에 덧셈(\(\sum_{z}\))이 들어있어, 미분하여 0이 되는 닫힌 형태(closed form)의 해를 구하는 것이 불가능합니다. 만약 각 데이터가 어느 클러스터에서 왔는지(\(z^{(i)}\)) 정답을 안다면 식은 \(\sum_{i=1}^n \left( \log p(x^{(i)}|z^{(i)}; \mu, \Sigma) + \log p(z^{(i)}; \phi) \right)\)로 간단해져서 가우시안 판별 분석(GDA)처럼 쉽게 풀 수 있을 것입니다. 여기서 EM 알고리즘의 아이디어가 출발합니다.

4. 일반화된 EM 알고리즘 (General EM Algorithms)

  • GMM을 넘어, 잠재 변수 \(z\)가 존재하는 모든 모델에 적용 가능한 일반적인 EM 알고리즘을 유도해 보겠습니다. 이를 위해 핵심 수학적 도구인 ’옌센의 부등식’이 필요합니다.

4.1. 옌센의 부등식 (Jensen’s Inequality)

  • \(f\)가 볼록(convex) 함수이고 \(X\)가 확률 변수일 때, \(\mathbb{E}[f(X)] \ge f(\mathbb{E}[X])\)가 성립합니다.
  • 반대로, 로그 함수(\(f(x) = \log x\))와 같이 오목(concave) 함수인 경우에는 부등호 방향이 반대로 되어 \(\mathbb{E}[f(X)] \le f(\mathbb{E}[X])\)가 성립합니다.

4.2. 증거 하한 (ELBO, Evidence Lower Bound)의 유도

  • 우리의 목표는 불완전 데이터의 로그 우도 \(\sum_{i=1}^n \log p(x^{(i)}; \theta)\)를 최대화하는 것입니다. 하나의 데이터 포인트 \(x\)에 대해, \(z\)에 대한 임의의 확률 분포 \(Q(z)\) (단, \(\sum_z Q(z)=1, Q(z) \ge 0\))를 도입하여 식을 변형해 보겠습니다.

\[\log p(x; \theta) = \log \sum_z p(x, z; \theta)\] \[= \log \sum_z Q(z) \frac{p(x, z; \theta)}{Q(z)}\]

  • 여기서 \(\sum_z Q(z) [\cdot]\) 은 분포 \(Q\)에 대한 기댓값 \(\mathbb{E}_{z \sim Q}[\cdot]\) 형태입니다. 로그 함수는 오목(concave) 함수이므로 옌센의 부등식을 적용할 수 있습니다.

\[\log \sum_z Q(z) \frac{p(x, z; \theta)}{Q(z)} \ge \sum_z Q(z) \log \frac{p(x, z; \theta)}{Q(z)}\]

  • 이 우변을 가리켜 ELBO (Evidence Lower Bound)라고 부릅니다. \[\text{ELBO}(x; Q, \theta) = \sum_z Q(z) \log \frac{p(x, z; \theta)}{Q(z)}\]

4.3. EM 알고리즘의 진행 (E-step & M-step)

  • EM 알고리즘은 본질적으로 \(Q\)와 \(\theta\)를 번갈아 업데이트하며 ELBO를 최대화하는 좌표 상승법(Coordinate Ascent)입니다.

  • 1. E-step: \(Q(z)\) 최적화

    • 부등식을 ’등식(equality)’으로 만들어 하한선을 끌어올리기 위해, 기댓값 내부의 변수가 상수여야 합니다. 즉 \(\frac{p(x, z; \theta)}{Q(z)} = c\).
    • \(Q(z)\)가 확률 분포의 조건을 만족하도록 상수를 정리하면: \[Q(z) = \frac{p(x, z; \theta)}{\sum_z p(x, z; \theta)} = \frac{p(x, z; \theta)}{p(x; \theta)} = p(z|x; \theta)\]
    • 따라서 E-step에서는 \(Q_i(z^{(i)})\)를 현재 파라미터 \(\theta\)가 주어졌을 때의 잠재 변수에 대한 사후 확률(Posterior)로 설정합니다. 이는 GMM에서 각 데이터가 각 클러스터에 속할 확률(Soft assignment) \(w_j^{(i)}\)를 구하는 것과 동일합니다.

  • 2. M-step: \(\theta\) 최적화

    • E-step에서 고정된 \(Q_i\)를 바탕으로, ELBO 식을 파라미터 \(\theta\)에 대해 최대화합니다. \[\theta := \arg\max_\theta \sum_{i=1}^n \sum_{z^{(i)}} Q_i(z^{(i)}) \log \frac{p(x^{(i)}, z^{(i)}; \theta)}{Q_i(z^{(i)})}\]

  • 이 최적화 과정을 반복하면, ELBO가 증가함에 따라 원래의 목표 함수인 \(\log p(x; \theta)\) 역시 단조 증가하므로 알고리즘의 수렴성이 보장됩니다.

  • 참고: KL 발산(KL Divergence) 관점에서 ELBO는 \(\log p(x) - D_{KL}(Q || p_{z|x})\)로 표현되며, E-step은 결국 \(Q\)와 사후 확률 간의 KL Divergence를 0으로 만들어 ELBO를 한계치까지 높이는 과정입니다.

5. GMM에서의 M-step 유도 (Detailed Derivations)

  • 이론적 이해를 바탕으로 다시 가우시안 혼합 모델(GMM)로 돌아와, M-step에서 중심 좌표 \(\mu_l\)과 군집 혼합 비율 \(\phi_j\)가 어떻게 업데이트되는지 구체적으로 미분해 보겠습니다.

  • GMM의 M-step에서 최대화해야 할 목적 함수는 다음과 같습니다. \[\sum_{i=1}^n \sum_{j=1}^k w_j^{(i)} \log \frac{p(x^{(i)}|z^{(i)}=j; \mu, \Sigma) p(z^{(i)}=j; \phi)}{w_j^{(i)}}\]

  • 가우시안 확률 밀도 함수를 대입하면 식은 아래와 같이 전개됩니다. \[= \sum_{i=1}^n \sum_{j=1}^k w_j^{(i)} \log \left( \frac{\frac{1}{(2\pi)^{d/2}|\Sigma_j|^{1/2}} \exp\left(-\frac{1}{2}(x^{(i)}-\mu_j)^T \Sigma_j^{-1} (x^{(i)}-\mu_j)\right) \cdot \phi_j}{w_j^{(i)}} \right)\]

5.1. \(\mu_l\) 에 대한 업데이트 유도

  • 특정 클러스터 \(l\)의 중심점 \(\mu_l\)에 대해 식을 미분하여 0이 되는 지점을 찾습니다. \(j \neq l\)인 항들은 \(\mu_l\)과 무관하므로 소거됩니다. \[\nabla_{\mu_l} \sum_{i=1}^n w_l^{(i)} \left( -\frac{1}{2}(x^{(i)}-\mu_l)^T \Sigma_l^{-1} (x^{(i)}-\mu_l) \right)\]

  • 이차식의 미분 공식 \(\nabla_x (x^T A x) = 2Ax\) (단, \(\Sigma_l^{-1}\)은 대칭행렬)를 적용하면: \[= \frac{1}{2} \sum_{i=1}^n w_l^{(i)} \nabla_{\mu_l} \left( 2\mu_l^T \Sigma_l^{-1} x^{(i)} - \mu_l^T \Sigma_l^{-1} \mu_l \right)\] \[= \sum_{i=1}^n w_l^{(i)} \left( \Sigma_l^{-1} x^{(i)} - \Sigma_l^{-1} \mu_l \right) = 0\]

  • 양변에 \(\Sigma_l\)을 곱하여 정리한 뒤 \(\mu_l\)에 대해 풀면 최종 업데이트 식이 도출됩니다: \[\mu_l := \frac{\sum_{i=1}^n w_l^{(i)} x^{(i)}}{\sum_{i=1}^n w_l^{(i)}}\]

  • 직관적으로, K-means의 중심 업데이트와 매우 유사하며 단순한 1/0 지시 함수 대신 ’가중치 \(w_l^{(i)}\)’를 사용한 가중 평균을 구하게 됩니다.

5.2. \(\phi_j\) 에 대한 업데이트 유도 (Lagrange Multiplier)

  • \(\phi_j\) 업데이트에는 확률의 합은 1이어야 한다는 제약조건 \(\sum_{j=1}^k \phi_j = 1\)이 존재하므로 라그랑주 승수법(Lagrange Multiplier)을 사용해야 합니다.

  • 목적 함수에서 \(\phi_j\)와 관련된 항만 뽑아내어 라그랑지안 \(\mathcal{L}(\phi)\)를 구성합니다: \[\mathcal{L}(\phi) = \sum_{i=1}^n \sum_{j=1}^k w_j^{(i)} \log \phi_j + \beta \left( \sum_{j=1}^k \phi_j - 1 \right)\]

  • \(\phi_j\)에 대해 편미분하고 0으로 설정합니다. \[\frac{\partial \mathcal{L}(\phi)}{\partial \phi_j} = \sum_{i=1}^n \frac{w_j^{(i)}}{\phi_j} + \beta = 0 \implies \phi_j = \frac{\sum_{i=1}^n w_j^{(i)}}{-\beta}\]

  • 이 해가 제약조건 \(\sum_{j=1}^k \phi_j = 1\)을 만족해야 하므로, 양변을 \(j\)에 대해 모두 합합니다. \[\sum_{j=1}^k \phi_j = 1 = \sum_{j=1}^k \frac{\sum_{i=1}^n w_j^{(i)}}{-\beta} = \frac{\sum_{i=1}^n \sum_{j=1}^k w_j^{(i)}}{-\beta}\]

  • E-step의 정의상 데이터 \(x^{(i)}\)에 대한 모든 확률의 합은 \(\sum_{j=1}^k w_j^{(i)} = 1\)이므로, 분자는 \(\sum_{i=1}^n 1 = n\)이 됩니다.

  • 따라서 \(-\beta = n\) 임을 알 수 있습니다.

  • 최종적으로 도출된 \(\phi_j\)의 식은 다음과 같습니다. \[\phi_j := \frac{1}{n} \sum_{i=1}^n w_j^{(i)}\]

  • 직관적으로, 전체 \(n\)개의 데이터 중에서 평균적으로 얼마나 많은 비중이 클러스터 \(j\)에 할당되었는지를 나타내는 비율입니다.
