들어가며 (Overview)

지난 강의들에서 우리는 어텐션(Attention)과 피드포워드(FeedForward) 같은 트랜스포머의 핵심 빌딩 블록을 살펴보았습니다. 그러나 이 모듈들을 단순히 쌓는 것만으로는 실제로 동작하는 언어 모델을 만들 수 없습니다. 다음과 같은 현실적인 문제들이 남아 있기 때문입니다.

  • 어텐션은 순서를 인식하지 못합니다. 토큰의 위치 정보를 어떻게 주입할 것인가?
  • 레이어를 깊게 쌓으면 특징(feature)의 분포가 폭주하거나 소실됩니다. 어떻게 안정화할 것인가?
  • 깊은 네트워크는 기울기 소실(vanishing gradient) 때문에 학습이 어렵습니다. 어떻게 학습을 용이하게 만들 것인가?

이번 강의의 목표(Goal)는 이 질문들에 답하는 트랜스포머의 부가 기법들을 살펴보고, 모든 모듈을 하나로 합쳐 완전한 Transformer 순전파(forward pass) 를 직접 구현하는 것입니다.

1. 위치 인코딩 (Positional Encoding)

1.1 왜 필요할까요? (Motivation)

어텐션은 순열 등변(permutation-equivariant) 연산입니다. 이는 MLP(완전 연결 레이어)에도 동일하게 해당됩니다. 순열 등변이란, 입력 토큰들의 순서를 바꾸면 출력도 정확히 같은 방식으로 순서가 바뀔 뿐, 그 이상의 정보 변화가 없다는 뜻입니다.

  • 직관적으로 표현하면, 어텐션 연산은 입력을 순서 없는 집합(set) 처럼 취급합니다.
  • 그러나 자연어 처리(NLP)에서는 단어의 상대적 순서가 의미를 결정합니다.

간단한 다음 토큰 예측 예시를 생각해 봅시다 (토큰: "I", "like").

  1. ["I", "like"] \(\rightarrow\) ?
  2. ["like", "I"] \(\rightarrow\) ?

위치 정보가 전혀 없는 비인과(non-causal) 모델은 두 경우에 대해 완전히 동일한 출력을 내놓습니다. 어텐션 입장에서 두 입력은 단지 같은 토큰의 집합이기 때문입니다. 이는 명백히 잘못된 동작입니다.

따라서 우리는 각 토큰의 특징 임베딩에 위치 정보(positional information) 를 명시적으로 주입해야 합니다.

1.1.1 절대 위치 인코딩 (Absolute Positional Encoding)

가장 단순한 접근은 절대 위치 인덱스를 특징으로 인코딩하는 것입니다.

  • 위치 \(m\) 에 있는 은닉 특징 \(h\) 에 대해, 위치를 인코딩한 벡터를 이어 붙입니다.

\[ h \rightarrow \text{concat}\bigl(h,\ \text{encode}(m)\bigr). \]

하지만 절대 위치 인코딩에는 치명적인 단점이 있습니다. 바로 이동 불변성(translation invariance)이 없다는 점입니다.

  • 만약 문장 전체를 한 칸씩 밀면(shift), 동일한 단어 쌍이라도 위치 인덱스가 달라지므로 인코딩이 완전히 바뀝니다.
  • 그 결과, 학습 때 보지 못한 위치 조합이나 더 긴 시퀀스에 대해 일반화 성능이 떨어집니다.

이 문제를 해결하기 위해 제안된 것이 바로 회전 위치 인코딩(Rotary Positional Encoding, RoPE) 입니다.

1.2 회전 위치 인코딩 (Rotary Positional Encoding, RoPE)

RoPE의 핵심 아이디어는 위치 정보를 쿼리/키 특징을 회전(rotate) 시켜 주입하되, 회전 각도를 위치 인덱스에 비례하도록 만드는 것입니다.

1.2.1 기본 발상

  • 위치 \(n\) 의 쿼리 \(q\) 와 위치 \(m\) 의 키 \(k\) 에 대해, RoPE는 각각을 \(\text{rotate}(q, n)\), \(\text{rotate}(k, m)\) 으로 변환합니다. 여기서 \(\text{rotate}(q, n)\) 은 벡터 \(q\) 를 위치 \(n\) 에 비례하는 각도만큼 회전시키는 연산을 의미합니다.
  • 어텐션 점수는 회전된 두 벡터의 내적으로 계산됩니다.

\[ \text{rotate}(q, n) \cdot \text{rotate}(k, m). \]

  • 핵심 성질은 임의의 이동량 \(t\) 에 대해 다음이 성립한다는 점입니다.

\[ \text{rotate}(q, n) \cdot \text{rotate}(k, m) = \text{rotate}(q, n+t) \cdot \text{rotate}(k, m+t). \]

즉, 어텐션 점수가 절대 위치 \(n, m\) 자체가 아니라 상대 위치 \(m-n\) 에만 의존합니다. 이것이 바로 RoPE가 자연스럽게 이동 불변성을 획득하는 이유입니다.

1.2.2 왜 회전이 상대 위치만 남기는가 (수식 유도)

2차원 평면에서의 회전 행렬을 떠올려 봅시다. 각도 \(\phi\) 만큼의 회전은 다음 직교 행렬로 표현됩니다.

\[ R(\phi) = \begin{pmatrix} \cos\phi & -\sin\phi \\ \sin\phi & \cos\phi \end{pmatrix}. \]

회전 행렬은 두 가지 중요한 대수적 성질을 갖습니다.

  • 직교성(orthogonality): \(R(\phi)^\top R(\phi) = I\), 따라서 \(R(\phi)^\top = R(-\phi)\).
  • 각도 합성(additivity): \(R(\alpha)\,R(\beta) = R(\alpha + \beta)\).

이제 2차원 쿼리 \(q\) 를 각도 \(n\theta\) 만큼, 키 \(k\) 를 각도 \(m\theta\) 만큼 회전시킨 뒤의 내적을 계산해 봅시다.

\[ \bigl(R(n\theta)\,q\bigr) \cdot \bigl(R(m\theta)\,k\bigr) = q^\top R(n\theta)^\top R(m\theta)\, k. \]

직교성과 각도 합성 성질을 차례로 적용하면,

\[ q^\top R(n\theta)^\top R(m\theta)\, k = q^\top R(-n\theta)\,R(m\theta)\, k = q^\top R\bigl((m-n)\theta\bigr)\, k. \]

결과식은 오직 위치 차이 \(m-n\) 에만 의존합니다. 따라서 두 위치를 동시에 \(t\) 만큼 이동시켜도 \((m+t) - (n+t) = m-n\) 이 불변이므로, 앞서 언급한 이동 불변성이 자동으로 성립합니다.

1.2.3 다중 주파수 회전 (Multiple 2D Rotations)

실제 특징 벡터의 차원 \(d\) 는 2보다 훨씬 큽니다. RoPE는 서로 다른 주파수를 가진 여러 개의 2D 회전을 특징에 동시에 적용합니다.

  • 특징 차원 \(d\) 가 주어지면, RoPE는 각 특징을 2차원씩 묶어 총 \(d' = d/2\) 개의 2D 쌍으로 나눕니다.
  • 위치 \(m\) 에 있는 \(i\) 번째 2D 쌍에 대해, RoPE는 회전 각도 \(m\theta_i\) 만큼 2D 회전을 적용합니다. 이때 주파수 \(\theta_i\) 는 다음과 같이 정의됩니다.

\[ \theta_i = \text{base}^{-i/d'}, \qquad i \in \{0, 1, \ldots, d'-1\}. \]

  • base 는 하이퍼파라미터로, 보통 10,000을 사용합니다.
  • 차원 쌍마다 서로 다른 주파수 \(\theta_i\) 를 적용함으로써, RoPE는 다양한 위치 편향(positional bias) 을 모델링할 수 있습니다.

보충: \(i\) 가 커질수록 주파수는 작아집니다. \(\text{base} > 1\) 이고 지수 \(-i/d'\) 가 음수이므로, \(i=0\) 일 때 \(\theta_0 = 1\) 로 가장 빠르게 회전하고(고주파), \(i = d'-1\) 에 가까워질수록 \(\theta_i \to \text{base}^{-1}\) 에 가까워져 매우 느리게 회전합니다(저주파). 이 다중 스케일 구조가 RoPE의 표현력의 원천입니다.

1.2.4 회전 행렬의 cos/sin 계산 구현

먼저 각 위치/차원에 대한 회전 각도의 코사인·사인 값을 계산하는 클래스를 구현합니다.

class RotaryEmbedding():
    """
    RoPE의 회전 행렬에 필요한 cosine, sine 값을 계산하는 클래스.
    """
    def __init__(self, head_dim, base=10000):
        self.base = base
        self.head_dim = head_dim
        self.theta = self._compute_theta()

    def _compute_theta(self):
        """
        원본 RoPE 구현에 따라 theta_i 를 계산.
        Returns:
            torch.Tensor: shape (head_dim//2, ) 의 theta 값들
        """
        exponent = torch.arange(0, self.head_dim, 2).float() / self.head_dim
        theta = 1 / self.base ** exponent
        return theta

    def __call__(self, position_ids):
        """
        주어진 위치 인덱스에 대해 cos, sin 값을 계산.
        Parameters:
            position_ids (torch.Tensor): shape (batch, seq)
        Returns:
            (cos, sin): 각각 shape (batch, seq, head_dim//2)
        """
        bsz = position_ids.shape[0]

        position_ids_ = position_ids[:, :, None].float()       # (bsz, seq, 1)
        theta_ = self.theta[None, None, :].expand(bsz, 1, -1)  # (bsz, 1, head_dim/2)

        freqs = torch.matmul(position_ids_, theta_)  # (bsz, seq, head_dim/2)
        cos, sin = torch.cos(freqs), torch.sin(freqs)

        return cos, sin
  • _compute_theta: 지수 exponent 는 \(0, 2, 4, \ldots, (d-2)\) 를 \(d\) 로 나눈 값, 즉 \(\tfrac{2i}{d} = \tfrac{i}{d'}\) 입니다. 따라서 theta 는 정확히 \(\theta_i = \text{base}^{-i/d'}\) 를 구현합니다.
  • __call__: 위치 인덱스 벡터(shape (bsz, seq, 1))와 주파수 벡터(shape (bsz, 1, d'))의 외적(행렬곱)을 통해 모든 (위치 \(m\), 차원 \(i\)) 조합의 각도 \(m\theta_i\) 를 한 번에 계산합니다. 그 후 코사인·사인을 취합니다. 결과 cos[..., m, i] 는 \(\cos(m\theta_i)\), sin[..., m, i] 는 \(\sin(m\theta_i)\) 가 됩니다.

1.2.5 회전 연산 적용 구현

이제 미리 계산한 cos/sin을 이용해 쿼리·키를 실제로 회전시킵니다. 2D 회전 공식을 각 2차원 쌍에 적용합니다.

\[ \begin{pmatrix} q'_{2i} \\ q'_{2i+1} \end{pmatrix} = \begin{pmatrix} \cos(m\theta_i) & -\sin(m\theta_i) \\ \sin(m\theta_i) & \cos(m\theta_i) \end{pmatrix} \begin{pmatrix} q_{2i} \\ q_{2i+1} \end{pmatrix}. \]

이를 성분별로 풀어 쓰면,

\[ q'_{2i} = \cos(m\theta_i)\, q_{2i} - \sin(m\theta_i)\, q_{2i+1}, \] \[ q'_{2i+1} = \sin(m\theta_i)\, q_{2i} + \cos(m\theta_i)\, q_{2i+1}. \]

def apply_rotary_pos_emb(q, k, cos, sin):
    """RoPE를 query/key 텐서에 적용.

    Parameters:
        q (torch.Tensor): query, shape (batch, n_head, seq, head_dim)
        k (torch.Tensor): key,   shape (batch, n_head, seq, head_dim)
        cos (torch.Tensor): shape (batch, seq, head_dim//2)
        sin (torch.Tensor): shape (batch, seq, head_dim//2)
    Returns:
        회전이 적용된 (q_rotate, k_rotate)
    """
    # cos[..., m, i] = cos(m*theta_i),  sin[..., m, i] = sin(m*theta_i)
    cos = cos.unsqueeze(1)  # (batch, 1, seq, head_dim//2)  -> head 차원으로 브로드캐스트
    sin = sin.unsqueeze(1)

    head_dim = q.shape[-1]
    q_rotate = torch.zeros_like(q)
    k_rotate = torch.zeros_like(k)

    for i in range(head_dim // 2):
        q_rotate[..., 2*i]   = cos[..., i] * q[..., 2*i]   - sin[..., i] * q[..., 2*i+1]
        q_rotate[..., 2*i+1] = sin[..., i] * q[..., 2*i]   + cos[..., i] * q[..., 2*i+1]

        k_rotate[..., 2*i]   = cos[..., i] * k[..., 2*i]   - sin[..., i] * k[..., 2*i+1]
        k_rotate[..., 2*i+1] = sin[..., i] * k[..., 2*i]   + cos[..., i] * k[..., 2*i+1]

    return q_rotate, k_rotate
  • cos.unsqueeze(1): cos/sin은 헤드(head)에 무관하게 동일하게 적용되므로, n_head 차원으로 브로드캐스트되도록 차원을 하나 끼워 넣습니다.
  • 반복문은 \(d/2\) 개의 2D 쌍 각각에 대해 위에서 유도한 회전 공식을 그대로 적용합니다. [..., 2*i] 와 [..., 2*i+1] 이 한 쌍을 이룹니다.

보충(인덱싱 관례): 여기서는 인접한 두 성분 \((x_{2i}, x_{2i+1})\) 을 한 쌍으로 묶는 interleaved(교차) 방식입니다. 일부 구현(예: HuggingFace)은 전반부와 후반부를 묶는 half-split 방식을 쓰는데, 둘은 차원 순열을 통해 동치이며 학습 결과에는 본질적 차이가 없습니다.

1.2.8 저주파와 고주파의 의미

RoPE에서 저주파와 고주파는 각각 무엇을 의미할까요?

  • 저주파(예: head 31): 위치 회전의 영향이 미미하여, 어텐션이 위치보다 의미 정보(semantic information) 에 더 집중하게 합니다.
  • 고주파(예: head 0): 특징이 위치에 따라 빠르게 변하므로, 위치 정보(positional information) 에 더 강한 편향을 부여합니다.

즉 RoPE는 한 벡터 안에서 의미 중심 채널과 위치 중심 채널을 동시에 마련해 두는 셈입니다.

1.2.10 어텐션 모듈에 RoPE 삽입

기존 멀티헤드 어텐션에서 달라지는 부분은 단 한 곳, 점수 계산 직전에 쿼리·키를 회전시키는 것입니다.

from model import softmax, Linear


class Attention():
    def __init__(self, dim, head_dim, n_head):
        self.head_dim = head_dim
        self.n_head = n_head
        self.wq = Linear(dim, n_head * head_dim)
        self.wk = Linear(dim, n_head * head_dim)
        self.wv = Linear(dim, n_head * head_dim)
        self.wo = Linear(n_head * head_dim, dim)

    def __call__(self, x, position_embeddings=None, mask=None, return_attn=False):
        """
        y = Attention(x)
        x: (batch_size, seq, dim),  mask: (batch_size, seq, seq)
        return: (batch_size, seq, dim)
        """
        bsz, seqlen, dim = x.shape

        query, key, value = self.wq(x), self.wk(x), self.wv(x)  # (b, seq, n_head*head_dim)

        query = query.reshape(bsz, seqlen, self.n_head, self.head_dim)
        key   = key.reshape(bsz, seqlen, self.n_head, self.head_dim)
        value = value.reshape(bsz, seqlen, self.n_head, self.head_dim)

        query = query.transpose(1, 2)  # (b, n_head, seq, head_dim)
        key   = key.transpose(1, 2)
        value = value.transpose(1, 2)

        #### New: RoPE 적용 ####
        cos, sin = position_embeddings
        query, key = apply_rotary_pos_emb(query, key, cos, sin)
        ########################

        scores = torch.matmul(query, key.transpose(2, 3))   # (b, n_head, seq, seq)
        scores = scores / math.sqrt(self.head_dim)          # 스케일링

        if mask is not None:
            scores = scores + mask                          # 브로드캐스트
        attn_score = softmax(scores)                        # (b, n_head, seq, seq)

        output = torch.matmul(attn_score, value)            # (b, n_head, seq, head_dim)
        output = output.transpose(1, 2).reshape(bsz, seqlen, -1)
        output = self.wo(output)                            # (b, seq, dim)

        if return_attn:
            return output, attn_score
        return output
  • scores / math.sqrt(self.head_dim): 내적값의 분산이 차원 수에 비례해 커지는 것을 보정하는 스케일링입니다. 이를 통해 소프트맥스 입력이 지나치게 커져 기울기가 소실되는 것을 막습니다.
  • mask 는 인과 마스크(causal mask)로, 미래 토큰을 보지 못하도록 \(-\infty\) 를 더해 소프트맥스 후 0이 되게 만듭니다.
  • RoPE는 값(value)에는 적용하지 않습니다. 위치 정보는 어텐션 점수(쿼리·키 내적)를 통해서만 주입하면 충분하기 때문입니다.

어텐션은 입력과 동일한 (batch, seq, dim) 모양을 반환하며, 어텐션 점수는 (batch, n_head, seq, seq) 모양으로 각 헤드별 토큰 간 상호작용을 담고 있습니다.

2. 정규화 (Normalization)

2.1 왜 필요할까요?

레이어를 많이 쌓을 때 발생하는 문제를 정리하면 다음과 같습니다.

  • 다수의 레이어를 쌓으면, 신경망 특징의 분포가 레이어를 거치며 다양한 변환을 겪어 마지막 레이어에서는 크게 달라질 수 있습니다.
  • 이 경우 특징 값이나 그 기울기가 지나치게 커지거나(폭주) 급격히 작아질(소실) 수 있습니다.
  • 각 레이어의 시작이나 끝에 정규화 레이어를 도입하면 연산 스케일을 안정화하는 데 도움이 됩니다.
  • 최근에는 레이어 정규화(layer normalization) 계열이 더 흔히 쓰입니다. 학습과 추론 단계 사이에 배치 크기가 달라질 수 있기 때문입니다(배치 정규화는 배치 통계에 의존하므로 이 경우 불안정합니다).

본 강의에서는 LLaMA가 채택한 제곱평균제곱근 정규화(Root Mean Square Normalization, RMSNorm) 를 구현합니다.

2.2 RMSNorm의 정의

특징 벡터 \(x \in \mathbb{R}^d\) 가 주어졌을 때, 강의 슬라이드는 RMSNorm을 다음과 같이 표기합니다.

\[ \text{RMSnorm}(x) = \frac{x}{\sqrt{\sum_i x_i^2}}. \]

TA 노트 (구현과 정의의 정합성): 위 슬라이드 표기는 분모에 \(\sqrt{\sum_i x_i^2}\) 를 쓰지만, 표준 RMSNorm의 정의와 아래 코드 구현은 차원 수 \(d\) 로 나눈 평균 을 사용합니다.

\[\text{RMS}(x) = \sqrt{\frac{1}{d}\sum_{i=1}^{d} x_i^2}, \qquad \text{RMSnorm}(x) = \frac{x}{\text{RMS}(x) + \epsilon\text{-보정}}.\]

두 표기는 상수 인자 \(\sqrt{d}\) 만큼만 다르며, 방향(unit vector화의 의미)은 동일합니다. 표준 정의를 따르면 차원 수에 무관하게 출력 스케일이 일정하게 유지된다는 장점이 있어, 실무에서는 평균 기반(RMS) 정의를 사용합니다. 또한 수치 안정성을 위해 분모 제곱근 안에 작은 상수 \(\epsilon\) 을 더합니다.

  • LayerNorm과의 차이: LayerNorm은 평균을 빼서 중심화(re-centering)한 뒤 표준편차로 나누지만, RMSNorm은 평균 제거 없이 스케일만 정규화합니다(re-scaling only). 평균 제거 연산을 생략해 계산이 더 가볍고, 실제로도 성능 저하가 거의 없다는 것이 알려져 있습니다.

2.3 구현

class RMSNorm():
    def __init__(self, eps=1e-6):
        self.eps = eps  # 수치 안정성을 위한 작은 상수

    def _norm(self, x):
        power = x.pow(2).mean(-1, keepdim=True)      # (1/d) * sum x_i^2
        output = x / torch.sqrt(power + self.eps)
        return output

    def __call__(self, x):
        """
        y = norm(x)
        x: (batch_size, seq, dim) -> (batch_size, seq, dim)
        """
        output = self._norm(x)
        return output
  • x.pow(2).mean(-1, keepdim=True): 마지막 차원(특징 차원)에 대해 제곱의 평균 \(\frac{1}{d}\sum_i x_i^2\) 을 계산합니다. keepdim=True 로 브로드캐스트가 가능하도록 차원을 유지합니다.
  • torch.sqrt(power + self.eps): 제곱근 안에 \(\epsilon\) 을 더해 0으로 나누는 상황을 방지합니다.

보충: 실제 LLaMA 구현은 여기에 학습 가능한 이득(gain) 파라미터 \(g \in \mathbb{R}^d\) 를 곱해 \(\text{RMSnorm}(x) \odot g\) 형태로 사용합니다. 본 교육용 구현은 이 학습 파라미터를 생략한 단순화 버전입니다.

3. Skip-connection: 잔차 학습 (Residual Learning)

3.1 정의와 동기

입력 \(x\) 와 함수 \(f\) 가 주어졌을 때, skip-connection은 다음과 같이 동작합니다.

\[ \text{output} = f(x) + x. \]

이 기법은 ResNet에서 대중화되었으며, 이제는 깊은 신경망에서 반드시 사용하는(must-to-use) 기법이 되었습니다.

  • Skip-connection은 네트워크가 입력의 항등성(identity)을 보존하도록 하여, 변환 전체를 처음부터 학습하는 대신 잔차 매핑(residual mapping)을 학습하도록 돕습니다. 즉 \(f\) 는 “입력에서 얼마나 바꿔야 하는가”라는 차이분만 학습하면 됩니다.
  • 또한 기울기 소실 문제를 완화하여, 깊은 네트워크의 학습을 한결 쉽게 만듭니다.

보충(기울기 흐름): 역전파 시 \(\text{output} = f(x) + x\) 의 미분은 \(\frac{\partial\,\text{output}}{\partial x} = f'(x) + I\) 가 됩니다. 항등 항 \(I\) 가 존재하므로, \(f'(x)\) 가 작아져도 기울기가 최소한 1만큼은 그대로 하위 레이어로 전달됩니다. 이것이 깊은 네트워크에서도 기울기가 살아남는 이유입니다.

3.2 Transformer 레이어(블록) 구현

트랜스포머 블록은 어텐션과 피드포워드 각각을 잔차 연결로 감쌉니다. 본 구현은 정규화를 서브레이어 입력 쪽에 적용하는 Pre-Norm 구조를 따릅니다. 입력 \(x\) 에 대한 계산은 다음과 같습니다.

\[ h = \text{Attention}\bigl(\text{norm}(x)\bigr) + x, \] \[ \text{output} = \text{FeedForward}\bigl(\text{norm}(h)\bigr) + h. \]

from model import FeedForward


class TransformerBlock():
    def __init__(self, layer_id, dim, n_head):
        self.n_head = n_head
        self.dim = dim
        self.head_dim = dim // n_head
        self.attention = Attention(dim, self.head_dim, n_head)
        self.feed_forward = FeedForward(dim=dim, hidden_dim=4*dim)

        self.layer_id = layer_id
        self.attention_norm = RMSNorm()
        self.ffn_norm = RMSNorm()

    def __call__(self, x, position_embeddings=None, mask=None):
        """
        y = Block(x)
        x: (batch_size, seq, dim) -> (batch_size, seq, dim)
        """
        # (1) Attention 서브레이어 + 잔차
        x_norm = self.attention_norm(x)
        attn_residual = self.attention(x_norm, position_embeddings, mask)
        h = x + attn_residual

        # (2) FeedForward 서브레이어 + 잔차
        h_norm = self.ffn_norm(h)
        mlp_residual = self.feed_forward(h_norm)
        out = h + mlp_residual

        return out
  • attention_norm, ffn_norm: 두 서브레이어 각각에 독립적인 RMSNorm을 둡니다.
  • FeedForward(dim=dim, hidden_dim=4*dim): 은닉 차원을 입력의 4배로 확장하는 것은 트랜스포머의 표준 관례입니다.

보충(Pre-Norm vs Post-Norm): 원조 트랜스포머는 잔차 합 이후 정규화를 적용하는 Post-Norm(\(\text{norm}(f(x)+x)\))이었으나, 현대 LLM(LLaMA 등)은 본 구현처럼 서브레이어 입력에 정규화를 적용하는 Pre-Norm을 선호합니다. Pre-Norm은 잔차 경로에 정규화가 끼지 않아 기울기가 더 안정적으로 흐르며, 학습률 워밍업 없이도 깊은 모델을 안정적으로 학습할 수 있습니다.

4. 전체 조립 (Putting all together)

4.1 완전한 Transformer 모델

이제 모든 모듈을 합쳐 완전한 Transformer를 만듭니다. 이 모델은 토큰 시퀀스를 입력받아 각 위치의 특징을 반환하는 사상입니다.

\[ V^{b \times n} \to \mathbb{R}^{b \times n \times d}. \]

  • \(V\): 토큰 어휘(vocabulary)
  • \(b\): 배치 크기, \(n\): 시퀀스 길이, \(d\): 특징 차원

전체 순전파의 흐름은 다음과 같습니다.

  1. 토큰 임베딩: 정수 토큰 ID를 \(d\) 차원 벡터로 변환합니다.
  2. 위치 임베딩 준비: RoPE의 cos/sin을 계산합니다.
  3. 인과 마스크 생성: 미래 토큰을 가리는 상삼각 \(-\infty\) 마스크를 만듭니다.
  4. 블록 반복: \(n_{\text{layers}}\) 개의 트랜스포머 블록을 순차적으로 통과시킵니다.
  5. 최종 정규화 + 출력 투영: 마지막 RMSNorm 후, 선형층으로 어휘 크기만큼의 로짓을 계산합니다.
from model import Embedding


class Transformer():
    def __init__(self, n_layers, vocab_size, dim, n_head):
        self.n_layers = n_layers
        self.vocab_size = vocab_size
        self.dim = dim
        self.n_head = n_head
        self.head_dim = dim // n_head

        # 토큰 임베딩
        self.tok_embeddings = Embedding(vocab_size, dim)

        # Transformer 블록들
        self.layers = []
        for layer_id in range(n_layers):
            self.layers.append(TransformerBlock(layer_id, dim, n_head))

        self.rope = RotaryEmbedding(self.head_dim)
        self.norm = RMSNorm()

        # 특징 -> 어휘 로짓 매핑
        self.output = Linear(dim, vocab_size)

    def __call__(self, tokens: torch.Tensor):
        """
        y = Transformer(x)
        tokens: (batch_size, seq) -> logits (batch_size, seq, vocab_size)
        """
        bsz, seqlen = tokens.shape
        h = self.tok_embeddings(tokens)

        # 위치 인덱스 및 RoPE
        position_ids = torch.arange(seqlen).reshape(1, -1)
        position_embeddings = self.rope(position_ids)

        # 인과 마스크
        mask = None
        if seqlen > 1:
            mask = torch.full((seqlen, seqlen), float("-inf"), device=tokens.device)
            mask = torch.triu(mask, diagonal=1)  # 상삼각(대각선 위쪽)만 -inf

        # 블록 순차 처리
        for layer in self.layers:
            h = layer(h, position_embeddings, mask)

        h = self.norm(h)            # 최종 정규화
        logits = self.output(h)     # 어휘 로짓
        return logits
  • torch.triu(mask, diagonal=1): 대각선 위쪽(미래 위치)만 \(-\infty\) 로 채워, 위치 \(i\) 의 쿼리가 자신보다 뒤(미래)의 키를 보지 못하게 합니다. 소프트맥스를 거치면 \(-\infty\) 항은 0이 되므로 인과성(causality) 이 보장됩니다.
  • self.output: 최종 특징을 어휘 크기 \(|V|\) 의 로짓으로 사상합니다. 이 로짓이 다음 토큰 예측의 근거가 됩니다.

4.3 손실 계산 (Loss Calculation)

4.3.1 다음 토큰 예측과 교차 엔트로피

입력 시퀀스 \(s\) 가 주어지면, 우리는 Transformer가 이를 처리해 다음 토큰에 대한 로짓을 내놓도록 학습시킵니다. 손실은 정답 라벨(ground-truth label) 을 사용해 계산하는데, 라벨은 일반적으로 다음 토큰에 해당합니다.

  • 예: 입력 시퀀스 [a, b, c] 에 대해 라벨은 [b, c, <EOS>] 가 됩니다. 즉 각 위치는 “바로 다음에 올 토큰”을 예측하도록 학습됩니다.

로짓 벡터 \(l \in \mathbb{R}^{|V|}\) 가 주어지면, 예측 확률은 소프트맥스로 계산합니다.

\[ p = \text{softmax}(l) \in [0, 1]^{|V|}. \]

정답 라벨 \(y \in \{1, \ldots, |V|\}\) 에 대한 교차 엔트로피 손실은 정답 클래스 확률의 음의 로그입니다. 이를 전개하면 다음과 같습니다.

\[ -\log p_y = -\log \text{softmax}(l)_y = -\log \frac{\exp(l_y)}{\sum_i \exp(l_i)} = \log \sum_i \exp(l_i) - l_y. \]

  • 마지막 등식은 로그의 성질 \(\log\frac{a}{b} = \log a - \log b\) 와 \(\log\exp(l_y) = l_y\) 를 사용한 것입니다.
  • 첫째 항 \(\log \sum_i \exp(l_i)\) 는 log-sum-exp 라 불리며, 정규화 상수(분배 함수)의 로그에 해당합니다. 둘째 항 \(l_y\) 는 정답 클래스의 로짓입니다. 즉 손실은 “전체 로짓 질량의 로그”에서 “정답 로짓”을 뺀 값으로, 정답 로짓이 다른 로짓들보다 클수록 작아집니다.

4.3.2 구현

def cross_entropy_loss(logits, labels):
    """
    교차 엔트로피 손실 계산 (토큰 평균).
    logits: (batch_size, seq, vocab_size)
    labels: (batch_size, seq)
    return: 스칼라 손실
    """
    bsz, seqlen, vocab_size = logits.shape
    logits = logits.reshape(-1, vocab_size)  # (tokens, vocab_size)
    labels = labels.reshape(-1)              # (tokens, )

    exp_logits = torch.exp(logits)

    logits_target = logits[torch.arange(labels.shape[0]), labels]  # (tokens, ) 정답 로짓 gather
    loss = torch.log(exp_logits.sum(-1)) - logits_target           # log-sum-exp - l_y
    loss = loss.mean()                                             # 토큰 평균
    return loss
  • logits[torch.arange(labels.shape[0]), labels]: 각 토큰에 대해 정답 라벨에 해당하는 로짓만 골라냅니다(아래 gather 예시 참고).
  • torch.log(exp_logits.sum(-1)) - logits_target: 위에서 유도한 \(\log\sum_i\exp(l_i) - l_y\) 를 그대로 구현합니다.
  • .mean(): 배치 내 모든 토큰에 대해 평균을 취합니다.

TA 노트 (수치 안정성): 위 구현은 torch.exp(logits) 를 직접 계산하므로, 로짓이 큰 양수일 때 오버플로 위험이 있습니다. 실무에서는 log-sum-exp 트릭 을 사용합니다. 각 행의 최댓값 \(M = \max_i l_i\) 를 빼면 \[\log\sum_i \exp(l_i) = M + \log\sum_i \exp(l_i - M)\] 이 성립하여, 지수의 인자가 0 이하가 되어 안정적으로 계산됩니다. PyTorch의 F.cross_entropy 나 torch.logsumexp 는 내부적으로 이 보정을 수행합니다. 교육용 구현에서는 명료성을 위해 생략했습니다.

4.3.3 손실을 포함한 Transformer

이제 labels 가 주어지면 손실을 함께 반환하도록 모델을 확장합니다.

class Transformer():
    def __init__(self, n_layers, vocab_size, dim, n_head):
        self.n_layers = n_layers
        self.vocab_size = vocab_size
        self.dim = dim
        self.n_head = n_head
        self.head_dim = dim // n_head

        self.tok_embeddings = Embedding(vocab_size, dim)
        self.layers = [TransformerBlock(layer_id, dim, n_head) for layer_id in range(n_layers)]
        self.rope = RotaryEmbedding(self.head_dim)
        self.norm = RMSNorm()
        self.output = Linear(dim, vocab_size)

    def __call__(self, tokens, labels=None):
        """
        y = Transformer(x, labels=None)
        labels가 주어지면 (loss, logits), 아니면 logits 반환.
        """
        bsz, seqlen = tokens.shape
        h = self.tok_embeddings(tokens)

        position_ids = torch.arange(seqlen).reshape(1, -1)
        position_embeddings = self.rope(position_ids)

        mask = None
        if seqlen > 1:
            mask = torch.full((seqlen, seqlen), float("-inf"), device=tokens.device)
            mask = torch.triu(mask, diagonal=1)

        for layer in self.layers:
            h = layer(h, position_embeddings, mask)

        h = self.norm(h)
        logits = self.output(h)

        if labels is not None:
            loss = cross_entropy_loss(logits, labels)
            return loss, logits
        else:
            return logits

4.3.4 PyTorch 인덱싱으로 보는 gather 연산

정답 로짓을 골라내는 핵심은 PyTorch의 고급 인덱싱(advanced indexing)입니다. 작은 예시로 직관을 잡아 봅시다.

logits = torch.arange(3*4).reshape(3, 4)
labels = torch.tensor([1, 2, 2])

# gather 연산: 각 행에서 labels가 가리키는 열의 값을 추출
selected = logits[torch.arange(labels.shape[0]), labels]

print("Logits:");           print(logits)
print("Labels         :", labels.tolist())  # [1, 2, 2]
print("selected values:", selected.tolist())
  • torch.arange(labels.shape[0]) 는 행 인덱스 [0, 1, 2], labels 는 열 인덱스 [1, 2, 2] 를 제공합니다.
  • 두 인덱스 텐서가 원소별로 짝지어져 (0,1), (1,2), (2,2) 위치의 값이 한 번에 추출됩니다. 즉 행마다 정답 라벨이 가리키는 로짓을 효율적으로 모읍니다. logits 가 0..11 로 채워져 있으므로 추출 결과는 [1, 6, 10] 이 됩니다.

4.3.5 손실 계산 확인

batch_size, seqlen = 2, 10
vocab_size = 64000
n_layers, dim, n_head = 6, 64, 8

x = torch.randint(0, vocab_size, (batch_size, seqlen))

# 다음 토큰 라벨: 입력을 한 칸 당기고 마지막에 EOS(id=1) 부착
labels = x[:, 1:]
labels = torch.cat([labels, torch.ones(batch_size, 1)], dim=1).long()

model = Transformer(n_layers, vocab_size, dim, n_head)
loss, logits = model(x, labels)

print("input size    :", x.shape)        # (2, 10)
print("logit size    :", logits.shape)   # (2, 10, 64000)
print(f"loss          : {loss.item():.2f}")
  • labels = x[:, 1:] 후 EOS 토큰을 끝에 이어 붙여, 각 위치가 다음 토큰을 예측하도록 라벨을 만듭니다(teacher forcing).
  • 초기 무작위 가중치에서의 손실은 대략 \(\log(|V|) = \log(64000) \approx 11.07\) 근처가 됩니다. 학습 전에는 모델이 모든 토큰에 거의 균등한 확률을 부여하기 때문입니다. 이는 구현이 정상인지 가늠하는 좋은 온전성 검사(sanity check) 입니다.

부록: Dropout (Additional Material)

A.1 정의와 동기

Dropout 은 딥러닝에서 널리 쓰이는 정규화(regularization) 기법입니다.

  • 이 기법은 학습 중에 선형층의 특징 원소를 무작위로 0으로 만듭니다(erase).
  • 매번 다른 부분 네트워크를 학습하는 효과를 내어, 깊은 신경망의 과적합(overfitting)을 완화하는 것으로 알려져 있습니다.

A.2 구현 (Inverted Dropout)

class Dropout:
    def __init__(self, p=0.0, training=True):
        self.dropout_prob = p
        self.training = True

    def __call__(self, x):
        """
        x: (..., dim) -> 원소를 확률 p로 0으로 만든 텐서
        """
        if self.training and self.dropout_prob > 0:
            dropout_mask = (torch.rand_like(x) > self.dropout_prob)   # 유지할 원소 = True
            x = x * dropout_mask.float()
            return x / (1 - self.dropout_prob)  # 살아남은 원소를 보정 스케일
        return x
  • torch.rand_like(x) > self.dropout_prob: \([0,1)\) 균등분포 난수가 \(p\) 보다 큰 위치만 살립니다. 즉 각 원소는 확률 \(p\) 로 0이 됩니다.
  • x / (1 - self.dropout_prob): inverted dropout 의 핵심입니다. 살아남은 원소를 \(1/(1-p)\) 배로 키워, 출력의 기댓값을 보존합니다.

보충(기댓값 보존 유도): 원소 \(x_i\) 에 대해 살아남을 확률은 \(1-p\) 입니다. 보정 전 출력의 기댓값은 \[\mathbb{E}[\text{drop}(x_i)] = (1-p)\cdot x_i + p \cdot 0 = (1-p)\,x_i\] 이므로, \(1/(1-p)\) 로 나누면 \[\mathbb{E}\!\left[\frac{\text{drop}(x_i)}{1-p}\right] = x_i\] 가 되어 기댓값이 원래 입력과 같아집니다. 이렇게 학습 시 미리 보정해 두면, 추론 시에는 아무 보정 없이 전체 뉴런을 그대로 사용할 수 있다는 장점이 있습니다.

A.3 Dropout 효과 검증

확률 \(p\) 를 키울수록 실제로 0이 되는 원소 비율이 \(p\) 에 비례하는지 확인합니다.

def test_dropout():
    probs = torch.linspace(0, 0.9, 10)
    zero_ratios = []

    for p in probs:
        dropout_layer = Dropout(p, training=True)
        x = torch.ones(10, 1000)
        dropped_x = dropout_layer(x)
        zero_ratio = (dropped_x == 0).float().mean().item()
        zero_ratios.append(zero_ratio)

    plt.plot(probs.numpy(), zero_ratios, marker='o')
    plt.xlabel('Dropout Probability'); plt.ylabel('Ratio of Zeros After Dropout')
    plt.title('Effect of Dropout on Zero Ratio'); plt.grid(); plt.show()

test_dropout()

설정한 dropout 확률과 실제 0의 비율이 거의 일치하는 것을 통해, 구현이 의도대로 동작함을 확인할 수 있습니다.

마치며 (Summary)

이번 강의에서 우리는 트랜스포머를 실제로 완성하는 데 필요한 네 가지 핵심 기법을 살펴보고 직접 구현했습니다.

  • 위치 인코딩(RoPE): 쿼리·키를 위치에 비례한 각도로 회전시켜, 어텐션 점수가 상대 위치에만 의존하도록 만들었습니다. 다중 주파수 구조로 의미·위치 정보를 동시에 담습니다.
  • 정규화(RMSNorm): 제곱평균제곱근으로 특징 스케일을 표준화하여, 깊은 네트워크에서 특징·기울기의 폭주/소실을 막았습니다.
  • Skip-connection: \(f(x)+x\) 형태의 잔차 학습으로 기울기 흐름을 보장하고 손실 지형을 매끄럽게 만들었습니다.
  • 전체 조립: 토큰 임베딩 → RoPE → 인과 마스크 → Pre-Norm 블록 반복 → 최종 정규화 → 어휘 로짓의 순전파를 완성하고, 교차 엔트로피 손실까지 계산했습니다. 부록에서는 과적합을 막는 Dropout 도 다루었습니다.

이로써 우리는 무작위 가중치에서 출발해 다음 토큰 예측 손실까지 흘려보낼 수 있는, 작동하는 미니 Transformer를 손수 구현하게 되었습니다.
