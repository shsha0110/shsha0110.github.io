1. 모델 학습의 새로운 패러다임: 분포의 추정

  • 이전 포스트에서는 시계열 예측에서 단순한 점 예측(point predictions)을 넘어 미래 값의 확률 분포 \(P(z_{t})\)를 추정하는 ’확률적 예측(Probabilistic Forecasting)’의 필요성과 구조에 대해 다루었습니다.

  • 이제 모델의 출력이 단일 스칼라 값이 아닌 ’분포의 파라미터’가 되었으므로, 기존의 오차 기반 손실 함수(예: MSE, MAE)를 그대로 사용하여 모델을 학습시킬 수 없습니다. 대신 우리는 통계학의 핵심 개념인 최대 우도 추정(Maximum Likelihood Estimation, MLE)을 사용하여 네트워크를 학습시켜야 합니다.

  • MLE를 통한 학습은 다음 세 단계로 요약됩니다:

      1. Step 1: 인코더가 생성한 잠재 상태 \(h_{t}\)를 사용하여 예측 분포 \(P(z_{t}|h_{t})\)를 추정합니다.
      1. Step 2: 추정된 분포를 바탕으로, 실제 관측된 데이터 \(Z_{t}\)가 나타날 우도(Likelihood) \(\mathcal{L}(z_{t})\)를 계산합니다.
      1. Step 3: 이 우도 \(\mathcal{L}(z_{t})\)가 최대화되도록(maximize) 네트워크의 파라미터를 업데이트(역전파)합니다.

  • 이때, 실제 최적화해야 할 구체적인 목적 함수(objective function)의 형태는 우리가 가정한 분포(Gaussian, Exponential 등)에 따라 다르게 결정됩니다.

2. 우도 (Likelihood)와 NLL (Negative Log Likelihood)

2.1. 우도 (Likelihood)의 직관적 이해

  • 데이터 셋 \(D\)와 학습 가능한 파라미터 \(\theta\)를 가진 함수 \(f_{\theta}\)가 주어졌다고 가정해 봅시다.
  • 우도(Likelihood)는 주어진 파라미터 \(\theta\) 하에서 실제 데이터 \(D\)가 관측될 조건부 확률 \(p(D|\theta)\)로 정의됩니다.
  • 위 그림처럼 우도가 높다는 것(Higher likelihood)은 현재의 모델 \(f_{\theta}\)가 관측된 실제 데이터 \(D\)의 특성을 매우 잘 설명(better describes)하고 있음을 의미합니다. 따라서 머신러닝에서 모델 \(f_{\theta}\)를 학습시키는 과정은 수학적으로 \(p(D|\theta)\)를 증가시키는 과정과 완전히 동일(equivalent)합니다.

2.2. NLL (Negative Log Likelihood) 최소화

  • 모델을 최적화하기 위해 우리는 우도 \(p(D|\theta)\)를 최대화하는 파라미터 \(\theta^{*}\)를 찾아야 합니다. 이를 수식으로 전개하면 다음과 같습니다.

\[\theta^{*} = \text{argmax}_{\theta} p(D|\theta)\]

  • 샘플들이 서로 독립(independence)이라고 가정하면, 데이터 셋의 결합 확률(Joint probability)은 각 개별 샘플 우도의 곱으로 표현됩니다. \[= \text{argmax}_{\theta} \prod_{x \in D} p(x|\theta)\]

  • 여기에 자연로그(log)를 취하면, 로그의 성질(property of log)에 의해 곱셈이 덧셈으로 바뀌어 연산이 훨씬 수월해지고 극단적으로 작은 확률값들의 곱셈으로 인한 언더플로우를 방지할 수 있습니다. 머신러닝의 최적화 문제에서는 통상적으로 손실(loss)을 ’최소화(minimize)’하는 형태를 띠므로, 전체 식에 마이너스(-) 기호를 붙여 NLL (Negative Log Likelihood) 형태로 변환합니다.

\[= \text{argmin}_{\theta} -\sum_{x \in D} \log p(x|\theta)\]

3. MLE 적용 사례: 가우시안 분포 (Gaussian Distribution)

  • 파라메트릭 분포 모델에서 예측 결과가 정규분포를 따른다고 가정했을 때의 구체적인 NLL을 유도해 보겠습니다.

  • 네트워크는 두 개의 프로젝션 헤드를 통해 평균 \(\mu\)와 표준편차 \(\sigma\)를 생성합니다. 이 경우 가우시안 \(\mathcal{N}(\mu, \sigma^{2})\)의 우도는 확률 밀도 함수(PDF) 그 자체와 동일합니다. \[p(x|\mu,\sigma) = \frac{1}{\sqrt{2\pi\sigma^{2}}} \exp\left(-\frac{(x-\mu)^{2}}{2\sigma^{2}}\right)\]

    • 여기서 \(x\)는 손실을 계산하고자 하는 실제 관측 타겟 데이터입니다.

  • 이 식에 \(-\log\)를 취하여 NLL(\(\mathcal{L}\))을 유도하면 다음과 같습니다. \[-\log p(x|\mu,\sigma) = -\log \left( \frac{1}{\sqrt{2\pi\sigma^{2}}} \exp\left(-\frac{(x-\mu)^{2}}{2\sigma^{2}}\right) \right)\] \[= \frac{(x-\mu)^{2}}{2\sigma^{2}} + \log(\sigma) + C\]

    • 여기서 \(C\)는 모델 파라미터와 무관한 상수항이므로 학습 그래디언트에 영향을 주지 않습니다.

  • 이 손실 함수를 최소화하는 방향으로 모델이 업데이트될 때 다음과 같은 현상이 발생합니다.

  • 모델이 추정하는 평균 \(\mu\)는 오차를 줄이기 위해 실제 샘플 \(x\)의 위치로 점점 다가가도록(updated toward) 유도됩니다.

  • 반면 표준편차 \(\sigma\)는 흥미로운 트레이드오프(tradeoff) 상황에 놓입니다. 수식의 \(\log(\sigma)\) 항은 표준편차를 무조건 줄이려는(direction to be reduced) 압력을 가하지만, 분모에 있는 \(\sigma^{2}\) 항은 예측 오차 \((x-\mu)^{2}\)가 클 때 \(\sigma\)를 키워서 패널티를 줄이려 합니다. 즉, 모델은 예측 오차가 충분히 작을 때만(only if the error is small) 모델의 확신(작은 \(\sigma\))을 키울 수 있습니다.

3.1. 흥미로운 사실: RMSE와의 관계

  • 만약 우리가 모델 설계 시 표준편차를 예측하지 않고 어떤 ’고정된 값(fixed standard deviation)’을 사용한다고 가정하면 어떻게 될까요? 이 경우 \(\sigma\)는 상수가 되므로, NLL 식은 다음과 같이 간단해집니다.

\[-\log f(x) = (x-\mu)^{2} + C'\]

  • 이 식은 우리가 가장 흔히 사용하는 회귀 손실 함수인 RMSE(혹은 MSE, L2) 손실과 완벽하게 동일(equivalent)해집니다!
  • 즉, 우리가 딥러닝에서 단순 점 예측(Point forecasts) 모델을 RMSE로 학습시키는 행위는, 본질적으로 “모델의 예측 분포가 고정된 표준편차를 가진 가우시안 분포를 따른다”고 가정하고 MLE를 수행하는 것과 자연스럽게 동일한 의미(naturally interpreted)를 지닙니다.

4. 시계열을 넘어선 회귀 문제로의 일반화 (Generalization)

  • 지금까지 살펴본 MLE와 확률적 예측의 아이디어는 시계열 분석(time series forecasting)에만 국한되지 않으며(beyond), 일반적인 모든 딥러닝 회귀(Regression) 문제로 완벽하게 일반화(generalize)될 수 있습니다.

  • 이전 관점 (Before): 네트워크 \(f_{\theta}(x) = \hat{y}\) 가 주어지면 이를 타겟 \(y\)에 대한 결정론적인 단일 점 예측(deterministic prediction)으로만 해석했습니다.

  • 새로운 관점 (Now): 동일한 네트워크라도 \(f_{\theta}(x) = P_{Y}(\cdot|x,\theta)\) 처럼, 입력 \(x\)가 주어졌을 때 가능한 \(Y\)의 확률 분포를 모델링한다고 해석할 수 있습니다. 모델 아키텍처 자체는 크게 변하지 않으며(remains the same), 단지 결과를 어떻게 해석(how to interpret)하고 어떤 목적 함수로 훈련시킬 것인가의 차이일 뿐입니다.

4.1. 회귀 예시: 사과 가격 예측

  • 직관적인 회귀 문제(regression problem)를 상상해 봅시다.
  • 사과의 크기(size) \(X_{1}\)과 무게(weight) \(X_{2}\)가 주어졌을 때(Given), 사과의 가격 \(y\)를 예측해야 합니다.
  • 현실 세계에서 오차가 정확히 ’0(zero error)’인 완벽한 점 예측은 불가능합니다(No!). 대신 우리는 사과 가격이 가질 수 있는 불확실성을 포함한 분포(distribution of price) 자체를 예측해야 합니다.
  • 위 그림처럼 네트워크 \(f_{\theta}\)를 통해 사과의 특성(\(X_1, X_2\))에 따라 가격 분포의 평균 \(\mu\)가 유동적으로 변하게 할 수 있습니다.
  • 만약 RMSE 에러를 최소화하도록 훈련된다면 이는 고정 분산을 가정한 것이지만, 새로운 프로젝션 헤드를 추가한다면 가격의 불확실성(uncertainty) \(\sigma\)까지도 유동적으로 함께 모델링(model)할 수 있습니다.

5. 분포 가정의 중요성과 새로운 목적 함수: 귤 가격 예측

  • 우리가 타겟 변수에 대해 어떤 확률 분포(Different distribution \(p_{\phi}(y)\))를 가정하느냐에 따라 적용해야 할 NLL 손실 함수 \(\mathcal{L}\)의 모양이 완전히 달라집니다.

  • 유사한 예시(similar example)로 귤(tangerine)의 크기 \(x_{1}\)과 무게 \(x_{2}\)를 통해 가격 \(y\)를 예측한다고 가정해 봅시다.

  • 그런데 만약 우리가 귤이 흔하게 널려있는 제주도(Jeju island)에 살고 있다면 어떨까요? 제주도의 많은 지역에서 귤은 거의 무료(free)에 가깝게 거래되거나 나누어집니다. 이 경우 귤의 가격 \(y\)는 종 모양의 정규분포가 아닌, 0에 가장 많은 확률이 몰려있는 지수 분포(exponential distribution)를 따를 확률이 높습니다.

  • 지수 분포의 파라미터는 단 하나, 기댓값에 해당하는 \(1/\lambda\) 뿐입니다. 가격 \(y\)는 음수가 될 수 없으므로(nonnegative를 가정), 지수 분포의 PDF는 \(f(y;\lambda) = \lambda e^{-\lambda y}\)로 정의됩니다.

  • 스케일의 일관성을 위해 모델의 신경망 출력 \(f_{\theta}(x)\)를 \(1/\lambda\) 로 추정하도록 설정한다면, 이 문제에 대한 NLL 손실 함수는 확률 밀도 함수에 \(-\log\)를 취하여 다음과 같이 유도됩니다.

\[\mathcal{L}(\cdot) = \log f_{\theta}(x) + \frac{y}{f_{\theta}(x)}\]

  • 이 수식이 주는 가장 강력하고 중요한 통찰은, 기존 회귀 손실함수에서 널리 쓰이던 “에러(Error)”의 개념(예: \(|y - \hat{y}|\))이 완전히 사라졌다(No concept of error)는 점입니다! 오직 MLE 원리에 의해 유도된 우도식 그 자체가 전혀 새로운 목적 함수(New Objective Function)가 되어 확률적 예측 모델을 훌륭하게 학습시킬 수 있습니다.
