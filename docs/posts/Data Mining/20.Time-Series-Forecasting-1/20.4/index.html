1. 오차 보정 함수 (Error-Correction Functions)

  • 지금까지 살펴본 선형 회귀(Linear Regression) 기반의 모델들을 대체할 수 있는 또 다른 강력한 접근법은 무엇일까요? 그 해답은 “이전의 예측에서 발생한 오차를 바로잡아 다음 예측을 개선한다”는 단순하고 직관적인 아이디어에서 출발합니다.

  • 이러한 접근법을 오차 보정 함수(Error-correction function)라고 부릅니다. 이전 예측으로 인해 발생한 오류를 직접적으로 수정하기 때문입니다. 수식으로는 다음과 같이 표현됩니다: \[Z_{t+1} = Z_t + \alpha (z_t - \hat{z}_t)\]

    • \(Z_t\): 이전 시점의 예측값 (previous forecast)
    • \((z_t - \hat{z}_t)\): 이전 예측에서 발생한 실제 오차 (error in previous forecast)
    • \(\alpha\): 평활화 파라미터(Smoothing parameter)로, 일반적으로 0과 1 사이의 값을 가지며 오차를 얼마나 강하게 보정할지 결정합니다.

2. 단순 지수 평활법 (Simple Exponential Smoothing, ETS)

  • 앞서 정의한 오차 보정 함수를 전개해보면 매우 흥미로운 패턴을 발견할 수 있습니다. 시점 \(t=3\)에 대한 예측값 \(\hat{z}_3\)을 유도하는 과정을 살펴봅시다.

  • 우선 공식을 재배열합니다: \[\hat{z}_3 = \hat{z}_2 + \alpha(z_2 - \hat{z}_2)\] \[= \alpha z_2 + (1-\alpha)\hat{z}_2\]

  • 이제 \(\hat{z}_2\) 자리에 \(t=2\) 시점의 예측 공식을 재귀적으로 대입해 봅니다: \[= \alpha z_2 + (1-\alpha)(\hat{z}_1 + \alpha(z_1 - \hat{z}_1))\] \[= \alpha z_2 + \alpha(1-\alpha)z_1 + (1-\alpha)^2\hat{z}_1\]

  • 이러한 방식을 미래 시점 \(T+h\)까지 일반화하면 다음과 같은 모델이 도출되며, 이를 단순 지수 평활법(Simple Exponential Smoothing, ETS)이라고 부릅니다:

\[\hat{z}_{T+h} = \alpha z_T + \alpha(1-\alpha)z_{T-1} + \alpha(1-\alpha)^2 z_{T-2} + \dots + (1-\alpha)^T \hat{z}_1\]

  • 수식을 보면 최근 관측치일수록 \(\alpha\)에 가까운 큰 가중치를 받고, 과거로 갈수록 \((1-\alpha)\)가 거듭제곱되어 가중치가 기하급수적(Exponential)으로 감소함을 알 수 있습니다. 특히 파라미터 \(\alpha\)가 클수록 최근의 관측치에 더 많은 비중(emphasis)을 두게 되어 예측선이 최근 데이터의 변동에 민감하게 반응하게 됩니다.

3. 상태와 예측의 분리 (State and Prediction)

  • 지수 평활법(ETS)의 구조를 보다 유연하게 확장하기 위해, 모델을 상태(State)와 예측(Prediction)이라는 두 가지 파트로 분리하여 정의해 보겠습니다.

  • 시간 \(t\)에서의 내부 상태를 \(l_t\)라고 정의합시다.

      1. 예측 방정식 (Forecast equation): 이전 시점의 상태 \(l_{t-1}\)을 사용하여 현재 시점의 예측값 \(\hat{z}_t\)를 생성합니다. \[\hat{z}_t = l_{t-1}\]
      1. 오차 보정 (Error Correction): 실제 관측치와 예측치의 오차를 바탕으로, 다음 타임 스텝을 위해 상태 \(l_{t}\)를 \(l_{t+1}\)로 업데이트합니다. \[l_t = l_{t-1} + \alpha(z_t - \hat{z}_t)\]

3.1. 일반화된 지수 평활법 (General Exponential Smoothing)

  • 이제 이 상태(State) \(l_t\)를 단순한 스칼라 값이 아닌 \(d\)차원 벡터(\(l_t \in \mathbb{R}^d\))로 확장하여 ETS 모델을 일반화할 수 있습니다.
    • 예측 방정식: \(\hat{z}_t = a_t^T l_{t-1}\)
    • 오차 보정: \(l_t = F_t l_{t-1} + g_t(z_t - \hat{z}_t)\)
  • 이 일반화된 모델은 데이터를 학습하기 위해 총 4가지의 학습 가능한 파라미터(learnable parameters)를 가집니다:
    • \(a_t \in \mathbb{R}^d\): 이전 상태 \(l_{t-1}\)을 예측값 \(\hat{z}_t\)로 변환하는 벡터.
    • \(F_t \in \mathbb{R}^{d \times d}\): 과거 상태 \(l_{t-1}\)을 현재 상태 \(l_t\)로 변환(Transition)하는 행렬.
    • \(g_t \in \mathbb{R}^d\): 발생한 예측 오차 \((z_t - \hat{z}_t)\)를 상태 \(l_t\)에 얼마나 반영할지 결정하는 벡터.
    • \(l_0 \in \mathbb{R}^d\): 초기 상태 벡터.

4. 상태 공간 모델 (State Space Models, SSM)

  • 상태 공간 모델(SSM)은 앞서 정의한 일반화된 지수 평활 모델을 더욱 단순화하면서도 통계적으로 강력하게 만듭니다.

  • 핵심적인 질문은 이것입니다. “오차 보정 항 \((z_t - \hat{z}_t)\)이 반드시 예측 공식 안에 명시적으로 포함되어야 하는가?” SSM은 그렇지 않다고 대답합니다. 대신, 모델의 오차 \((z_t - \hat{z}_t)\) 자체를 랜덤 변수(Random variable) \(\epsilon_t\)로 취급하여 확률적으로 모델링합니다.

  • 결과적으로 SSM은 다음과 같은 두 가지 확률적 방정식으로 재탄생합니다:

      1. 측정 방정식 (Measurements): 실제 관측치는 내부 상태의 선형 변환에 정규 분포를 따르는 노이즈가 더해진 결과입니다. \[z_t = a_t^T l_{t-1} + \epsilon_t, \quad \epsilon_t \sim \mathcal{N}(0, \sigma^2)\]
      1. 상태 전이 (State transition): 다음 상태는 이전 상태의 선형 변환에 전이 노이즈가 더해져 결정됩니다. \[l_t = F_t l_{t-1} + g_t \epsilon_t\]

  • 여기서 초기 상태 \(l_0\) 역시 고정된 파라미터가 아니라 랜덤 변수(\(l_0 \sim \mathcal{N}(\mu_0, \text{diag}(\sigma_0^2))\))로 가정된다는 점이 특징입니다.

5. 선형 상태 공간 모델 (Linear State Space Models)

  • 마지막으로, 순수한 SSM 구조에 이전에 배웠던 특성 기반(Feature-based) 선형 회귀를 결합하여 더욱 강력한 선형 상태 공간 모델을 구축할 수 있습니다. 이 방법은 모델의 표현력을 높여주지만(Stronger), 동시에 학습해야 할 파라미터의 수가 늘어난다는 트레이드오프가 존재합니다.

  • 구조는 다음과 같이 나뉩니다:

    • 선형 상태 공간 파트 (Linear State Space Model part): 시계열의 내재적 동인을 모델링합니다. \[u_t = a_t^T l_{t-1}\]
    • 특성 기반 파트 (Feature-based part): 외부 변수나 지표 등 명시적인 특성(Features)을 모델링합니다. \[b_t = w^T x_t\]

  • 최종적으로 데이터가 생성될 확률적 모델(Likelihood)은 이 두 파트의 합인 \(u_t + b_t\)를 조건으로 하는 확률 분포로 정의됩니다: \[z_t \sim P(z_t | u_t + b_t)\]

  • 이를 통해 우리는 시계열 자체의 잠재적인 모멘텀(State)과 우리가 명시적으로 부여한 정보(Features)를 모두 활용하여 미래를 확률적으로 예측할 수 있게 됩니다.
