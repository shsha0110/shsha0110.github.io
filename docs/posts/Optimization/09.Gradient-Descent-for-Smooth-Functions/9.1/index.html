이번 강의에서는 비매끄러운(non-smooth) 함수를 위한 열경사법(subgradient method) 에서 한 걸음 더 나아가, 미분 가능하면서 평활(smooth) 한 함수에 대한 경사하강법(gradient descent) 을 다룹니다. 핵심 메시지는 명확합니다. 함수가 평활하다는 단 하나의 가정만 추가하면, 우리는 상수 스텝 사이즈(constant step size) 를 쓰면서도 열경사법보다 훨씬 빠른 \(O(1/T)\) 수렴률을 얻을 수 있습니다. 이 마법 같은 결과를 떠받치는 것이 바로 평활 함수의 자기 조정(self-tuning) 성질 입니다.

1. 개요 (Outline)

이번 강의의 학습 목표는 다음 세 가지입니다.

  • 경사하강법(gradient descent) 입문: 비매끄러운 함수에서 쓰던 열경사법과 무엇이 다른지를 이해합니다.
  • 평활 함수에 대한 경사하강법의 수렴 분석(convergence analysis): 상수 스텝 사이즈로 \(O(1/T)\) 수렴률을 증명합니다.
  • 평활 함수(smooth functions)의 성질: 이차 상계, 최적성 갭, gradient의 co-coercivity 등 수렴 분석을 떠받치는 핵심 도구들을 정리합니다.

2. 평활 함수에 대한 경사하강법의 수렴 (Convergence of Gradient Descent for Smooth Functions)

2.1 β-평활성의 정의와 self-tuning 성질

미분 가능한 함수 \(f : \mathbb{R}^d \to \mathbb{R}\) 가 어떤 \(\beta > 0\) 에 대해 \(\ell_2\) 노름에서 \(\beta\)-평활(\(\beta\)-smooth) 하다는 것은, 임의의 \(x, y \in \mathbb{R}^d\) 에 대해 다음이 성립함을 의미합니다.

\[ \|\nabla f(x) - \nabla f(y)\|_2 \le \beta \|x - y\|_2 \]

  • 이 정의는 곧 gradient \(\nabla f\) 가 \(\beta\)-립시츠 연속(Lipschitz continuous) 임을 뜻합니다. 즉, 두 점이 가까우면 그 점들에서의 gradient도 비슷하다는, gradient의 “안정성”을 요구하는 조건입니다.

여기서 평활 함수가 가지는 핵심적인 직관, 자기 조정(self-tuning) 성질 이 등장합니다.

  • 제약 없는(unconstrained) 문제에서 최적해 \(x^\ast\) 는 최적성 조건(optimality condition) 에 의해 \(\nabla f(x^\ast) = 0\) 을 만족합니다.
  • 그런데 \(\beta\)-평활성 정의에 \(y = x^\ast\) 를 대입하면 다음을 얻습니다.

\[ \|\nabla f(x)\|_2 = \|\nabla f(x) - \nabla f(x^\ast)\|_2 \le \beta \|x - x^\ast\|_2 \]

  • 즉, 최적해에 가까워질수록(\(\|x - x^\ast\|_2 \to 0\)) gradient의 크기도 자연스럽게 0으로 줄어듭니다. 이것이 self-tuning 성질의 본질입니다.

이는 미분 불가능한 함수 와 극명하게 대조됩니다. 예를 들어 \(\mathbb{R}\) 위의 \(f(x) = |x|\) 를 생각해 보면, 최적해 \(x^\ast = 0\) 근처에서도 열경사(subgradient)의 크기는 줄어들지 않고 \(\pm 1\) 사이에서 진동합니다.

2.2 스텝 사이즈 관점에서의 차이

이 self-tuning 성질은 스텝 사이즈(step size) 선택에 직접적인 영향을 줍니다.

  • 립시츠 연속 함수(비매끄러운 경우) 에 대한 열경사법은 반복 횟수 \(T\) 에 의존하는 작고 점점 줄어드는 스텝 사이즈 \(O(1/\sqrt{T})\) 를 요구했습니다. 그 이유는 열경사가 최적해 근처에서도 줄어들지 않기 때문에, 진동을 억제하려면 스텝을 인위적으로 작게 만들어야 했기 때문입니다.
  • 평활 함수 에서는 사정이 다릅니다. 최적해에 가까워질수록 gradient가 알아서 작아지므로, 우리는 \(T\) 에 의존하지 않는 큰 상수 스텝 사이즈 를 안전하게 쓸 수 있습니다. 이것이 바로 self-tuning 성질이 주는 실질적인 이득입니다.

2.3 경사 스텝은 항상 엄격한 개선을 보장한다 (Descent Lemma)

수렴 결과를 증명하기 전에, 먼저 하나의 경사 스텝(gradient step)이 항상 목적함수 값을 엄격하게 개선함 을 보이겠습니다. 미분 가능한 \(\beta\)-평활 함수 \(f\) 에 대해, 경사 스텝은 다음과 같이 정의됩니다.

\[ x_{t+1} = x_t - \eta_t \nabla f(x_t) \]

여기서 \(\eta_t > 0\) 는 스텝 사이즈입니다. 이제 평활 함수의 이차 상계(quadratic upper bound)(3.1절에서 증명할 핵심 부등식)를 출발점으로 삼습니다.

\[ f(x_{t+1}) \le f(x_t) + \nabla f(x_t)^\top (x_{t+1} - x_t) + \frac{\beta}{2}\|x_{t+1} - x_t\|_2^2 \]

단계별 유도

여기에 경사 스텝 정의 \(x_{t+1} - x_t = -\eta_t \nabla f(x_t)\) 를 대입합니다.

  • 1차 항(linear term): \[ \nabla f(x_t)^\top(x_{t+1} - x_t) = \nabla f(x_t)^\top \big(-\eta_t \nabla f(x_t)\big) = -\eta_t \|\nabla f(x_t)\|_2^2 \]
  • 2차 항(quadratic term): \[ \frac{\beta}{2}\|x_{t+1} - x_t\|_2^2 = \frac{\beta}{2}\|-\eta_t \nabla f(x_t)\|_2^2 = \frac{\eta_t^2 \beta}{2}\|\nabla f(x_t)\|_2^2 \]

이 둘을 합치면 다음을 얻습니다.

\[ f(x_{t+1}) \le f(x_t) + \left(-\eta_t + \frac{\eta_t^2 \beta}{2}\right)\|\nabla f(x_t)\|_2^2 \]

이제 핵심은 괄호 안의 \(-\eta_t + \frac{\eta_t^2 \beta}{2}\) 를 가장 작게(가장 음수로) 만드는 \(\eta_t\) 를 고르는 것입니다. 이 표현은 \(\eta_t\) 에 대한 이차함수 이며, \(\eta_t^2\) 의 계수 \(\beta/2 > 0\) 이므로 아래로 볼록한 포물선입니다.

  • \(\eta_t\) 로 미분하여 0으로 놓으면 \(-1 + \eta_t \beta = 0\), 즉 \(\eta_t = 1/\beta\) 에서 최솟값을 가집니다.
  • (강의 노트에서 “maximized”라고 표현한 것은, 부호를 뒤집어 본 목적함수의 감소량 \(\eta_t - \frac{\eta_t^2\beta}{2}\) 가 \(\eta_t = 1/\beta\) 에서 최대가 된다는 뜻으로 이해하면 자연스럽습니다. 즉 한 스텝당 보장되는 개선폭을 최대화하는 선택입니다.)
  • 이때의 값은 \(-\frac{1}{\beta} + \frac{1}{\beta^2}\cdot\frac{\beta}{2} = -\frac{1}{2\beta}\) 입니다.

따라서 \(\eta_t = 1/\beta\) 로 두면 다음의 하강 보조정리(descent lemma) 를 얻습니다.

\[ \boxed{\,f(x_{t+1}) \le f(x_t) - \frac{1}{2\beta}\|\nabla f(x_t)\|_2^2\,} \]

  • 이 부등식은 \(x_t\) 가 최적해가 아니어서 \(\nabla f(x_t) \ne 0\) 인 한, \(f(x_{t+1})\) 이 \(f(x_t)\) 보다 엄격하게 작아진다 는 것을 보장합니다. 즉 경사하강법은 매 스텝마다 목적함수를 반드시 개선합니다.

2.4 수렴 정리 (Theorem 9.1)

이제 위의 관찰을 바탕으로 평활 볼록 함수에 대한 수렴률을 증명합니다.

정리 9.1 (Theorem 9.1). \(f : \mathbb{R}^d \to \mathbb{R}\) 가 \(\ell_2\) 노름에서 \(\beta\)-평활하고 볼록(convex) 하다고 하자. 그리고 \(\{x_t : t = 1, \dots, T+1\}\) 을 각 \(t\) 에 대해 스텝 사이즈 \(\eta_t = \dfrac{1}{\beta}\) 로 경사하강법이 생성한 반복열이라 하자. 그러면 \[ f(x_{T+1}) - f(x^\ast) \le \frac{\beta \|x_1 - x^\ast\|_2^2}{2T} \] 가 성립한다. 여기서 \(x^\ast\) 는 \(\min_{x \in \mathbb{R}^d} f(x)\) 의 최적해이다.

증명 (Proof)

(1단계) 하강 보조정리에서 출발. 2.3절의 결과로부터,

\[ f(x_{t+1}) \le f(x_t) - \frac{1}{2\beta}\|\nabla f(x_t)\|_2^2 \]

(2단계) 볼록성으로 \(f(x_t)\) 를 위에서 누르기. \(f\) 가 볼록하므로 1차 하계(first-order lower bound)가 성립합니다. 즉 \(f(x^\ast) \ge f(x_t) + \nabla f(x_t)^\top(x^\ast - x_t)\) 이고, 이를 정리하면

\[ f(x_t) \le f(x^\ast) - \nabla f(x_t)^\top(x^\ast - x_t) \]

이를 1단계에 대입하면

\[ f(x_{t+1}) \le f(x^\ast) - \nabla f(x_t)^\top(x^\ast - x_t) - \frac{1}{2\beta}\|\nabla f(x_t)\|_2^2 \]

(3단계) 우변을 거리의 차이로 변환 (완전제곱식 트릭). 경사 스텝이 \(x_{t+1} = x_t - \frac{1}{\beta}\nabla f(x_t)\) 임을 이용해 다음 항등식을 만듭니다. \(\|x_{t+1} - x^\ast\|_2^2\) 를 전개하면

\[ \|x_{t+1} - x^\ast\|_2^2 = \left\|x_t - x^\ast - \tfrac{1}{\beta}\nabla f(x_t)\right\|_2^2 = \|x_t - x^\ast\|_2^2 - \frac{2}{\beta}\nabla f(x_t)^\top(x_t - x^\ast) + \frac{1}{\beta^2}\|\nabla f(x_t)\|_2^2 \]

따라서

\[ \frac{\beta}{2}\Big(\|x_t - x^\ast\|_2^2 - \|x_{t+1} - x^\ast\|_2^2\Big) = \nabla f(x_t)^\top(x_t - x^\ast) - \frac{1}{2\beta}\|\nabla f(x_t)\|_2^2 \]

이 표현이 정확히 2단계 우변의 \(-\nabla f(x_t)^\top(x^\ast - x_t) - \frac{1}{2\beta}\|\nabla f(x_t)\|_2^2\) 와 같습니다(\(-(x^\ast - x_t) = (x_t - x^\ast)\)). 그러므로

\[ f(x_{t+1}) \le f(x^\ast) + \frac{\beta}{2}\Big(\|x_t - x^\ast\|_2^2 - \|x_{t+1} - x^\ast\|_2^2\Big) \]

즉

\[ f(x_{t+1}) - f(x^\ast) \le \frac{\beta}{2}\Big(\|x_t - x^\ast\|_2^2 - \|x_{t+1} - x^\ast\|_2^2\Big) \]

(4단계) 망원합(telescoping)으로 합산. \(t = 1, \dots, T\) 에 대해 위 부등식을 더하면, 우변은 인접 항들이 상쇄되는 망원합이 되어

\[ \sum_{t=1}^{T}\big(f(x_{t+1}) - f(x^\ast)\big) \le \frac{\beta}{2}\Big(\|x_1 - x^\ast\|_2^2 - \|x_{T+1} - x^\ast\|_2^2\Big) \le \frac{\beta}{2}\|x_1 - x^\ast\|_2^2 \]

마지막 부등식은 \(\|x_{T+1} - x^\ast\|_2^2 \ge 0\) 이므로 그 항을 버려서 얻습니다. 양변을 \(T\) 로 나누면

\[ \frac{1}{T}\sum_{t=1}^{T}\big(f(x_{t+1}) - f(x^\ast)\big) \le \frac{\beta}{2T}\|x_1 - x^\ast\|_2^2 \]

(5단계) 단조 감소성으로 마무리. 평활 함수에 대한 각 경사 스텝은 목적함수를 개선하므로 \(f(x_{t+1}) \le f(x_t)\), 즉 수열 \(\{f(x_{t+1})\}\) 은 단조 감소 합니다. 따라서 마지막 값 \(f(x_{T+1})\) 은 평균보다 작거나 같습니다.

\[ f(x_{T+1}) - f(x^\ast) \le \frac{1}{T}\sum_{t=1}^{T}\big(f(x_{t+1}) - f(x^\ast)\big) \le \frac{\beta}{2T}\|x_1 - x^\ast\|_2^2 \]

이것으로 증명이 끝납니다. \(\qquad\blacksquare\)

  • 참고: 열경사법에서는 평균점 \(\frac{1}{T}\sum_t x_t\) 에 대한 보장만 얻을 수 있었던 반면, 여기서는 단조 감소성 덕분에 마지막 반복점 \(x_{T+1}\) 에 대한 직접적인 보장을 얻는다는 점이 중요한 차이입니다.

2.5 핵심 시사점과 열경사법과의 비교

  • 가장 중요한 시사점은, 우리가 반복 횟수 \(T\) 에 의존하지 않는 상수 스텝 사이즈 \(1/\beta\) 를 사용했다는 것입니다. 이는 평활 함수의 self-tuning 성질 덕분입니다. 스텝 사이즈 자체는 줄이지 않더라도, 최적해에 다가갈수록 \(x_t\) 와 \(x_{t+1}\) 사이의 실제 이동량 \(\eta_t\|\nabla f(x_t)\|_2\) 가 자연스럽게 줄어듭니다.
  • \(\|x_1 - x^\ast\|_2\) 와 평활 파라미터 \(\beta\) 는 모두 고정된 상수이므로, 수렴률은 \(O(1/T)\) 입니다. 따라서 \(f(x_{T+1}) - f(x^\ast) \le \epsilon\) 을 달성하려면 \(T = O(1/\epsilon)\) 번의 반복이면 충분합니다.

이는 열경사법의 \(O(1/\sqrt{T})\) 수렴률 및 \(O(1/\epsilon^2)\) 반복 복잡도보다 확연히 개선된 결과입니다. 두 방법의 분석 마지막 단계를 나란히 비교하면 그 차이가 어디서 오는지 분명해집니다.

  • 열경사법(subgradient method): \[ f\!\left(\frac{1}{T}\sum_{t=1}^{T}x_t\right) - f(x^\ast) \le \frac{1}{T}\sum_{t=1}^{T}\big(f(x_t) - f(x^\ast)\big) \le \frac{\|x_1 - x^\ast\|_2^2}{2\eta T} + \frac{\eta L^2}{2} \]
  • 평활 함수에 대한 경사하강법: \[ f(x_{T+1}) - f(x^\ast) \le \frac{1}{T}\sum_{t=1}^{T}\big(f(x_{t+1}) - f(x^\ast)\big) \le \frac{\|x_1 - x^\ast\|_2^2}{2\eta T} \]

두 식은 거의 같지만 결정적인 차이가 있습니다.

  • 평활 함수의 경우 우변에 추가 항 \(\eta L^2 / 2\) 가 없습니다. 열경사법에서는 이 항 때문에 스텝 사이즈 \(\eta\) 를 키울 수도 줄일 수도 없는 trade-off가 발생하여, 최적의 \(\eta\) 를 고르면 \(O(1/\sqrt{T})\) 에 머무릅니다.
  • 또한 평활 함수에서는 매 경사 스텝이 목적함수를 개선한다 는 사실(단조 감소성)을 추가로 사용할 수 있었습니다.

3. 평활 함수 (Smooth Functions)

3.1 평활 함수의 이차 상계 (Quadratic Upper Bounds on Smooth Functions)

지난 절(2장)의 수렴 분석은 전적으로 다음의 이차 상계 부등식(quadratic upper bound inequality) 에 의존했습니다. \(\beta\)-평활한 볼록 함수 \(f : \mathbb{R}^d \to \mathbb{R}\) 에 대해, 임의의 \(x, y \in \mathbb{R}^d\) 에서

\[ f(y) \le f(x) + \nabla f(x)^\top(y - x) + \frac{\beta}{2}\|y - x\|_2^2 \]

이 성립합니다. 이는 \(f\) 를 점 \(x\) 에서의 1차 테일러 근사 위로 얹은 이차함수가 항상 위에서 덮는다 는 기하학적 의미를 가집니다. 이 성질을 평활 함수의 여러 중요한 성질들과 함께 검증해 보겠습니다.

정리 9.2: 평활성과 볼록성의 동치 (Theorem 9.2)

정리 9.2 (Theorem 9.2). \(f : \mathbb{R}^d \to \mathbb{R}\) 를 볼록 함수라 하자. 그러면 \(f\) 가 어떤 \(\beta > 0\) 에 대해 \(\ell_2\) 노름에서 \(\beta\)-평활할 필요충분조건은 \[ g(x) = \frac{\beta}{2}\|x\|_2^2 - f(x) \] 가 볼록인 것이다.

이 정리는 “평활성”이라는 미분 조건을 “\(\frac{\beta}{2}\|x\|^2 - f\) 의 볼록성”이라는 더 다루기 쉬운 조건으로 바꿔 줍니다. 직관적으로는, \(f\) 가 어느 방향으로도 이차함수 \(\frac{\beta}{2}\|x\|^2\) 보다 “더 빠르게 휘지 않는다”는 곡률 상한 조건입니다.

증명 (\(\Rightarrow\) 방향): 평활 \(\Rightarrow\) \(g\) 볼록

볼록 함수의 단조성 조건(monotonicity condition), 즉 gradient가 단조 연산자라는 조건 \(\langle \nabla g(x) - \nabla g(y), x - y\rangle \ge 0\) 을 보이면 됩니다.

  • \(g\) 의 gradient는 \(\nabla g(x) = \beta x - \nabla f(x)\) 입니다.
  • 따라서 \[ \langle \nabla g(x) - \nabla g(y),\, x - y\rangle = \beta\|x - y\|_2^2 - \langle \nabla f(x) - \nabla f(y),\, x - y\rangle \]
  • 이제 코시-슈바르츠 부등식(Cauchy-Schwarz inequality) 과 \(\beta\)-평활성을 차례로 적용하면 \[ \langle \nabla f(x) - \nabla f(y),\, x - y\rangle \le \|\nabla f(x) - \nabla f(y)\|_2 \cdot \|x - y\|_2 \le \beta\|x - y\|_2^2 \]
  • 그러므로 \[ \langle \nabla g(x) - \nabla g(y),\, x - y\rangle \ge \beta\|x-y\|_2^2 - \beta\|x-y\|_2^2 = 0 \] 즉 \(g\) 는 볼록입니다.

증명 (\(\Leftarrow\) 방향): \(g\) 볼록 \(\Rightarrow\) 평활

\(g\) 가 볼록이므로, 볼록 함수의 1차 특성화(first-order characterization) 에 의해 임의의 \(z \in \mathbb{R}^d\) 에 대해

\[ \frac{\beta}{2}\|z\|_2^2 - f(z) \ge \frac{\beta}{2}\|x\|_2^2 - f(x) + \big(\beta x - \nabla f(x)\big)^\top(z - x) \]

이 부등식을 정리하면(좌변·우변의 노름 항들을 모아 \(\frac{\beta}{2}\|z-x\|_2^2\) 로 완성하면) 바로 이차 상계 가 됩니다.

\[ f(z) \le f(x) + \nabla f(x)^\top(z - x) + \frac{\beta}{2}\|z - x\|_2^2 \quad \forall z \in \mathbb{R}^d \tag{$\star$} \]

(보충) 노름 항 정리: \(\frac{\beta}{2}\|z\|^2 - \frac{\beta}{2}\|x\|^2 - \beta x^\top(z-x) = \frac{\beta}{2}\big(\|z\|^2 - \|x\|^2 - 2x^\top z + 2\|x\|^2\big) = \frac{\beta}{2}\|z-x\|^2\) 임을 이용합니다.

이제 이 부등식 \((\star)\) 로부터 평활성을 끌어냅니다. 영리하게 \(z = y + \frac{1}{\beta}\big(\nabla f(x) - \nabla f(y)\big)\) 로 놓고 다음을 계산합니다.

\[ \begin{aligned} f(x) - f(y) &= \big(f(x) - f(z)\big) + \big(f(z) - f(y)\big)\\ &\le -\nabla f(x)^\top(z - x) + \nabla f(y)^\top(z - y) + \frac{\beta}{2}\|z - y\|_2^2 \end{aligned} \]

  • 첫째 항 \(f(x) - f(z) \le -\nabla f(x)^\top(z-x)\) 는 \(f\) 의 볼록성(1차 하계 \(f(z) \ge f(x) + \nabla f(x)^\top(z-x)\))에서 옵니다.
  • 둘째 항 \(f(z) - f(y) \le \nabla f(y)^\top(z-y) + \frac{\beta}{2}\|z-y\|_2^2\) 는 점 \(y\) 에서의 이차 상계 \((\star)\) 에서 옵니다.

선형 항들을 정리하면

\[ f(x) - f(y) \le \nabla f(x)^\top(x - y) + \big(\nabla f(x) - \nabla f(y)\big)^\top(y - z) + \frac{\beta}{2}\|z - y\|_2^2 \]

이제 \(z - y = \frac{1}{\beta}(\nabla f(x) - \nabla f(y))\) 이므로 \(y - z = -\frac{1}{\beta}(\nabla f(x) - \nabla f(y))\) 를 대입합니다.

  • \(\big(\nabla f(x) - \nabla f(y)\big)^\top(y - z) = -\frac{1}{\beta}\|\nabla f(x) - \nabla f(y)\|_2^2\)
  • \(\frac{\beta}{2}\|z - y\|_2^2 = \frac{\beta}{2}\cdot\frac{1}{\beta^2}\|\nabla f(x) - \nabla f(y)\|_2^2 = \frac{1}{2\beta}\|\nabla f(x) - \nabla f(y)\|_2^2\)

두 항을 합치면 \(-\frac{1}{\beta} + \frac{1}{2\beta} = -\frac{1}{2\beta}\) 이므로

\[ f(x) - f(y) \le \nabla f(x)^\top(x - y) - \frac{1}{2\beta}\|\nabla f(x) - \nabla f(y)\|_2^2 \]

이를 정리하면

\[ \frac{1}{2\beta}\|\nabla f(x) - \nabla f(y)\|_2^2 \le f(y) - f(x) + \nabla f(x)^\top(x - y) \]

같은 방식으로 \(x\) 와 \(y\) 의 역할을 바꾸면

\[ \frac{1}{2\beta}\|\nabla f(y) - \nabla f(x)\|_2^2 \le f(x) - f(y) + \nabla f(y)^\top(y - x) \]

이 두 부등식을 더하면 \(f(y) - f(x)\) 와 \(f(x) - f(y)\) 가 상쇄되어

\[ \frac{1}{\beta}\|\nabla f(x) - \nabla f(y)\|_2^2 \le \big(\nabla f(x) - \nabla f(y)\big)^\top(x - y) \]

마지막으로 우변에 코시-슈바르츠 부등식 \(\big(\nabla f(x) - \nabla f(y)\big)^\top(x-y) \le \|\nabla f(x) - \nabla f(y)\|_2 \cdot \|x-y\|_2\) 를 적용하고 양변을 \(\|\nabla f(x) - \nabla f(y)\|_2\) 로 나누면

\[ \|\nabla f(x) - \nabla f(y)\|_2 \le \beta\|x - y\|_2 \]

즉 \(f\) 는 \(\beta\)-평활합니다. \(\qquad\blacksquare\)

  • 정리하면, 볼록 함수의 1차 특성화 에 의해 \(g(x) = \frac{\beta}{2}\|x\|_2^2 - f(x)\) 가 볼록일 조건 \(g(y) \ge g(x) + \nabla g(x)^\top(y-x)\) 은 바로 이차 상계 \[ f(y) \le f(x) + \nabla f(x)^\top(y - x) + \frac{\beta}{2}\|y - x\|_2^2 \] 와 동치이며, 이로써 평활 함수의 이차 상계 성질이 확인됩니다.

보조정리 9.3: 볼록성 없이도 성립하는 이차 근사 오차 한계 (Lemma 9.3)

사실 이차 근사 오차에 대한 한계는 \(f\) 가 볼록이 아니어도 성립합니다. 다음의 더 강한 양방향(절댓값) 형태를 증명합니다.

보조정리 9.3 (Lemma 9.3). \(f\) 가 \(\ell_2\) 노름에서 \(\beta\)-평활하면, 임의의 \(x, y\) 에 대해 \[ \left| f(y) - f(x) - \nabla f(x)^\top(y - x) \right| \le \frac{\beta}{2}\|y - x\|_2^2 \]

증명: 미적분의 기본정리 활용

핵심 아이디어는 \(x\) 에서 \(y\) 까지를 잇는 선분 위에서 미적분의 기본정리(fundamental theorem of calculus) 를 적용하는 것입니다. 합성함수 \(\phi(t) = f(x + t(y-x))\) 를 생각하면 \(\phi'(t) = (y-x)^\top \nabla f(x + t(y-x))\) 이고, \(f(y) - f(x) = \int_0^1 \phi'(t)\,dt\) 입니다. 여기서 \(\nabla f(x)^\top(y-x) = \int_0^1 (y-x)^\top \nabla f(x)\,dt\) 를 빼 주면

\[ \begin{aligned} \left| f(y) - f(x) - \nabla f(x)^\top(y - x) \right| &= \left| \int_0^1 (y - x)^\top \big(\nabla f(x + t(y - x)) - \nabla f(x)\big)\, dt \right|\\ &\le \int_0^1 \|y - x\|_2\, \|\nabla f(x + t(y - x)) - \nabla f(x)\|_2\, dt\\ &\le \int_0^1 \beta t\, \|y - x\|_2^2\, dt\\ &= \frac{\beta}{2}\|y - x\|_2^2 \end{aligned} \]

  • 등식: 미적분의 기본정리.
  • 첫 번째 부등식: 적분의 절댓값에 대한 삼각부등식과 코시-슈바르츠 부등식.
  • 두 번째 부등식: \(\beta\)-평활성. 두 점 \(x + t(y-x)\) 와 \(x\) 사이의 거리가 \(\|t(y-x)\|_2 = t\|y-x\|_2\) 이므로 \(\|\nabla f(x + t(y-x)) - \nabla f(x)\|_2 \le \beta t \|y - x\|_2\).
  • 마지막 등식: \(\int_0^1 t\, dt = \frac{1}{2}\). \(\qquad\blacksquare\)

3.2 평활 함수의 최적성 갭 (Optimality Gap for Smooth Functions)

\(f\) 가 평활할 때 흥미로운 또 하나의 결과는, 임의의 점 \(x\) 만으로 최적값과의 갭 \(f(x) - f(x^\ast)\) 을 양쪽에서 추정 할 수 있다는 것입니다.

정리 9.4: 최적성 갭의 상·하계 (Theorem 9.4)

정리 9.4 (Theorem 9.4). \(f : \mathbb{R}^d \to \mathbb{R}\) 가 \(\ell_2\) 노름에서 \(\beta\)-평활하고 볼록하면, 임의의 \(x \in \mathbb{R}^d\) 에 대해 \[ \frac{1}{2\beta}\|\nabla f(x)\|_2^2 \le f(x) - f(x^\ast) \le \frac{\beta}{2}\|x - x^\ast\|_2^2 \] 가 성립한다. 여기서 \(x^\ast\) 는 \(\min_{x \in \mathbb{R}^d} f(x)\) 의 최적해이다.

  • 하계의 의미: gradient의 크기 \(\|\nabla f(x)\|_2\) 가 작으면 우리는 이미 최적값에 가깝다는 것을 확신 할 수 있습니다. 즉 gradient는 정지 조건(stopping criterion)으로 쓸 수 있는 신뢰할 만한 신호입니다.
  • 상계의 의미: 점 \(x\) 가 최적해 \(x^\ast\) 에 가까우면 함수값도 최적값에 가깝습니다.

증명

상계 먼저. \(f\) 가 \(\beta\)-평활하므로 점 \(x^\ast\) 에서의 이차 상계를 쓰면

\[ f(x) \le f(x^\ast) + \nabla f(x^\ast)^\top(x - x^\ast) + \frac{\beta}{2}\|x - x^\ast\|_2^2 \]

최적성 조건 \(\nabla f(x^\ast) = 0\) 에 의해 가운데 항이 사라지므로

\[ f(x) - f(x^\ast) \le \frac{\beta}{2}\|x - x^\ast\|_2^2 \]

하계. 임의의 \(y \in \mathbb{R}^d\) 에 대해, \(x^\ast\) 가 최소점이라는 사실과 점 \(x\) 에서의 이차 상계를 결합하면

\[ f(x^\ast) \le f(y) \le f(x) + \nabla f(x)^\top(y - x) + \frac{\beta}{2}\|y - x\|_2^2 \]

여기서 우변을 최소화하는 \(y\) 를 고릅니다. 우변은 \(y\) 에 대한 이차함수이고, 그 최솟값은 \(y = x - \frac{1}{\beta}\nabla f(x)\) 에서 달성됩니다. 이를 대입하면

  • \(\nabla f(x)^\top(y - x) = \nabla f(x)^\top\big(-\tfrac{1}{\beta}\nabla f(x)\big) = -\frac{1}{\beta}\|\nabla f(x)\|_2^2\)
  • \(\frac{\beta}{2}\|y - x\|_2^2 = \frac{\beta}{2}\cdot\frac{1}{\beta^2}\|\nabla f(x)\|_2^2 = \frac{1}{2\beta}\|\nabla f(x)\|_2^2\)

따라서 우변은

\[ f(x) - \frac{1}{\beta}\|\nabla f(x)\|_2^2 + \frac{1}{2\beta}\|\nabla f(x)\|_2^2 = f(x) - \frac{1}{2\beta}\|\nabla f(x)\|_2^2 \]

그러므로

\[ f(x^\ast) \le f(x) - \frac{1}{2\beta}\|\nabla f(x)\|_2^2 \quad\Longleftrightarrow\quad \frac{1}{2\beta}\|\nabla f(x)\|_2^2 \le f(x) - f(x^\ast) \]

이것으로 하계가 증명됩니다. \(\qquad\blacksquare\)

보조정리 9.5: gradient의 co-coercivity (Lemma 9.5)

정리 9.4를 바탕으로 평활 함수의 또 다른 강력한 성질, gradient의 공강제성(co-coercivity) 을 증명할 수 있습니다.

보조정리 9.5 (Lemma 9.5). \(f : \mathbb{R}^d \to \mathbb{R}\) 가 \(\ell_2\) 노름에서 \(\beta\)-평활하고 볼록하면, 임의의 \(x, y \in \mathbb{R}^d\) 에 대해 \[ \big(\nabla f(x) - \nabla f(y)\big)^\top(x - y) \ge \frac{1}{\beta}\|\nabla f(x) - \nabla f(y)\|_2^2 \]

  • 단순 볼록성은 \(\big(\nabla f(x) - \nabla f(y)\big)^\top(x-y) \ge 0\) (gradient의 단조성)만을 보장하지만, 평활성이 더해지면 이를 gradient 차이의 제곱항으로 정량적으로 강화 할 수 있습니다. 이 부등식은 경사하강법·가속법(Nesterov) 등 많은 알고리즘의 수렴 분석에서 핵심 도구로 쓰입니다.

증명: 보조함수 트릭

주어진 \(x, y\) 에 대해 다음 두 보조함수를 정의합니다.

\[ g(z) = f(z) - \nabla f(x)^\top z, \qquad h(z) = f(z) - \nabla f(y)^\top z \]

  • gradient를 계산하면 \(\nabla g(z) = \nabla f(z) - \nabla f(x)\), \(\nabla h(z) = \nabla f(z) - \nabla f(y)\) 입니다.
  • 따라서 \(\nabla g(x) = 0\), \(\nabla h(y) = 0\) 이 되어 \(x\) 는 \(g\) 의 최소점, \(y\) 는 \(h\) 의 최소점 입니다.
  • 선형 항을 더해도 곡률(즉 gradient의 차이)은 변하지 않으므로, \(g\) 와 \(h\) 는 여전히 \(\beta\)-평활하고 볼록합니다.

이제 \(g\) 에 정리 9.4의 하계 를 적용합니다. \(x\) 가 \(g\) 의 최소점이므로 \(g(z) - g(x) \ge \frac{1}{2\beta}\|\nabla g(z)\|_2^2\) 이고, \(z = y\) 로 두면

\[ f(y) - f(x) - \nabla f(x)^\top(y - x) = g(y) - g(x) \ge \frac{1}{2\beta}\|\nabla g(y)\|_2^2 = \frac{1}{2\beta}\|\nabla f(y) - \nabla f(x)\|_2^2 \]

(가운데 등식 확인: \(g(y) - g(x) = \big(f(y) - \nabla f(x)^\top y\big) - \big(f(x) - \nabla f(x)^\top x\big) = f(y) - f(x) - \nabla f(x)^\top(y-x)\).)

마찬가지로 \(h\) 에 적용하면(\(y\) 가 \(h\) 의 최소점)

\[ f(x) - f(y) - \nabla f(y)^\top(x - y) = h(x) - h(y) \ge \frac{1}{2\beta}\|\nabla h(x)\|_2^2 = \frac{1}{2\beta}\|\nabla f(x) - \nabla f(y)\|_2^2 \]

이 두 부등식을 더하면 좌변의 \(f(y) - f(x)\) 와 \(f(x) - f(y)\) 가 상쇄되고

\[ -\nabla f(x)^\top(y - x) - \nabla f(y)^\top(x - y) \ge \frac{1}{\beta}\|\nabla f(x) - \nabla f(y)\|_2^2 \]

좌변을 정리하면 \(\big(\nabla f(x) - \nabla f(y)\big)^\top(x - y)\) 와 같으므로

\[ \big(\nabla f(x) - \nabla f(y)\big)^\top(x - y) \ge \frac{1}{\beta}\|\nabla f(x) - \nabla f(y)\|_2^2 \]

이것으로 증명이 완료됩니다. \(\qquad\blacksquare\)

마치며 (Summary)

이번 강의의 핵심을 한 문장으로 요약하면, 평활성(smoothness)은 gradient에 안정성을 부여하여, 상수 스텝 사이즈만으로 \(O(1/T)\) 수렴을 가능하게 한다 는 것입니다.

  • 이차 상계(정리 9.2, 보조정리 9.3) 는 매 스텝의 개선량을 정량화하는 출발점이었습니다.
  • 이를 기반으로 한 하강 보조정리 와 망원합 트릭이 정리 9.1 의 \(O(1/T)\) 수렴률을 낳았습니다.
  • 최적성 갭(정리 9.4) 은 gradient 크기를 정지 조건으로 쓸 수 있게 해 주었고,
  • co-coercivity(보조정리 9.5) 는 단순 볼록성의 gradient 단조성을 정량적으로 강화하여, 이후의 가속 알고리즘 분석으로 가는 다리가 됩니다.
